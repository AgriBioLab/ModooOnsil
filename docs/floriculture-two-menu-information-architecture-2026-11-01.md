# 마이영농·영농일지 메뉴 및 카테고리 구성안

정리일: 2026-11-01
상태: 사용자와 검토 중인 메뉴·카테고리 구성안. 재배 관련 상위 메뉴는 마이영농·영농일지 두 개로 구성한다. 화면 구현 완료나 전체 서비스 메뉴 확정을 의미하지 않는다.

## 1. 상위 메뉴와 기본 진입

| 상위 메뉴 | 역할 | 기본 화면 |
| --- | --- | --- |
| 마이영농 | 내 농장·온실·현재 재배를 확인하고 계획·운영 | 우리 온실 |
| 영농일지 | 관찰·실제 작업·변경·결과를 날짜별로 기록·조회 | 전체 일지 |

기존 재배관리 기능은 마이영농의 재배 목록·상세와 영농일정으로 포함한다. 현황은 우리 온실 화면에서, 통계는 마이영농 하위에서 제공한다. '메인'·'현황'·'재배관리'를 각각 별도 상위 메뉴로 중복하지 않는다.

## 2. 마이영농 하위 메뉴

| 하위 메뉴 | 화면 내 카테고리/영역 | 주요 기능 |
| --- | --- | --- |
| 우리 온실 | 온실·구역 선택 / 내부 환경과 현재 재배 / 오늘 할 일 / 확인할 이상·미수신 / 임박한 출하 | 접속 첫 화면에서 현재 상태와 우선순위 확인, 재배 상세·기록으로 이동 |
| 재배 목록 | 재배 중 / 재배 종료 | 재배 건 등록, 품종·입고·위치·단계·수량·출하 목표 확인, 종료 이력 조회 |
| 영농일정 | 작업 예정 / 생육 조사·재확인 / 출하 예정 | 예정일·대상·담당자·내용 등록, 예정/기한 경과 확인, 실제 완료 기록 연결 |
| 통계 | 환경 / 생육 / 작업 / 출하·수량 | 기간·온실·품종·재배 건별 비교, 원자료로 이동 |
| 농장 설정 | 농장·온실·구역 / 설비·센서 / 품종·자재 / 작업·조사 기준 / 담당자·알림 | 반복 사용하는 기본정보와 기준 관리 |

우리 온실은 공간 중심의 요약, 재배 목록은 재배 건 중심의 운영이다. 한 온실에 서로 다른 시기·단계의 여러 재배 건이 있을 수 있다. 온실을 바꾸면 그 온실의 재배와 내부 환경을 함께 바꾸며 대표 센서가 어느 구역을 나타내는지 표시한다.

'재배 중/재배 종료'는 목록 필터다. 특정 생육 단계는 품목·농가별로 설정하며 상위 메뉴로 나열하지 않는다. 이미 종료된 재배는 정정·이력 조회가 가능하도록 보존한다.

계획·할 일의 원래 관리 위치는 영농일정이다. 우리 온실과 재배 상세에서는 같은 일정을 요약/필터해 보여준다. 일정 변경이나 완료를 메뉴별로 중복 저장하지 않는다. 일지 없이도 미래 작업을 계획할 수 있고, 계획 없이 실제 한 작업도 일지에 기록할 수 있다.

## 3. 재배 상세의 화면 내 탭

예시 대상: 'A동 · 호접란 3차'. 배치는 내부 추적 단위이며 화면 이름은 농가가 알아보기 쉬운 재배 건 명칭을 사용한다.

| 탭 | 포함할 내용 |
| --- | --- |
| 기본정보 | 품종·공급처·입고일/상태·화분/배지·현재 위치·단계·적용 기준·출하 목표 |
| 생육·환경 | 최근 생육 조사·잎/뿌리/꽃대/개화 이력·관련 구역 내부 환경·관찰/수신 시각 |
| 계획·일정 | 해당 재배 건의 작업·조사·재확인·출하 예정 |
| 출하·수량 | 입고·이동·폐기·출하 사건과 현재 잔량, 선별·보류 상태 |
| 기록이력 | 해당 재배 건으로 필터된 실제 일지·단계/위치 변경·후속 결과 |

상세 탭은 상위 메뉴가 아니다. 화면이 작은 경우 접을 수 있는 영역이나 별도 상세로 구성할 수 있다.

기본정보에서 현재 단계·위치·수량을 확인하되 변경 시 사건 날짜·대상·사유를 가진 기록을 만든다. 일지 이력과 같은 기록을 사용한다. 목표 출하와 실제 출하는 구분한다. 배치 이동 전후의 위치로 당시 환경을 연결하며 현재 위치의 센서값으로 과거 환경을 대체하지 않는다.

## 4. 영농일지의 화면과 기록 카테고리

영농일지는 하나의 조회 화면에 아래 유형을 필터로 제공한다. 유형마다 별도의 일지 저장소나 입력 페이지를 만들지 않는다.

- 기본 조회: 전체 일지.
- 보기 전환: 달력 / 목록. 보기 방식이며 별도 상위 메뉴가 아니다.
- 공통 조건: 날짜·온실/구역·재배 건·기록 유형, 필요시 담당자.
- 공통 버튼: 일지 쓰기.
- 계획을 함께 표시하는 경우 실제 기록과 색상·표기·상태를 구분한다.

| 기록 카테고리 | 포함할 내용 | 조건부 입력 |
| --- | --- | --- |
| 생육·관찰 | 잎·뿌리·꽃대·봉오리·개화 관찰, 정기 생육 측정, 확인된 단계 전환 | 조사 대상·범위·방법·단위·측정값·사진; 단계 변경 시 실제 적용일 |
| 관수·시비 | 실제 관수·급액·시비·관련 수질/배지 측정 | 대상·시각·양/단위·자재, 측정 시 시료/방법 |
| 재배작업 | 분갈이·유인·적심 등 해당 품목에서 실제 수행한 작업 | 대상·수량·시간·자재·담당자; 필요한 변경 사건 연결 |
| 병해충·이상 | 증상·발생 위치·영향 범위, 진단/검사, 방제·대응·후속 확인 | 발견 사실·확인 수준·조치·결과·재확인 일정 |
| 입고·이동 | 묘 입고·검수·재배 건 이동·분할 | 출발/도착 위치·실제 수량/단위·발생일·원래 재배 건 |
| 출하·폐기 | 실제 선별·출하·폐기·반품 | 수량/단위·규격·처리/판정일·사유; 재고 증감 처리 구분 |
| 시설·환경 | 설비 점검·고장·수리·설정 변경·직접 확인한 환경 이상 | 시설/구역·시각·관찰 사실·실제 조치·변경 전후 |
| 기타 | 위 유형에 속하지 않는 메모·사진 | 대상·날짜·내용; 재배 대상을 특정할 수 없는 농장 공통 메모 허용 |

한 번의 활동에서 관찰과 작업이 함께 발생할 수 있으므로 대표 유형과 연결 기록/항목으로 처리하고 같은 수행을 이중 집계하지 않는다. 영농일지 유형은 목적에 따라 선택하고 모든 항목을 모든 날 필수 입력으로 만들지 않는다.

정기 센서값 전체는 센서 수집 이력에 저장하고 환경 화면과 통계에서 조회한다. 센서 샘플마다 일지를 생성하지 않는다. 필요시 일지에 관련 시간대의 환경 이력을 연결한다.

새 재배 건은 마이영농에서 한 번 등록한다. 이때 실제 입고 사건도 함께 남길 수 있다. 이미 등록한 입고를 일지에 다시 입력하도록 요구하지 않는다. 입고/분갈이/이동처럼 여러 성격이 있는 사건은 연결 관계로 관리한다.

## 5. 통계의 내부 카테고리

| 카테고리 | 비교 내용 | 필요한 기준 |
| --- | --- | --- |
| 환경 | 주야간 추이·설정 범위 이탈 시간·구역별 차이 | 측정 위치·시간대·적용 목표·결측 처리 |
| 생육 | 같은 방식의 조사 추이·배치 간 편차·개화 시점 | 품종·단계·조사법·단위·표본/전수 구분 |
| 작업 | 실제 작업량·노동시간·계획 대비 수행 | 작업 단위·대상·부분/취소·중복 처리 |
| 출하·수량 | 목표 대비 실제 출하·규격 충족·폐기·잔량 | 분모·수량 단위·규격·집계 기간 |

비용·매출은 장부 연결 범위가 정해졌을 때 관련 분석을 추가한다. 이번 두 메뉴안은 재배 관련 구조이며 기존 장부 기능의 삭제·통합을 결정하지 않는다.

## 6. 메뉴·카테고리·필터·버튼의 구분

| 종류 | 예시 | 역할 |
| --- | --- | --- |
| 상위 메뉴 | 마이영농, 영농일지 | 큰 이용 목적 구분 |
| 하위 메뉴 | 우리 온실, 재배 목록, 영농일정, 통계, 농장 설정 | 기능 공간 구분 |
| 상세 탭 | 기본정보, 생육·환경, 계획·일정, 출하·수량, 기록이력 | 한 재배 건의 정보 분류 |
| 기록 카테고리 | 생육·관찰, 관수·시비, 재배작업 등 | 실제 기록 유형 구분 |
| 필터 | A동, 호접란 3차, 날짜, 재배 중/종료 | 같은 화면에서 조회 대상 제한 |
| 보기 전환 | 달력/목록 | 같은 기록의 표현 방식 |
| 행동 버튼 | 재배 등록, 일지 쓰기, 계획 추가, 완료 기록 | 생성·변경 실행 |

온실명·품종명·생육 단계는 대상 선택·필터이며 고정 상위 메뉴로 늘리지 않는다.

## 7. 대표 이용 흐름

- 현재 상태 확인: 마이영농 → 우리 온실 → A동 → 호접란 3차 → 생육·환경.
- 실제 기록: 마이영농 재배 상세의 기록하기 또는 영농일지의 일지 쓰기 → 같은 대상·시각·유형으로 저장.
- 다음 작업: 마이영농 → 영농일정 → 계획 추가 → 실제 수행 후 완료 내용 저장 → 일지와 같은 실적 연결.
- 정기 검토: 마이영농 → 통계 → 기간/재배 건 선택 → 원자료 조회 → 다음 계획 검토.
- 기준 변경: 마이영농 → 농장 설정 → 기준 변경 및 적용일 기록 → 배치별 적용 이력 보존.

상위 메뉴를 두 개로 단순화하면서 내부의 재배 대상·실제 기록·계획·설정 책임은 구분하는 구성이다.
