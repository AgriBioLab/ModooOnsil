# 출하 화면 개선 4개 항목 반영

기준: grades-v7 및 사용자 손그림 비교 후 승인한 개선 4개 항목. 출하방식, 등급 체계, 평균 등급, 금액 의미, 홈·재배일지 기능은 이번 변경 대상이 아니다.

## 변경

1. 출하 등록·정정에서 선택한 작기의 온실명·품목명·품종명을 읽기 전용 표로 표시한다. 작기를 바꾸면 요약도 갱신한다.
2. 등급 입력을 규격·수확일·금액 선택 영역에서 분리한다. 기존 공통 입력·표 스타일을 사용한다.
3. 여러 등급 입력 시 등급 합계·총출하량·차이를 입력 중에 표시한다. 수량과 출하 단위가 바뀌면 갱신하며 기존 저장 시 합계 검증을 유지한다.
4. 등급 미지정·단일 등급·여러 등급별 수량을 구분하고 비활성 입력은 저장에서 제외한다. 상세·목록은 단일 등급 또는 등급별 수량을 표시한다.

## 기존 기록 보존

- 저장 키·형식·등급 기준(특상·상·중)과 `producerManagementStore.js`는 변경하지 않았다. 잔량 계산과 정정·취소 이력 처리를 유지한다.
- 입력 방식은 기존 `grade`와 `gradeBreakdown`에서 판별하며 별도의 저장 필드를 추가하지 않는다.
- 기존의 비표준 등급은 기존 기록에서만 유지한다. 단일 등급과 등급별 수량이 함께 있던 기록은 정정 시 두 값을 보존하고, 화면은 수량 내역을 우선 표시한다.
- 사용자가 입력 방식을 바꾸어 저장하면 선택한 방식의 데이터만 반영한다. 저장 전 방식 전환은 초안을 보관하며 원기록을 변경하지 않는다.
- 규격·수확일·금액과 재배 단위가 다른 출하의 명시적 차감 재배수량은 기존 처리대로 유지한다.
