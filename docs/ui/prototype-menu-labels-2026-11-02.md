# 프로토타입 상위 메뉴 — 확정한 명사형 표기

> 이 문서는 이전 시안 이력입니다. 사용자 손그림과 후속 UI 합의를 반영한 현재 메뉴·CRUD·URL은 [화훼 영농관리 인계서](flower-management-crud-handoff-2026-11-02.md)를 따릅니다.

사용자가 제시한 다섯 구분을 유지하며, 대상과 내용을 드러내는 명사형 표기를 적용한다. 이전 두 메뉴 통합안과 행동형 명칭 검토를 거쳐 이번 대화에서 반영을 요청한 이름이다. 작성·추가·수정은 화면 안 버튼에 사용한다.

| 기존 구분 | 프로토타입 표기 | 연결 화면 |
| --- | --- | --- |
| 영농현황 | 온실별 현재 재배·환경 상태 | 메인 온실 선택·재배 상태·내부 환경 |
| 재배일지 | 날짜별 재배일지 | 기존 기록 목록, 내부 버튼으로 일지 작성 |
| 마이영농 | 농장·온실·재배 정보 | 농장 정보와 등록 온실 확인, 온실 기본정보 추가 |
| 통계·분석 | 기간별 생육·작업·출하 결과 비교 | 시안에서는 두 달의 저장된 일지 유형별 건수 비교 |
| 장부 | 농장 입금·출금 내역 | 월별 실제 입출금 내역 조회, 기록 추가로 연결 |

- 메뉴 순서는 위 표와 동일하게 적용했다. 피해보상 신청은 보조 영역에 유지했다.
- 재배일지와 장부는 기존 기록 조회를 기본 화면으로 두고 그 안에서 새 기록을 추가한다.
- 비교 화면은 입력된 일지 건수만 사용한다. 생육량·작업 효과·수익성을 예측하지 않는다. 기록이 없는 달은 '기록 없음'으로 표시하고 완료 취소 기록은 제외한다.
- 명칭 반영과 전체 기능 구현은 구분한다. 마이영농의 전체 재배 정보 편집과 통계의 생육·노동시간·출하 결과 비교는 이번 메뉴명 변경으로 추가 구현하지 않는다.
- 기존 시안 데이터의 기준일은 2026.11.01.로 유지한다. 변경일과 실제 데이터 기준일은 구분한다.
- 긴 메뉴명은 데스크톱의 5열 메뉴와 모바일 전체 메뉴에서 모두 표시한다. 본문 제목과 입력 화면 제목도 같은 용어를 사용한다.

반영 파일: producerWorkspaceHeader.html, producerMain.html, producerWorkspace.css, producerWorkspace.js 및 공유용 producer-main-prototype.html.

검증: JavaScript 구문 검사, 1440/1024/768/390/320px 화면의 가로 넘침·메뉴 잘림 확인, 일지/입출금 저장, 비교 월 변경, 온실 등록 진입, 모바일 메뉴 닫힘, 공유용 단일 HTML 동작 확인. 브라우저 스크립트 오류 없음.

## 전체 페이지 전환 — 2026.11.02.

다섯 상위 메뉴와 작성·등록·상세 화면은 공통 헤더 아래 전체 페이지로 표시한다. 모달과 배경 딤은 사용하지 않는다. 모바일 전체 메뉴도 배경 딤 없이 펼쳐진다.

| 메뉴 | 진입 URL |
| --- | --- |
| 온실별 현재 재배·환경 상태 | `producerMain.html` |
| 날짜별 재배일지 | `producerMain.html?view=journal` |
| 농장·온실·재배 정보 | `producerMain.html?view=profile` |
| 기간별 생육·작업·출하 결과 비교 | `producerMain.html?view=statistics` |
| 농장 입금·출금 내역 | `producerMain.html?view=ledger` |

공통 HTML을 유지하면서 URL별 페이지 내용을 전환한다. 직접 진입·새로고침·브라우저 뒤로가기·앞으로가기를 지원한다. 작성 취소와 '이전 화면'은 이전 화면으로 돌아가며 직접 진입 시 상위 화면으로 이동한다. 기존 브라우저 데모 저장소 `agribiolab-workspace-demo-v2`를 유지한다.

검증 스크립트: `tmp/fullpage/smoke.cjs`. 5개 메뉴 × 1440/1024/768/390/320px, 활성 메뉴, 페이지 제목, 가로 넘침, 모달·딤 부재, 일지·입출금 저장, 조회조건 유지, 작업 완료·취소, 온실 중복·등록, 공유용 파일 직접 열기를 확인했다. 실제 서버 인증·저장·센서 연계는 포함하지 않는다.
