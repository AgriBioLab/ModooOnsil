# 홈 화면 UI 및 조회 연결 검토

- 작업 브랜치: feat_homeUI
- 진입 화면: src/main/resources/static/home.html
- 현재 단계: 기존 sampleData.js의 DB 스냅샷 및 계정별 브라우저 저장값을 사용하는 UI. 서버 API·DB 쿼리는 새로 실행하거나 변경하지 않았다.
- 공통 KRDS CSS, 사이드바·헤더·푸터를 재사용한다. 로그인 및 index 진입 후 홈으로 이동한다.

## 화면 범위

진행 중인 작기 / 확인할 이슈 / 오늘의 기록 탭을 사용한다. 진행 중인 작기를 직접 선택하고 작기명·품목명·품종명을 강조한다. 온실명은 부가 정보로 표시하며, 선택한 작기의 일지 작성 화면으로 연결한다. 이슈·일지는 페이지당 4건이며 긴 목록은 영역 안에서 스크롤한다. 작은 화면에서는 카드가 세로로 배치되어 스크롤할 수 있다.

등록 온실·진행 작기는 보조 정보다. 미조치 이슈는 로그인 회원의 전체 작기에서 발생/조치중 상태만 포함한다. 종료된 작기의 미해결 이슈도 숨기지 않는다. 작기 현황의 이슈 수는 선택한 진행 작기에 한정한다.

오늘은 한국시간 기준 실제 날짜다. 오늘 기록이 없다고 과거 기록의 날짜를 바꾸지 않는다. 일지 없음은 작업 없음이 아니다. 현재 생육단계 업무가 정의되어 있지 않으므로 홈의 생육단계 및 최근 작업일은 표시하지 않는다. 환경값은 최신 측정 행의 온도·습도·CO2이며 측정시각을 함께 표시한다. NULL은 0으로 바꾸지 않는다. 정상/긴급 판정, 임의 재배 진행률, 출하·수확·매출·예정 작업 데이터를 추가하지 않는다.

## 업무리스트 쿼리 연결 및 추가 필요 사항

원본: https://docs.google.com/spreadsheets/d/1xe5y2MTOuJAD2PW2kTIe4EFNr0N2_JEtaS5UW8xgdcI/edit

| 화면 | 기존 쿼리 | DB 연결 시 보완 |
| --- | --- | --- |
| 농장명 | 회원 I5 내 정보 조회 | 로그인 회원 ID 사용 |
| 온실 선택 및 수 | 온실 I2 목록 조회 | 필터 없는 회원 범위; 페이징된 결과로 전체 건수를 계산하지 않음 |
| 진행 작기 | 작기계획 I2/I6 | 상태 정확 일치: 진행 |
| 최근 환경값 | 온실 환경 변화 H4 | 기존 최신 1건 쿼리 활용. planId 소유권 확인 필수 |
| 전체 미조치 이슈 | 온실 환경 이슈 I3/I5 | 작기·온실 JOIN과 회원 범위, 상태 IN ('발생','조치중'), 전체 건수와 페이지 조회 추가 |
| 오늘 일지·작업 건수 | 재배일지 I6/I15 | 회원 범위와 오늘 00:00 이상/다음날 00:00 미만 조건, 전체/완료/미완료 집계, 페이지 조회 |

**추가 업무 정의 필요:** 홈 농장 요약 조회, 회원 전체 미조치 이슈 조회, 오늘의 일지·작업 요약 조회. 기존 업무의 조회 결과를 조합한 읽기 전용 업무다. 새로운 테이블·컬럼은 필요하지 않다. 최신 환경값은 작기 선택 후 해당 작기 1건만 가져오므로 모든 작기의 최신값 일괄 조회는 1차 범위에 필요하지 않다.

**추가/보완 SQL 필요:** 전체 요약 집계, 미조치 이슈 회원 범위·페이지 조회, 오늘 일지·작업 집계·페이지 조회. 상세 목록을 매번 전량 다운로드해 합산하지 않도록 서버 서비스에서 구성한다. 여러 1:N 테이블을 한 번에 JOIN해 건수가 증폭되지 않도록 각각 집계한다. 현재 UI는 기존 데이터 배열을 이용하며 이 SQL을 구현한 것은 아니다.

## DB 연동 전 확인

- 업무시트 일부의 '진행중'과 ERD/현재 코드의 '진행'이 다르다. 현재 UI는 '진행'을 사용한다.
- ERD와 최신 시트에 deleted_at이 있으나 sql/sprint2/DDL.sql에는 없다. 실제 DB 스키마를 확인하고 논리 삭제 제외를 일관되게 적용해야 한다. UI는 데이터에 삭제 표시가 있으면 제외한다.
- 샘플 데이터의 cycleId/stageId 등은 기존 UI 모델 이름이다. DB의 plan_id/growth_stage 등을 연동 시 변환해야 하며 새 DB 필드가 아니다.
- 현재 샘플 데이터 및 localStorage 인증 흐름을 재사용한 UI이므로 운영 DB 연동/서버 인증 구현 완료를 의미하지 않는다.

## 확인 결과

JavaScript 구문 검사, 홈의 CSS/JS 파일 참조, 샘플 회원 3명의 화면 렌더·회원 범위 분리·이슈 탭 전환, 신규 회원 빈 상태를 검사했다. 브라우저 도구가 file:// 프로토콜을 차단해 실제 화면 크기별 시각 검증은 수행하지 못했다.

## 작기 중심 개편 검증
진행 작기를 회원별로 순회해 선택한 작기의 일지 작성 링크, 품목·품종 표시 및 생육단계 제거를 코드 실행으로 확인했다. 일지 등록 화면은 cycleId가 등록 가능한 작기일 때만 미리 선택한다. 추가 테이블·필드·쿼리는 이번 수정에서 필요하지 않으며, 최근 일지 조회 보완 요구는 제거했다.

## 오늘 작업 내용 카드
- 오른쪽 카드 기본 탭: 선택 작기의 오늘 작업 내용. 실제 작업일(worked_at)이 한국시간 오늘인 일지의 작업명, 작업시간, 유형, 상태, 내용을 표시한다. 등록일(created_at)이 오늘인 과거 일지까지 포함하는 의미는 아니다.
- 업무리스트 재배일지 I6(작업일 조회), I14(일지 작업내용 조회)를 조합한다. 기존 필드만 사용하며 새로운 ERD 필드는 없다. DB 연동 시 회원/작기/오늘 범위 조회 뒤 작업내용 조회를 재사용한다. 성능상 필요하면 동일 조건의 일괄 JOIN 조회로 보완한다.
- 최근 환경 측정은 작기·오늘 작업 카드 아래 별도의 접이식 보조 영역으로 분리한다. 기본은 접힌 상태이며 펼치면 최신 측정일시 및 온도/습도/CO2를 표시한다. 전체 측정 이력은 기존 환경 변화 화면으로 연결한다.
- 작업이 많으면 카드 내부 스크롤을 사용한다. 테스트는 메모리에서만 오늘 작업을 생성해 날짜 필터와 빈 상태를 검증했으며 실제 시연 데이터는 변경하지 않았다.

- 일지 우선 배치: 오늘 작업 내용은 탭 없이 항상 표시한다. 온실명은 작기명 바로 아래에 배치한다. 선택 작기 이슈 요약 및 이슈 버튼은 중복을 줄이기 위해 제거하고 전체 작기 이슈 탭을 유지한다. 데이터·쿼리 변경은 없다.

## 최종 홈 탐색 정리
- 상단 탭은 진행 중인 작기 / 환경 측정 / 전체 작기 이슈 순서다. 첫 화면은 진행 중인 작기와 오늘 작업 내용을 유지한다.
- 오늘의 기록 탭은 중복을 줄이기 위해 제거했다. 날짜의 한국시간 문구만 삭제하고 날짜 계산은 Asia/Seoul을 유지한다.
- 페이지 상단의 작성 버튼은 제거하고 오늘 작업 내용 카드의 작기별 일지 목록/작성 버튼만 유지한다.
- 환경 측정은 접이식 영역 대신 상단의 별도 탭으로 이동했다. 작기 선택은 두 탭에서 유지된다. 새 데이터/쿼리는 추가하지 않았다.
