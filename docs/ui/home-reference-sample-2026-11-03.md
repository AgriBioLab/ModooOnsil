# 참고 손그림 기반 홈 샘플

사용자가 필요한 샘플 데이터를 하드코딩으로 표시하는 방식을 요청해 홈의 기본 화면을 손그림 배치에 맞추었다.

- 상단 4개 요약: 재배 중인 품종·출하 예정·알림/주의·오늘 등록 일지.
- 중단: 왼쪽 월 수입·출하 건수, 오른쪽 선택 온실 체크사항과 더보기.
- 하단: A/B/C동 공통 탭, 왼쪽 품목·품종·생육단계·진행률·생육지표·예상 날짜, 오른쪽 온도·습도·CO₂·광도·측정 시각·주의 문구.
- 768px 이상에서 재배와 환경을 나란히, 모바일에서는 세로로 배치한다. 공통 헤더·사이드·서체·색·버튼은 유지한다. 손그림의 정보 구조를 우선하며 홈은 세로 스크롤을 허용한다.

## 데이터와 동작

샘플은 `src/main/webapp/resources/js/producerHomeSample.js`에 모았다. 기준일은 2026-11-03이며 이후 실제 수치로 자동 갱신하지 않는다. 수입·진행률·개화율·센서·주의 문구 등은 화면 확인용 예시이며 실제 집계·예측·실시간 센서값이 아니다. 홈 상단에 샘플 데이터와 기준일을 표시한다.

온실 탭은 선택한 온실의 체크사항·재배·환경을 함께 전환하며 방향키·Home·End와 URL·새로고침을 지원한다. 체크박스는 저장하지 않는 화면 미리보기다. 샘플 데이터를 브라우저 저장소에 삽입하거나 기존 기록을 변경하지 않는다.

기존 홈은 ‘저장 기록 현황 보기’(`view=home&source=records`)로 유지한다. 기존 `farmId`·`houseId` 조회 URL도 저장 기록을 표시한다. 검색·초기화 후에도 저장 기록 모드를 유지한다. 재배·출하 CRUD와 잔량 계산은 변경하지 않았다.
