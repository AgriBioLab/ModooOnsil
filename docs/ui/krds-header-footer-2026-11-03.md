# KRDS 참고 헤더·푸터 — 2026.11.03. v17

## 가상 운영기관 추가 — v18

사용자가 확정된 운영정보가 없으며 가상 데이터로 넣도록 요청했다. `producerServiceInfo.js`의 공통 정보에서 푸터·개인정보 처리방침 화면이 같은 기관명과 연락처를 조회한다.

- 기관: 한국화훼영농지원센터 (가상 기관)
- 주소: 가상특별시 화훼구 영농로 100, 화훼지원관 3층
- 전화: 000-0000-0000
- 이메일: support@flower-farm.example
- 운영시간: 평일 09:00~18:00, 주말·공휴일 휴무
- 개인정보 처리방침: `?view=privacy`. 가상 기관의 UI 확인용 문서임을 표시하며 실제 운영 방침으로 안내하지 않는다. 실제 연락처로 연결하는 전화·이메일 액션은 제공하지 않는다.

정책 화면은 별도 서비스 안내 메뉴로 조회하며 업무 저장 데이터와 분리한다. 푸터의 사이트맵 위치는 유지한다. `fictional-footer-check.cjs`에서 공통 정보 일치·방침 링크·6개 폭·원본 미변경·단일 HTML·스크립트 오류 없음을 확인했다. v18이 아래의 기존 ‘확정 정보 대기’ 기록보다 우선한다.

[가상 정보가 추가된 푸터](fictional-footer-1244-2026-11-03.png), [모바일](fictional-footer-390-2026-11-03.png).

KRDS 공식 [헤더](https://www.krds.go.kr/html/site/component/component_02_03.html)와 [푸터](https://www.krds.go.kr/html/site/component/component_02_04.html)의 정보 위계·탐색·반응형 원칙을 생산자 업무 화면에 적용했다. 전체 메뉴(사이트맵)는 데스크톱·모바일 헤더에서 제거하고 푸터로 이동했다.

실행 화면: `src/main/webapp/view/producerMain.html?v=krds-chrome-v17-20261103&view=cycles`

## 헤더

- 상단 유틸리티: 사용자명 → 내 정보 → 로그아웃. 항목 사이 구분선을 제공한다.
- 서비스 아이덴티티: 기존 잎 아이콘·서비스명과 영농 기록 설명을 별도 행으로 표시한다. 로고는 홈으로 이동한다.
- 주요 메뉴: 홈·영농현황 / 재배관리 / 온실관리 / 기간별 비교·통계 / 마이페이지의 기존 분류와 목적지를 유지한다.
- 모바일: 서비스명과 메뉴 버튼을 제공하며 내 정보·로그아웃과 주요 탐색은 메뉴 안에서 이용한다. 작은 화면에서는 가로 주요 메뉴를 중복 표시하지 않는다.
- 본문 건너뛰기, 초점 표시, 메뉴의 키보드 접근과 Escape 닫기를 유지한다.

## 푸터

- 서비스 로고·설명 → 주요 메뉴 바로가기 → 전체 메뉴(사이트맵)·하단 표기의 순서다.
- 주요 메뉴 바로가기는 헤더와 같은 이름·목적지를 사용한다.
- 전체 메뉴는 푸터의 별도 유틸리티 링크이며 기존 8개 영역·45개 메뉴와 대상 선택 흐름으로 연결한다.
- 짧은 화면은 푸터가 뷰포트 아래쪽에 놓이고, 긴 화면은 본문 뒤에 자연스럽게 이어진다. 본문을 덮는 고정 푸터를 사용하지 않는다.
- 작은 화면에서는 같은 정보 순서를 유지하며 세로 배치한다.

운영기관명·대표 연락처·개인정보 처리방침 URL은 사용자에게 확인을 요청했다. 현재 확정 정보가 없어 기관·연락처·정책 내용을 만들거나 무효 링크를 넣지 않았다. 서비스가 실제로 정부 운영임을 확인한 것은 아니므로 공식 정부 배너·정부 상징·접근성 인증 마크도 추가하지 않았다. KRDS 참고 적용과 전체 준수·인증을 구분한다.

## 변경 파일·유지 범위

- `producerWorkspaceHeader.html`: 공통 헤더 구성, 헤더 사이트맵 링크 제거, 모바일 메뉴 라벨.
- `producerMain.html`: 공통 푸터와 전용 스타일 로드.
- `producerServiceChrome.css`: 기존 업무 화면과 분리한 헤더·푸터 스타일.
- `build-producer-previews.py`: 공유용 단일 HTML에 같은 스타일·구조를 포함.

회원·농장·온실·작기·일지·수량·출하 데이터, ID 관계, 등급·잔량 계산과 등록·수정 로직은 변경하지 않았다. 생산자 가입 및 품질담당자 화면의 별도 셸은 이번 변경 대상이 아니다. 기존 컨플루언스 캡처는 v16 당시 기록으로 유지한다.
