# 작기 상세 가독성·위계 정리

2026-11-03 / v13

## 표시 순서

1. 작기명을 H1으로 표시하고 ‘작기 상세’는 보조 제목으로 낮춘다. 목록 복귀 버튼을 제공한다.
2. 진행·종료 상태와 생육단계를 분리하고 온실·품목·품종·재배기간을 표시한다.
3. 현재 재배수량·목표 출하량·출하 예정기간을 한 묶음으로 요약한다.
4. 일지 작성·출하 등록을 공통 작업 영역에 두어 어느 탭에서도 사용할 수 있게 한다. 생육·환경 비교는 보조 링크로 둔다.
5. 기본정보·재배일지·출하 이력·수량 변경 탭으로 세부 내용을 나눈다.
6. 수정·수량 변경·작기 종료·삭제는 별도의 ‘작기 관리’ 펼침 영역에 둔다. 삭제는 위험 행동 스타일로 구분한다.

## 세부 정보

- 기본정보는 날짜·시작 수량·재배면적·묘 구입처·실제 수확일을 의미별로 읽도록 배치했다.
- 메모와 종료 결과는 별도 섹션에서 전체 폭으로 줄바꿈한다. 긴 문장을 반쪽 표 셀에 넣거나 잘라내지 않는다.
- 이전 데이터의 자동 생성 이관 안내 문구는 조회에서만 제외한다. 사용자 메모와 저장 원본은 유지하며 시작일 확인 필요 상태는 따로 표시한다.
- 수량 미등록은 필요한 정보와 ‘수량 등록’ 행동으로 안내한다.
- 빈 이력은 ‘등록된 재배일지/출하/수량 변경 기록이 없습니다’로 구분한다.
- 모바일에서는 요약을 항목·값 행으로, 기본정보를 한 열로 표시한다. 공통 헤더·사이드·색·입력·버튼 톤은 유지한다.

## 유지한 동작

저장소·수량 계산·기존 URL·연결 관계는 변경하지 않았다. 종료 작기의 출하 등록·수량 변경 제한, 일지·출하·환경 비교·수정·종료·삭제의 기존 진입을 유지한다. 새 `tab=basic/journal/shipments/quantity` URL로 상세 탭 직접 진입도 가능하다.
