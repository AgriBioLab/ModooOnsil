## 후속 반영: 재배·환경 통합

공통 온실 선택 아래 ‘우리 온실’ 한 패널에서 품목·품종·현재 단계·날짜와 그 온실의 대표 센서 환경을 함께 확인합니다. ‘전체 비교’는 모달로 이동했습니다. 비교 중 동을 선택하면 창이 닫히고 메인의 재배·환경이 함께 바뀝니다. `greenhouse-unified-panel.png`에서 통합 패널을 확인할 수 있습니다.

베드 선택과 대표 센서의 범위를 구분했습니다. 메인은 선택 온실의 대표값을 유지하며, 베드별 센서는 상세에서 확인합니다. 동일한 공통 탭이 재배 영역과 환경 영역을 포함하는 패널을 제어합니다.

## 적용한 가정

- 날짜·작업·생육 단계·온도·날씨·금액은 **2026.11.01. 기준 시연 예시**입니다.
- 원본 엑셀의 전체 온실 수를 운영 데이터로 복제하지 않고, 메인에는 A·B·C동과 각 2개 베드의 예시를 구성했습니다.
- 재배 진행률 %는 사용하지 않았습니다. 농가가 기록한 현재 단계와 다음 출하 계획을 분리해 표시합니다. 단계 이름 역시 실제 농가 기준으로 확정해야 하는 예시입니다.
- A동 장미는 기존 식재를 유지하며 다음 출하를 계획하는 예시입니다. 정식 경과일과 다음 출하 D-day는 서로 다른 지표입니다.
- 메인의 환경은 공통 탭으로 선택한 온실의 지정 대표 센서값을 표시하며 평균을 임의 계산하지 않습니다. 모든 동을 동시에 볼 때는 전체 비교를 엽니다. 온실을 선택하면 재배현황과 구역 상세가 연결됩니다. 베드 선택은 베드별 재배·상세 정보에 적용되며 온실 대표값은 유지합니다. 할 일·월 장부는 전체 농장 범위를 유지합니다. 외부 예보는 수원시 농장의 보조 정보입니다.
- 차광 운전 일정은 설비 연계 전 상태로 표시하고, 수동 작업의 완료 체크와 구분합니다.
- 지역 주의정보 미연계를 ‘안전’이나 ‘주의정보 없음’으로 표시하지 않았습니다.
- 월 장부는 입출금일과 입력된 데모 기록 기준입니다. 차액은 순이익·예상 매출과 구분합니다. 기록이 없는 달은 0원 대신 ‘기록 없음’으로 표시합니다.

## 클릭할 수 있는 동작

1. 환경 카드나 A/B/C동 탭으로 온실을 선택하면 재배현황과 선택 구역 상세가 연결됩니다. 전체 비교 모달에서 각 온실의 대표 센서값을 동시에 비교할 수 있습니다. 베드를 바꾸면 품종·단계·날짜·D-day·최근 확인일과 상세 베드 환경이 갱신됩니다. 현재값은 측정 예시이며 미래 실내 예보를 만들어 표시하지 않습니다. 미등록 온실의 환경값은 미수신으로 표시합니다.
2. 작업 체크를 누르면 완료 기록 모달이 열립니다. 실제 수행 내용을 저장해야 완료됩니다. 취소하면 완료되지 않습니다.
3. 완료 내용은 영농일기에 함께 저장됩니다. 완료 표시 취소 시 기존 일기에는 취소 이력이 남습니다.
4. 영농일기 직접 작성은 선택한 온실·베드를 기본값으로 가져옵니다.
5. 오늘 할 일 추가·전체 보기, 시안 내 신규 온실 추가를 제공합니다. 신규 온실의 날짜·센서값은 미등록입니다.
6. 월을 바꾸면 해당 입출금일의 금액을 집계합니다. 금액 카드로 원본 내역을 보고, 새 입출금을 저장하면 해당 월로 이동합니다.
7. 내부 환경 상세, 마이영농·주의정보·외부 날씨·피해보상 안내는 상세 모달로 확인합니다.

데이터는 브라우저의 `agribiolab-workspace-demo-v2` 키에 저장합니다. 기존 시안의 v1 저장소와 구분했으며 실제 계정·서버 DB·외부 API·설비 제어는 연결하지 않았습니다.
