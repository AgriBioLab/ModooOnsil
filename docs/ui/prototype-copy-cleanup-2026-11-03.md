# 프로토타입 화면 문구·로그인 메뉴 정리

사용자 브라우저 코멘트 5개와 ‘샘플 표기 제거’ 요청을 반영했다. 이전 문서의 샘플 배지·검토용 안내 노출 설명보다 이 기준이 우선한다.

## 반영

- PC 헤더·모바일 메뉴의 사용자명에서 ‘검토용’을 제거했다.
- 로그인 후 공통 헤더·전체 메뉴에서 용어 안내·회원가입·농업경영체 인증 링크를 제거했다. 용어 안내 URL은 유지하며 화면 내 생육조사 안내의 링크도 노출하지 않는다.
- 농업경영체 인증을 마이페이지 ‘내 정보’ 내부의 인증 상태·정보 입력 영역에 배치했다. 회원가입의 인증 단계도 유지한다. 로그인 전 처음 화면의 가입 진입은 유지한다.
- 이전 시안 데이터 이관 안내 배너를 제거했다. 데이터 이관과 원본 보존, 수량 미등록 검증은 유지한다.
- 홈·온실 상세의 샘플 배지, 샘플 출처 열·안내, 시안·브라우저 저장 설명을 제거했다. 온실 정보·환경 수치·측정일·상태·기능은 유지한다.
- 공통 입력 안내는 ‘필수 입력’만 표시하며 정상 처리 안내도 사용자 행동 중심으로 정리했다. 실제 오류·미등록 값·입력 검증은 유지한다.
- 회원가입의 시안 배너·개발 설명·참고 링크와 로그인 전 가입 링크의 ‘화면 시안’ 표기를 정리했다. 동의 검증·비밀번호 검증과 입력값 비저장 처리는 유지한다.
- 공유용 HTML도 재생성했다. 헤더 버전 변경에 관계없이 공통 헤더를 포함하도록 빌더를 수정했다.

## 구현 범위

표시 문구와 진입 구조만 변경했다. 기존 화면 전용 고정 데이터, 저장 키·형식·실제 온실 CRUD·잔량 계산은 유지한다. 인증·회원가입·비밀번호의 실제 서버 API를 새로 구현한 것은 아니다. 미연결 인증 요청은 완료 상태를 만들지 않고 진행 불가 상태를 표시하며 입력값을 전송·저장하지 않는다.
