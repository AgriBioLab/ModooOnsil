# 화훼농민용 2차 서비스 UI 시안

## 출하의 작기 생산정보·목표 연결 — 2026.11.03.

출하에서 작기를 선택하면 생산정보·수량 현황·출하 목표를 같은 원본에서 조회합니다. 목표 거래처·규격은 신규 입력 초안으로 제공하며 직접 입력과 기존 정정값을 보존합니다. 등록/정정 후 예상 잔량·실적, 상세·목록의 생산 작기 연결을 추가했고 기존 등급·차감·취소 규칙은 유지합니다. [v23 원본·입력·검증 기준](shipment-production-source-2026-11-03.md)을 현재 우선 기준으로 사용합니다.

## 작기 목표·데일리 계획 — 2026.11.03.

목표 출하·단계별 일정·일일 작업·실제 일지를 같은 작기로 연결했습니다. 오늘·주간·지연 작업, 단계·작업 등록/수정, 진행·완료 실적, 조사 주기·환경 범위 가이드, 목표·일정 변경 이력을 제공합니다. 홈·온실·일지 통합조회·전체 메뉴도 연결했으며 계획량은 재고를 차감하지 않습니다. [v22 설계·데이터·보존·검증](cycle-planning-2026-11-03.md)을 현재 우선 기준으로 사용합니다.

## 미등록 항목 보충 — 2026.11.03.

회원·농장·온실·작기·재배일지·센서·출하의 빈 부가정보를 공통 예시값으로 보충했습니다. 수행하지 않은 작업과 수확 전 상태를 구분하고 기존 입력·0값·수량 계산을 보존합니다. 일지 첨부 참고 이미지와 상세 항목도 표시합니다. [v21 보충·보존 기준](prototype-common-data-2026-11-03.md)을 현재 우선 기준으로 사용합니다.

## 일반 화면의 공통 예시 데이터 — 2026.11.03.

전체 작업을 업무·데이터 구조 검토용 UI 프로토타입으로 정리했습니다. 별도 체험 모드 없이 일반 화면에 수기 일지·15개 센서 항목·장비·자동 관수/차광 완료·실패 결과를 같은 ID로 연결합니다. 기존 기록·출하·잔량 계산은 유지하며 [공통 데이터·보존·검증 기준](prototype-common-data-2026-11-03.md)이 현재 우선 기준입니다.

## 재배일지·센서 연결 구체화 — 2026.11.03.

일지·센서 통합조회와 센서 관측 원자료 화면을 추가했습니다. 같은 작기·온실·날짜의 수기 작업과 관측 요약을 함께 보고, 출처·단위·관측/수신 시각·집계 제외를 확인합니다. 실제 수신 API·제어 실행 로그는 미연동이며 [현황·데이터 흐름·연동 필요 항목](journal-sensor-workflow-2026-11-03.md)에 구분했습니다. 업무 사이트맵은 47개 메뉴입니다.

## KRDS 참고 헤더·푸터 — 2026.11.03.

서비스 로고·사용자 유틸리티·주요 메뉴를 구분하고, 서비스 정보·바로가기·전체 메뉴를 담은 푸터를 추가했습니다. 사이트맵 진입은 데스크톱·모바일 헤더에서 푸터로 이동했습니다. 이후 사용자 요청으로 가상 기관·주소·연락처와 개인정보 처리방침 화면을 추가했습니다(v18). [적용 범위·출처·검증](krds-header-footer-2026-11-03.md)을 참고하세요.

## 업무별 상세 사이트맵 — 2026.11.03.

첨부 참고 구조에 맞춰 업무 영역→기능 묶음→화면·작업의 3단계 전체 메뉴를 추가했습니다. 8개 영역·45개 메뉴를 검색하고, 온실 환경·수량 변경처럼 ID가 필요한 기능은 대상을 선택한 뒤 기존 화면·탭으로 이동합니다. 헤더의 전체 메뉴에서 진입합니다. [전체 구조·목적지·검증](domain-sitemap-2026-11-03.md)을 참고하세요.

## 공통 데이터·작기 검색·페이지 이동 — 2026.11.03.

회원→농장→온실→작기→일지·수량변경·출하를 같은 저장 원본으로 연결했습니다. 작기 검색 네 항목은 기본 노출하고 품목·품종·생육단계를 별도 열로 표시합니다. 주요 목록의 연속 번호·페이지 이동·표시 개수와 내 정보 우측 로그아웃을 추가했습니다. [연결 구조·명칭 기준·검증·인증 연결 범위](common-workspace-data-2026-11-03.md)를 현재 기준으로 사용합니다.

## 작기 데이터 연결 통일 — 2026.11.03.

작기의 전체 입력 항목을 등록·수정·상세에서 관리하고, 목록·홈·온실·일지·출하는 같은 작기 ID의 원본을 참조합니다. 홈의 생육 요약도 입력·조회에 연결했으며, 종료 작기나 잘못된 ID가 다른 작기로 바뀌지 않도록 정리했습니다. 기존 원본·수량 계산·등급 체계를 유지합니다. [전체 항목 매핑·검증](cycle-data-parity-2026-11-03.md)을 현재 기준으로 사용합니다.

## 작기 상세 정보 위계 — 2026.11.03.

작기명 → 상태·온실·재배기간 → 수량·출하 요약 → 주요 작업 → 상세 탭 → 관리 작업 순서로 정리했습니다. 메모와 종료 결과는 전체 폭의 별도 섹션이며 이전 자료의 자동 생성 안내는 원본 변경 없이 조회에서만 정리합니다. [변경 범위·검증](cycle-detail-hierarchy-2026-11-03.md)을 참고하세요.

## 온실·작기 연결 흐름 — 2026.11.03.

온실은 시설정보, 작기는 독립 등록으로 역할을 구분했습니다. 작기를 등록하면 선택 온실과 홈에 동일한 정보가 반영됩니다. 온실에서의 작기 등록은 보조 동선이며 저장·취소 시 해당 온실로 복귀합니다. 별도 고정 온실·작기 화면은 공통 저장 기록으로 통합했습니다. 기존 저장 데이터와 수량 계산을 유지하며 [연결 구조·검증](house-cycle-flow-2026-11-03.md)을 현재 기준으로 사용합니다.

## 화면 문구·로그인 메뉴 정리 — 2026.11.03.

사용자 요청에 따라 샘플·검토용·시안 설명과 이관 안내 배너를 화면에서 제거했습니다. 로그인 후 헤더·모바일 메뉴는 사용자명·내 정보 중심으로 정리하고, 인증은 내 정보와 가입 단계 내부로 이동했습니다. 데이터·CRUD·잔량 계산은 유지합니다. 아래 이전 문서의 배지·가입/용어/인증 링크 노출보다 [이번 표시 기준](prototype-copy-cleanup-2026-11-03.md)이 우선합니다.

## 온실 상세 손그림·샘플 — 2026.11.03.

온실명을 포함한 재배·내외부 환경 요약과 ‘온실 정보 / 환경 데이터’ 탭을 추가했습니다. 목록에서 A/B/C동 샘플로 진입할 수 있고, 등록 온실도 같은 배치에서 실제 정보 수정·관측기록 조회를 유지합니다. 미등록 항목은 샘플로 구분하며 실제 저장 데이터에 삽입하지 않습니다. [변경 범위·검증](greenhouse-reference-2026-11-03.md)을 참고하세요.

## 홈 손그림 배치·하드코딩 샘플 — 2026.11.03.

기본 홈을 상단 4개 요약 → 월 현황·체크사항 → 온실 탭 → 재배정보·내부환경의 손그림 구조로 반영했습니다. 고정 샘플은 `producerHomeSample.js`에 모으고 화면에 샘플과 기준일을 표시합니다. 기존 홈은 ‘저장 기록 현황 보기’로 유지하며 데이터·잔량 계산은 변경하지 않았습니다. 홈 배치는 아래 이전 ‘2열 표 미리보기·첫 뷰포트 압축’보다 [이번 홈 기준](home-reference-sample-2026-11-03.md)이 우선합니다.

## 출하 화면 개선 4개 항목 — 2026.11.03.

승인된 작기 요약, 등급별 수량 분리, 실시간 합계·차이, 단일/여러 등급 입력 구분을 반영했습니다. 상세·목록과 공유용 단일 HTML에도 연결했습니다. 저장 형식·등급 체계·잔량 계산을 유지하며, 기존 기록 보존과 등록·정정·취소 및 폭별 검증을 완료했습니다. [변경 범위·검증 기록](shipment-improvements-2026-11-03.md)을 참고하세요.
