# 온실과 작기 등록·조회 흐름 반영

상태: 구현 완료 / 2026-11-03 / v12

## 역할과 등록 동선

- 온실은 시설정보를 관리한다. 작기가 없어도 등록·사용할 수 있다.
- 작기는 작기관리에서 등록하며 등록된 사용 중 온실을 선택한다. 저장 후 작기 상세로 이동한다.
- 온실 상세의 ‘작기 등록’은 보조 동선이다. 온실을 미리 선택하고, 저장하면 선택한 온실 상세로 돌아와 생성한 작기를 표시한다. 취소하면 시작한 온실 상세로 돌아온다.
- 온실 등록 후 작기 등록을 강제하지 않는다. 작기가 없으면 ‘진행 중인 작기 없음’과 등록 버튼을 표시한다.

## 데이터 연결

- 기존 `cycles.houseId → houses.id`를 공통 원본으로 사용한다. 품목·품종·생육단계·기간을 온실에 복사 저장하지 않는다.
- 온실 상세에는 작기명·품목/품종·생육단계·재배기간·상세보기만 요약한다. 진행 작기가 여러 개면 선택하고, 종료 작기는 이력으로 확인한다.
- 홈의 온실 탭도 등록 온실을 읽고 선택한 작기의 정보·현재 재배수량을 조회한다. 작기 등록·수정·종료와 출하·취소 결과가 동일하게 반영된다.
- 온실명·시설정보·관측값을 별도 화면 데이터로 덮어쓰지 않는다. 신규 온실의 미등록 시설값과 미수신 환경값을 구분한다.
- 다른 탭에서 저장한 내용은 미저장 입력이 없는 화면에서 갱신한다. 미저장 입력 보호와 기존 수량 검증을 유지한다.

## 초기 데이터·호환

- A/B/C동 시설과 A동 작기·환경 기록은 공통 저장소의 초기 데이터에 포함한다. 이미 저장된 v3 또는 이전 데이터에는 삽입하거나 초기화하지 않는다.
- 예전 `sampleHouse=A` URL은 이름이 일치하는 등록 온실로 연결한다. 해당 온실이 없으면 목록으로 이동할 수 있게 한다. 별도 메모리 온실은 만들지 않는다.
- `producerHomeSample.js`는 알림·월 수입·체크사항의 보조 표시만 유지한다. 이 항목의 실제 집계·업무 등록은 이번 범위가 아니다. 품종 수·일지 수·출하 건수와 온실·작기·환경·잔량은 공통 기록을 조회한다.
- 저장 키와 기존 기록 구조·잔량 계산·출하 정정/취소 검증은 유지한다. 신규 작기의 온실 선택은 사용 중 시설로 제한하고, 과거 작기 편집은 기존 연결을 보존한다.
- URL의 복귀 정보는 저장하지 않는다.
