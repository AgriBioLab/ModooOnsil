서비스 이용과 기록 관리

화훼농민은 본인이 관리 권한을 가진 농장의 재배·작업·출하 기록을 작성하고 확인합니다. 실제 관찰·수행한 사실과 예정 사항을 구분해 기록합니다.

계정과 농장 접근 권한

개인별 계정 사용을 기본안으로 합니다. 다른 사람의 농장 기록 열람과 수정은 별도의 권한 부여가 필요합니다. 직원 초대와 농장 대표 변경 절차는 운영정책에서 정합니다.

외부 기관 제출과 데이터 이용

회원가입 자체로 농장 기록의 외부 제공이나 피해보상 신청 제출이 승인되지는 않습니다. 해당 기능을 이용할 때 대상과 제공 범위를 별도로 확인합니다.

확정할 내용: 운영기관·문의처, 가입/탈퇴, 기록 보관·반환, 이용 제한·이의제기, 약관 변경 절차.
