# 작기 데이터 연결 통일 — 2026.11.03.

같은 작기 ID의 원본 기록을 등록·수정·목록·상세·홈·온실·재배일지·출하에서 참조한다. 서로 다른 작기의 값을 동일한 값으로 덮어쓰거나, 기존 저장소를 초기화하지 않는다. 화면별 표시 범위는 유지하고 해당 화면에 표시하는 값의 출처를 통일한다.

실행 화면: `src/main/webapp/view/producerMain.html?v=cycle-data-v14-20261103&view=cycles`

## 원본과 연결

- 저장 원본: `agribiolab-producer-management-v3`의 `cycles`.
- 시설 연결: `cycles.houseId` → `houses.id` → `farms.id`. 온실에 품목·품종을 중복 저장하지 않는다.
- 일지·출하·수량 변경: 각 기록의 `cycleId` → `cycles.id`.
- `producerManagement.js`의 `cycleData()`가 공통 표시값을 만들고 `cycleReference()`가 일지·출하의 연결 작기 정보를 표시한다.
- 환경 기록은 `houseId`로 연결한다. 작기에 측정값을 복사하거나 결측을 0으로 만들지 않는다.

## 입력·수정·조회 항목 대조

진행 작기의 21개 항목과 종료일·종료 결과 2개를 대조했다. 내부 `id`, `quantityPending` 및 기존 추가 속성도 유지한다.

| 저장 항목 | 입력·수정 | 조회·연결 |
| --- | --- | --- |
| `name` 작기명 | 기본정보 | 목록·상세·홈·온실·일지·출하·비교에서 같은 ID로 조회 |
| `houseId` 재배 온실 | 기본정보 | 시설 원본의 농장·온실명, 홈·온실의 작기 선택 |
| `crop` 품목 | 기본정보 | 목록·상세·홈·온실·일지·출하 연결 정보 |
| `variety` 품종 | 기본정보 | 위와 동일 |
| `stage` 생육단계 | 기본정보 | 위와 동일, 진행·종료 상태와 분리 |
| `start` 재배 시작일 | 기본정보 | 상세·목록·홈·온실·일지·출하의 재배기간, 기록 날짜 검증 |

| `endDate` 종료일 | 위와 동일 | 상세 종료 결과, 목록·홈·온실·연결 작기의 재배기간 |
| `endNote` 종료 결과 | 위와 동일 | 상세 종료 결과 |
| `note` 재배 메모 | 위와 동일 | 상세 메모, 줄바꿈 유지 |
| `supplier` 묘 구입처 | 선택 입력 영역 | 상세 기본정보 |

| `flowerStalks` 평균 꽃대 수 | 위와 동일 | 상세·홈, 소수·0·미입력 구분 |
| `flowering` 평균 개화율 | 위와 동일 | 상세·홈, 0~100 및 미입력 구분 |
| `color` 화색 메모 | 위와 동일 | 상세·홈 |

홈에만 표시되던 생육 요약 4개를 등록·수정·상세에 연결했다. 이 값은 작기의 입력된 요약값이며 일지의 개체별 생육조사 원자료를 자동 평균하거나 덮어쓰지 않는다. 화색 메모와 조사 원자료의 0~5 화색 평가점수도 구분한다.

작기의 수확일, 출하 기록별 수확일·출하일, 작기 종료일은 서로 다른 날짜로 보존한다. 진행 상태에서 종료 결과를 비우는 기존 저장 정책과 이력이 있는 작기의 온실·단위 변경 제한은 유지한다.

## 잘못된 선택 방지와 보존

- 종료된 작기 ID를 지정하면 홈·온실에서 그 작기를 표시한다. 다른 진행 작기로 바꾸지 않는다.
- 다른 온실의 작기 또는 없는 ID를 지정하면 다시 선택하도록 안내한다. 일지·출하·비교의 잘못된 ID도 첫 번째 작기로 대체하지 않는다.
- 사용 종료된 온실의 종료 작기도 명시한 ID로 조회할 수 있다.
- 작기명·품종을 수정하면 기존 일지·출하의 연결 정보도 원본에서 다시 조회한다. 기록 자체의 작업일·출하량·거래처는 보존한다.
- 기존 이관 안내는 표시와 편집 입력에서 제외하고, 사용자 메모와 저장 원문·추가 속성은 보존한다. 미입력 값을 임의로 채우지 않는다.
- 재배 진행률·개화율·평균 꽃대 수는 새 입력값만 범위를 검증한다. 예전 표시값 때문에 원본을 읽지 못하거나 초기화하지 않는다.
- 기존 수량·등급 체계와 출하·정정·취소·잔량 계산은 변경하지 않았다.
