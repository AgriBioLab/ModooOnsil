## 메뉴

로그인 후 주 메뉴는 5개다. 회원가입·농업경영체 인증은 상단 보조 링크와 모바일 전체 메뉴에서 여는 별도 가입 흐름이다. 농장정보는 마이페이지에서 내 정보와 탭으로 구분한다. 기존 `view=farms`와 CRUD 주소·저장 내용은 유지한다. 온실은 `view=houses`로 독립한다. 용어 안내는 보조 링크를 유지한다.

주 메뉴는 품질담당자와 같은 좌측 정렬·간격·높이·파란 선택 밑줄을 사용한다. 화면 폭이 1023px 이하여도 주 메뉴를 표시하며 좁은 화면은 줄바꿈한다. 하위 메뉴는 Enter/Space로 열고 Escape로 닫는다. 전체 메뉴도 같은 사이트맵을 제공한다.

상단 메뉴 미표시의 원인은 화훼 전용 CSS의 1023px 이하 숨김 규칙이었다. 실제 미리보기 폭 1012px에서 확인 후 제거했다. 이전 버전이 열린 탭은 새로고침해 서비스명·최신 CSS도 적용했다. 추가하던 균등 폭·세로 구분선·선택 배경 덮어쓰기를 제거하고 공통 `header.css`의 15px 메뉴·44px 항목 높이·8px/24px 행 여백·40px 항목 간격을 상속한다.

실제 미리보기에서 1440·1024·1023·1012·768·390·320px의 7개 폭을 확인했다. 모두 주 메뉴 5개가 표시되고 페이지 가로 넘침이 없었다. 재배관리 하위 메뉴 펼침·Escape 닫힘도 확인했다. 증빙: `flower-header-fixed-1012-2026-11-02.png`.

## 화면 밀도

1366×768 데스크톱, 기본 확대·예시 데이터·기본 조회 상태에서 주요 13개 업무 화면과 가입 약관 화면이 첫 뷰포트에 들어오는지 확인했다. 상세 펼침·긴 입력·모바일·확대 시에는 자연스러운 스크롤을 허용한다. 본문 높이를 고정하거나 내용을 잘라내지 않는다.

| 화면 | 배치 |
| --- | --- |
| 홈 | 수량 요약과 2열 미리보기. 각 최대 2건·전체보기 제공 |
| 목록 | 높이 850px 미만 3건, 이상 5건씩 표시. 총 건수·범위·이전/다음 제공 |
| 조회 | 주요 조건 우선, 상세 조건 펼침. 시작일·종료일 한 묶음 |
| 작기 등록 | 재배 기본정보 / 정식·출하 목표·작기 종료 탭. 필수 입력 오류 시 해당 탭 표시 |
| 작기 상세 | 기본정보 / 재배일지 / 출하 이력 / 수량 변경 탭 |
| 일지 작성 | 필수 기록 우선, 생육조사·사진·다음 확인 메모 펼침 |
| 출하 등록 | 작기·날짜·출하처·수량 우선, 규격·등급 펼침. 정정 시 펼쳐 표시 |
| 생육·환경 비교 | 그래프 병렬, 원자료 펼침 |
| 회원가입 | 접힌 약관 → 농업경영체 인증 → 회원정보 → 입력 시안 완료 |

## 공통 톤과 저장

품질담당자의 공통 CSS를 직접 사용한다. 본문 15px·제목 32px·헤더 75px·입력 40px·표 14px/기본 행 48px·색·구분선을 유지한다. 화훼 전용 본문 여백은 위 16px·왼쪽 32px·아래 12px, 사이드 위 44px이다. 사이드 280px, 1024~1279px에서 220px, 1023px 이하 전체 메뉴 전환이다. 모바일 입력은 44px·16px이다. 공유 CSS·품질담당자 화면 자체는 변경하지 않았다.

CRUD는 기존 브라우저 저장소를 사용하며 출하 수량 반영·참조 삭제 방지·미저장 보호를 유지한다. 농업경영체 인증은 **기관 미연동·인증 미완료 화면**이다. 실제 계정 생성도 수행하지 않는다. 가입·인증 입력은 저장·전송하지 않는다.
