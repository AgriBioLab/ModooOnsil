# 전체 상위 메뉴명 재점검

후속 결정: 이 문서는 중간 점검안이다. 사용자와 합의한 최종 명사형 이름과 현재 반영 범위는 [프로토타입 메뉴명](prototype-menu-labels-2026-11-02.md)을 따른다.

점검일: 2026-11-02
상태: 전체 메뉴명 재검토안. 현재 화면에 적용한 이름과 제안 이름을 구분한다. 이번 작업은 점검·명칭 및 진입 구조 제안이며 UI 코드를 변경하지 않는다.

## 1. 점검 결론

이전 변경에서 상위 메뉴의 역할을 개별 입력 버튼이나 현재 구현된 일부 시연 기능에 맞추어 좁힌 문제가 있다. 장부뿐 아니라 재배일지의 조회 역할, 마이영농의 재배 정보 역할, 통계·분석의 전체 비교 목적도 다시 구분해야 한다.

하나의 기능을 드러낸다는 요구는 각 메뉴가 하나의 주된 이용 목적을 갖는다는 의미로 적용한다. 상위 메뉴와 개별 입력 버튼을 같은 이름·같은 진입 동작으로 맞출 필요는 없다.

## 2. 전체 메뉴 점검표

| 구분 | 현재 적용된 이름 | 점검 결과 | 권장 이름 |
| --- | --- | --- | --- |
| 영농현황 | 온실별 작물·내부환경 확인하기 | 현재 상황을 보는 메뉴임을 명시하고 재배 단계·출하 예정과 내부 환경을 같은 대상에서 확인 | 온실별 현재 재배·환경 상태 확인하기 |
| 재배일지 | 날짜별 생육·작업 기록하기 | 작성 버튼처럼 표현되어 이전 기록 조회·후속 결과 확인 역할이 축소됨 | 날짜별 재배일지 확인하기 |
| 마이영농 | 농장·온실 기본정보 설정하기 | 설정 기능만 강조하고 등록한 재배 건의 입고·품종·배지·목표 등의 정보가 이름에서 빠짐 | 등록한 농장·온실·재배 정보 확인하기 |
| 통계·분석 | 기간별 재배기록 비교하기 | 비교 대상이 불명확하고 현재 일지 건수 비교를 전체 통계·분석의 역할처럼 표현할 우려 | 기간별 생육·작업·출하 결과 비교하기 |
| 장부 | 농장 입금·출금 내역 확인하기 | 현재 실제 현금 입출금 조회 기능과 일치. 유지 | 농장 입금·출금 내역 확인하기 |

표의 권장 이름은 프로토타입의 기능 범위를 설명하기 위한 검토안이다. 통계·분석 전체가 구현된 상태를 뜻하지 않는다. 상위 메뉴는 대상과 대표 목적을 표현하고, 개별 화면 안에서 실제 생성·수정 버튼을 제공한다.

## 3. 메뉴별 기본 화면과 내부 버튼

| 메뉴 | 기본 진입 화면 | 화면 안에서 제공할 행동 |
| --- | --- | --- |
| 온실별 현재 재배·환경 상태 확인하기 | 온실 선택, 현재 단계·최근 조사·내부 환경·오늘 작업·임박한 출하 요약 | 온실 선택, 재배 상세, 관련 일지 열기 |
| 날짜별 재배일지 확인하기 | 달력/목록, 날짜·온실·재배 건·기록 유형 조건 | 일지 작성, 기록 정정, 후속 결과 추가 |
| 등록한 농장·온실·재배 정보 확인하기 | 농장·온실·재배 건별 등록 정보 | 온실 등록, 재배 건 등록, 기본정보 수정, 적용 기준 변경 |
| 기간별 생육·작업·출하 결과 비교하기 | 비교 기간·온실·재배 건·항목 선택 | 비교 조건 적용, 원래 기록 열기 |
| 농장 입금·출금 내역 확인하기 | 월·거래 유형별 실제 입출금 내역과 합계 | 입출금 내역 추가, 기록 정정 |

현재 상태와 등록 정보의 차이:
- 현황: 지금 어떤 상태이며 어디를 먼저 확인할 것인가. 최근 확인/수신 시각을 표시한다.
- 등록 정보: 어디에 무엇을 어떤 조건으로 등록·재배하고 있는가. 입고·품종·화분/배지·목표·적용 기준과 변경 이력을 유지한다.
- 두 화면에서 같은 품종·온실명 등을 재사용하며 별도로 복사 입력하지 않는다.

일지와 통계의 차이:
- 일지: 개별 관찰·작업·이동·출하 등 실제 사건을 날짜별로 확인한다.
- 통계: 비교 조건·단위·방법을 맞추어 누적 변화와 결과를 비교한다.

## 4. 코드 점검으로 확인한 실제 범위

- 메인은 선택 온실/베드의 재배 상태·실내 환경과 농장 전체 작업/장부 요약을 표시한다.
- 재배일지 상위 메뉴는 현재 journal-add로 연결되어 즉시 작성 양식을 연다. 저장한 일지는 보조 버튼을 통해 볼 수 있다. 권장안에서는 journal 조회가 기본 진입이 되어야 한다.
- 마이영농은 profile 안내와 온실 추가 양식으로 연결된다. 농장·재배 건·관리 기준을 모두 편집하는 기능이 구현된 상태는 아니다.
- 통계는 선택한 두 달의 일지 유형별 건수를 집계한다. 실제 생육 측정 추이·노동시간·출하 결과 비교가 구현된 상태는 아니다. 일지 건수와 생육/작업 성과를 혼동하지 않는다.
- 장부는 실제 입출금 내역 조회 후 기록 추가로 연결된다. 현재는 미수금·미지급금·원가·손익을 모두 관리하는 회계 장부로 표현하지 않는다.
- 헤더의 '내 정보'도 profile로 연결되어 마이영농과 동일한 농장 정보를 연다. 향후 계정 정보와 농장 정보를 구분해야 한다. 기능이 준비되기 전 '내 정보'를 별개의 구현 기능처럼 표시하지 않는다.

## 5. 후속 UI 수정 시 적용할 기준

- 다섯 권장 명칭의 의미를 먼저 기준으로 삼고, 화면에서 실제 가능한 기능과 미구현 항목을 구분한다.
- 재배일지와 장부는 기존 내역 조회를 기본 진입으로 두고 작성/추가는 내부 버튼으로 제공한다.
- 마이영농의 등록 정보와 현황의 현재 상태를 분리하되 같은 대상·이력을 연결한다.
- 현재 일지 건수 비교를 전체 생육·작업·출하 분석이 완성된 것처럼 표현하지 않는다.
- 데스크톱·모바일 상위 메뉴, 본문 제목, 기본 진입 화면을 함께 검토한다.
- 메뉴명 점검을 이유로 무관한 기능을 확장하거나 구현되지 않은 통계 값을 만들어 넣지 않는다.
