# 재배일지·센서 데이터 흐름 구체화 — v19

## 현재 화면이 구체적이지 않았던 이유

메뉴를 등록·조회·수정 기능으로 나누었지만 데이터가 발생하고 검토되는 업무 흐름을 충분히 드러내지 않았다. 저장 관측값 조회는 있었으나 실제 센서 수신 API·장비 등록·수집 상태·제어 실행 로그는 없다. Java 서버에서도 관련 수신 경로를 확인하지 못했다. UI의 고정 환경 기록을 실제 실시간 연동으로 볼 수 없다.

1. 재배일지 수기 기록과 온실 관측이 별도 화면에 있어 같은 날짜의 작업·생육·환경을 대조하기 어려웠다.
2. 관측 시각과 시스템 수신 시각, 데이터 출처·단위·품질이 조회에서 충분히 드러나지 않았다.
3. 온실 공용 센서값을 작기별 전용 데이터와 구분하는 기준이 화면에 없었다.
4. 수집주기가 정해지지 않아 수신 지연·결측·장비 오프라인을 판정할 근거가 없다.
5. 센서 관측과 자동 관수·차광 등의 제어 실행을 별도 이력으로 설계하지 않았다. 관측값 변화로 작업 완료를 추정하면 안 된다.

## 이번 UI 반영

| 화면 | 기능 |
| --- | --- |
| 일지·센서 통합조회 | 작기·관찰/작업일 선택 → 같은 날짜의 재배일지·생육조사·작업 상세와 해당 온실의 환경 요약 조회 |
| 환경 관측 요약 | 출처 ID·관측 항목·원 단위별 유효 건수·최솟값·관측점 산술평균·최댓값·집계 제외 건수 |
| 센서 관측 조회 | 온실·관측일 선택 → 관측 묶음·항목 수·출처 ID·최근 관측 시각 → 요약·원자료 |
| 관측 원자료 | 관측 시각·수신 시각·항목·원값·원단위·출처 ID·출처·검증 상태 |
| 기록 연결 | 통합조회에서 선택한 작기·날짜 그대로 일지 작성, 일지 상세·센서 원자료·같은 기간 비교로 이동 |
| 사이트맵·업무 메뉴 | 재배일지에 통합조회, 온실관리에 센서 관측 조회 추가. 8개 영역·47개 업무 메뉴 |

현재 저장된 관측을 읽어 자동 집계하는 UI 단계다. 실시간 수신 연결은 `미연동`으로 표시하며, 새로운 관측값을 수신하거나 정상 연결을 가장하지 않는다. 사용자에게 UI 프로토타입의 가상 수집 흐름과 실제 API 중 어떤 기준으로 진행할지 확인을 요청했다. 답변 전에는 기존 기록을 읽는 독립적인 연결·집계 작업을 진행했다.

## 연결·집계 기준

- `records.cycleId → cycles.id → cycles.houseId → environment.houseId`로 연결한다. 작기 재배기간 밖의 날짜는 이력·관측을 연결하지 않는다.
- 같은 온실의 센서 관측은 여러 작기가 공유할 수 있다. 작기별 별도 측정값으로 복사하거나 기록 건수를 중복 생성하지 않는다. 작기별 베드 센서를 구분하려면 장비·구역 매핑이 추가로 필요하다.
- 같은 출처 ID·출처·구역·항목·단위끼리 묶는다. 서로 다른 센서·단위의 값은 섞지 않는다.
- 유한 숫자 0은 정상적인 원값으로 보존한다. 없는 값은 0으로 채우지 않는다.
- 원자료에서 `invalid/error/rejected`로 표시된 값, 숫자가 아닌 값, 출처 ID 또는 단위가 없는 값은 요약 집계에서 제외하고 원자료에는 남긴다. 임계치를 추측해 생육 이상을 판정하지 않는다.
- 평균은 관측점 산술평균이며 24시간의 시간가중 평균이라고 표시하지 않는다. 시간 간격·표본 수·단위에 대한 과장 없이 유효 관측 수를 함께 표시한다.
- 수신 시각이 없는 기존 기록에는 현재 시각을 넣지 않는다. 재배일지 본문·작업량·사진·환경 원본·등급·잔량 계산은 바꾸지 않는다.

## 실제 자동수집에 필요한 다음 연결

아래는 연동 제안이며 현재 동작하는 수신 API 또는 확정 스키마가 아니다.

| 단계 | 필요한 정보·동작 | 현재 상태 |
| --- | --- | --- |
| 장비·위치 매핑 | 장비/게이트웨이 ID, 소속 농장·온실, 센서 위치·구역, 관측 항목·단위, 사용기간 | 장비 등록·매핑 화면 미구현 |
| 수신 | 원본 이벤트 ID, 장비 ID, 실제 관측 시각·시간대, 수신 시각, 값·단위·품질 코드 | 실제 수신 API·프로토콜 미제공 |
| 검증·보존 | 중복 이벤트 처리, 지연 도착, 재수신, 단위 변경, 결측·오류 원자료 보존 | 실제 수신 처리기 미구현 |
| 수집 상태 | 예상 수집주기, 마지막 수신, 지연/누락 기준, 장비 연결 상태 | 주기·상태 규격 미제공 |
| 일지 연결 | 온실·관측일·작기기간 기준 요약, 수동 작업 기록과 함께 조회 | 저장 원자료 기준 UI 반영 |
| 자동 실행 | 제어기 실행 ID·명령·실제 시작/종료·성공/실패·실제 공급량·수동/자동 구분 | 제어기 실행 로그 미제공 |

관수량·차광 상태를 센서 변화에서 추정해 작업으로 저장하지 않는다. 자동화 기기가 실제 수행한 작업은 제어기 실행 로그를 받아 재배일지의 자동 실행 이력으로 연결해야 한다. 사용자의 관찰 메모와 자동 원본은 서로 덮어쓰지 않고 출처를 유지한다.
