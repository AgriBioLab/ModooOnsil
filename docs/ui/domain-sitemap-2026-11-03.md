## 연결·검색 원칙

- 대상 ID가 필요한 조회·수정·출하·수량 작업은 먼저 대상 선택 화면을 거친다. 첫 번째 온실이나 작기를 자동으로 선택하지 않는다.
- 온실 환경은 선택한 온실 상세의 환경 데이터 탭, 작기 일지·출하·수량 이력은 선택한 작기 상세의 해당 탭으로 연결한다.
- 수량 변경·새 출하는 시작 수량이 등록된 진행 작기만 선택한다. 종료 등록은 진행 작기만, 출하 정정은 취소되지 않은 출하만 선택한다.
- 저장소를 다시 조회해 선택한 기록이 여전히 유효한지 확인한다. 삭제·변경된 대상은 오류를 안내하고 다른 기록으로 대체하지 않는다.
- 대상이 없으면 등록·목록으로 안내한다. 작기 수량 미등록 등으로 선택할 수 없을 때는 작기 목록에서 확인하게 한다.
- 검색은 메뉴명·영역명·기능 묶음·관련 키워드를 사용하며 공백과 영문 대소문자를 구분하지 않는다. 영역별 검색과 전체 검색, 결과 수·빈 결과·초기화를 제공한다.
- 검색 URL과 영역 선택을 유지하며, 메뉴 검색은 업무 데이터의 미저장 상태로 처리하지 않는다. 업무 폼에서 전체 메뉴로 나가면 기존 미저장 보호를 유지한다.
- 생육조사 메뉴는 기존 일지의 조사 입력을 펼치고, 재배작업 메뉴는 기존 일지의 기록 유형을 선택한다. 인증 메뉴는 기존 내 정보의 인증 입력을 펼친다. 기능을 별도 복제하지 않는다.
- 회원가입·용어 안내는 로그인 후 사이트맵에 다시 노출하지 않는다. 삭제·취소는 해당 상세에서 대상을 검토한 뒤 수행하는 기존 동선을 유지한다.
- 데이터 형식·공통 ID·저장 데이터·등급·잔량 계산·인증 범위는 변경하지 않았다.
