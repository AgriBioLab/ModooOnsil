# 온실 상세 손그림 반영

## 화면

- 온실관리 목록에 A/B/C동 ‘화면 샘플’ 진입을 추가하고 등록 온실 목록·검색·수정·등록을 유지했다.
- 상단: 온실명·상태·목록 복귀, 재배 품목·품종·주차, 내부온도·습도·일사강도 및 외부온도·습도.
- 하단: ‘온실 정보 / 환경 데이터’ 탭. 정보 탭은 유형·형태·측고·폭·길이·면적·배지·동수와 정보 수정, 환경 탭은 항목 선택·관측 시각별 산점도·원기록 표를 제공한다.
- 참고 이미지의 W/m² 값은 ‘내부 일사강도’로 표시한다. 실제 광도 관측은 원래 단위를 보존하며 단위를 확인하지 못한 값은 ‘단위 미등록’으로 표시한다.

## 데이터·수정

- 고정 샘플은 `src/main/webapp/resources/js/producerGreenhouseSample.js`에 모았다. 기본 샘플 값은 2026-11-03 기준으로 내부 24.5°C·68%·320W/m², 외부 22°C·50%다.
- 샘플의 재배정보는 홈 샘플과 같은 품목·품종·재배 시작일을 사용한다. 주차는 시작일을 1주차로 계산한다.
- 샘플 온실은 이름·시설정보를 화면에서 수정할 수 있다. 샘플 수정은 메모리에만 적용하며 새로고침하면 원래 예시로 돌아간다.
- 등록 온실은 저장된 정보를 우선하며 미등록 환경·시설 항목에만 ‘샘플’을 표시한다. 샘플 시설값을 실제 수정 폼에 채우거나 저장하지 않는다. 숫자 0과 미등록을 구분한다.
- 같은 온실의 진행 작기가 여러 개면 선택한 작기의 품목·품종·주차를 함께 표시한다. 진행 작기가 없으면 ‘재배 없음’으로 표시한다.
- 실제 온실의 ‘사용 중’과 센서 환경의 정상 여부를 구분한다. 실제 환경 상태는 미연동으로 표시한다.
- 환경 그래프는 동일한 항목·단위끼리 관측 시각을 기준으로 표시하며 관측점 사이를 임의로 연결하지 않는다.
- 브라우저 저장소·기존 온실 CRUD·출하·잔량 계산은 유지했다.
