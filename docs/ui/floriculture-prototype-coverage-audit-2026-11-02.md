# 화훼 온실 재배 고려사항 — 현재 시안 반영 점검

점검일: 2026-11-02. 대상: 현재 `producerMain.html`과 실제 실행 스크립트 `producerWorkspace.js`. 기존 재배관리 정리문서와 대조했다. 화면 수정 없이 반영 여부를 점검한 문서다.

## 판단

모두 반영된 상태가 아니다. 다섯 메뉴와 전체 페이지 이동 구조, 온실·구역 선택, 실내 환경 예시, 할 일과 자유서술 일지, 실제 입출금 기록의 틀이 구현되어 있다. 실제 농가의 재배 판단·측정·실행·결과를 이어 주는 세부 입력과 이력은 상당 부분 미구현이다.

자유서술에 내용을 적을 수 있다는 사실을 해당 관리 기능의 구현 완료로 보지 않는다. 환경값·단계·일정은 시연 예시이며 실제 센서 수집·자동 판단·제어가 아니다. 다음 목록은 제품의 관리 범위 점검안이며 모든 화훼농가의 모든 조건을 망라한 표준은 아니다.

## 기존 다섯 메뉴를 유지한 보완 위치

1. **온실별 현재 재배·환경 상태:** 선택한 구역의 재배 배치·단계·잔량, 실내 환경·수신 상태, 최근 생육 조사, 미해결 이상·재확인 예정, 오늘 할 일과 출하 계획을 요약한다. 각 원본 기록으로 연결한다.
2. **날짜별 재배일지:** 관찰·생육 측정 / 관수·시비 / 병해충·장해 / 재배 작업 / 단계·이동·수량 변경 / 출하·폐기로 나누고 선택한 유형에 맞는 입력을 표시한다. 공통 항목은 날짜·시각·온실·구역·배치·담당자다. 사실·판단·실제 조치·후속 결과를 구분한다.
3. **농장·온실·재배 정보:** 농장·설비·센서·재배구역, 품종·자재 목록, 재배 배치와 목표, 품목·단계별 조사 기준을 등록한다. 과거 기록에 사용한 기준·조건은 보존한다. 별도 상위 '재배관리' 메뉴를 다시 만들지 않는다.
4. **기간별 생육·작업·출하 결과 비교:** 동일 배치·품종·조사법·단위 등 비교 조건을 맞춘 기록으로 생육·작업·출하 결과를 표시한다. 기록 건수와 생육량을 구분한다. 동반 변화만으로 원인을 확정하지 않는다.
5. **농장 입금·출금 내역:** 실제 입출금 기록에 관련 배치·작업·출하를 연결한다. 현금 차액을 순이익으로 표시하지 않는다.

## 분화 호접란 조사표 제안

공통 자유서술 외에 배치·조사 개체/표본 범위, 조사일·시각·담당자, 잎 수·대상 잎 길이/너비, 새잎·잎 손상, 보이는 뿌리 상태, 꽃대 수/길이·첫 확인일, 봉오리·개화 수·첫 개화일, 사진을 선택적으로 기록할 수 있어야 한다. 잎·꽃대의 측정 위치와 대상 선정법, 미관찰의 의미를 먼저 정한다.

이 항목들은 현장 합의용 제품 설계안이다. 공식 호접란 생육조사 표준이나 모든 항목의 매일 측정을 뜻하지 않는다. 품종·입고 단계·농가 작업 범위에 맞게 정한다. 국화의 조사표를 호접란에 그대로 적용하지 않는다.

## 입력 시점

- 매일 순회: 실내 환경·설비·배지 수분·식물 이상, 미해결 사항과 오늘 할 일. 센서값은 연계 시 자동 수집하고 미연계 시 수기 출처를 표시한다.
- 작업할 때: 실제 대상·시간·양·자재·작업 결과와 계획 차이.
- 정기 조사: 합의한 표본과 방법으로 생육 측정·사진·수질/배지 검사. 주기는 현장과 결정한다.
- 사건 발생 때: 입고·이동·분갈이·단계 전환·첫 꽃대/개화·출하·피해·폐기·반품.
