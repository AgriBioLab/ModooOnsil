# 하우스 화훼 재배관리 고려사항 — 공통 체계와 국화·호접란 구분

정리일: 2026-11-01  
범위: 시설 화훼의 공통 관리 체계와 절화 국화·분화 호접란의 차이. 앞선 조사자료를 바탕으로 한 현장 검토용 정리안이다. 실제 농가의 설정값·표본 수·조사 주기는 별도 확정한다.

## 1. 관리의 중심 질문

**어디에서, 어떤 품종·배치를, 어느 단계로 키우고 있으며, 오늘 무엇을 확인·실행해서 언제 어떤 품질로 출하할 것인가?**

이를 다음 흐름으로 연결한다.

재배 목표·기준 설정 → 묘 입고·배치 등록 → 환경·뿌리·생육 확인 → 작업 판단·실행 → 결과 재확인 → 출하 판정·실적 → 다음 재배 개선.

재배일지는 이 과정에서 관찰·판단·실행·결과를 연결하는 기록이다. 온실 환경이 목표 범위 안에 있다는 사실과 식물 생육이 정상이라는 판단은 구분한다.

## 2. 무엇을 관리 단위로 삼는가

| 단위 | 의미 | 저장할 핵심 정보 |
| --- | --- | --- |
| 농장 | 운영 전체 | 위치·담당자·공통 자재/작업 목록 |
| 온실·제어구역 | 환경을 확인·조절하는 공간 | 시설·설비·센서·구역·베드 구성 |
| 재배 배치 | 품종·입고/재배 시기·조건 등을 묶어 추적하는 집단 | 품종·입고·수량·화분/배지·목표 출하·위치 이력 |
| 조사 개체 | 반복 관찰·측정하는 식물 | 개체 ID·소속 배치·위치·관찰/측정 이력 |
| 날짜별 기록 | 실제 관찰·작업·변경·출하 | 대상·시각·담당자·내용·결과·후속 확인 |

한 온실에 여러 배치가 있을 수 있으며, 같은 배치도 다른 구역으로 이동할 수 있다. 온실 선택만으로 품종·단계가 하나라고 가정하지 않는다. 배치를 나누거나 합칠 때 원래 배치와의 관계를 보존한다.

## 3. 재배 전·입고 때 정해야 할 내용

| 관리 영역 | 구체적으로 확인할 것 | 판단 목적 | 등록 시점 |
| --- | --- | --- | --- |
| 상품·출하 목표 | 절화/분화, 품종·화색·규격, 목표 출하일·수량·납품처 | 어떤 품질을 언제 완성할지 결정 | 계획 수립·변경 |
| 온실·설비 | 면적·구역·베드, 난방·냉방·환기·차광·관수·배수, 정전/고장 시 대응 | 목표 조건을 유지할 시설·인력이 있는지 확인 | 최초·시설 변경 |
| 묘·입고 품질 | 공급처·입고일·묘 규격·주수, 잎/뿌리 상태·균일도·의심주 | 입고 당시 상태를 기준으로 이후 변화 비교 | 입고·검수 |
| 재배 방식 | 토양/양액/화분 재배, 화분 크기·배지 종류/배치·충전 조건·원수 | 서로 다른 뿌리·관수 조건을 구분 | 배치 생성·이식/변경 |
| 관리·조사 기준 | 단계별 환경 목표, 항목·단위·측정법·조사 위치/개체·빈도·담당자 | 기록과 판단 기준 통일 | 재배 시작·기준 변경 |

원수·자재 제품·품종 이름의 공통 목록과, 특정 배치에 실제 사용한 조건을 구분한다. 공통 목록을 수정해도 과거 기록의 조건이 바뀌지 않도록 적용일·변경 이력을 남긴다.

## 4. 재배 중 반복해서 판단할 여섯 가지

| 관리 영역 | 현장에서 볼 내용 | 농민이 결정할 것 | 기록할 내용 |
| --- | --- | --- | --- |
| 내부 환경·설비 | 주야 온습도·빛·필요시 CO₂·젖음/결로, 위치 차이·실제 설비 상태 | 설정 유지·추가 확인·작업/설비 대응 필요 여부 | 구역·시각·측정값/출처·이탈·설정/설비 변경과 사유 |
| 관수·뿌리 | 토양/배지의 수분·배수·대표 화분의 뿌리·관수 편차 | 지금 물이 필요한지, 공급·배수 이상이 있는지 | 관찰 대상·관수 전후·실제 물/급액 양·시간·구역 |
| 양분·배지 | 원수/급액/배액/배지의 EC·pH, 검사법·단위·자재 변경 | 추가 분석·공급 방식 검토가 필요한지 | 시료·방법·측정값·비료 실제 사용·검사 결과 |
| 생육·개화 | 정한 방법으로 잎·줄기·뿌리·꽃대·꽃 변화와 균일도 확인 | 현재 단계 유지·다음 단계 준비·지연/이상 추가 확인 | 개체 ID·측정값·사진·사건 확인일·조사 범위 |
| 병해충·생리장해 | 증상 부위·발생 위치/주수·확산, 해충/트랩·젖음·작업 이력 | 의심주 구분·추가 관찰·진단/상담·대응 | 발견 사실·확인 수준·조치·후속 결과 |
| 작업·인력 | 오늘 예정/미완료·실제 수행·자재·작업시간·손상 | 우선순위·담당자·추가 확인일 | 실제 대상·시각·작업량·자재/양·변경/미실시 사유 |

**현재 센서값만 보지 않고 밤·새벽 이력과 식물 반응을 함께 본다.** 실외 기상은 환기·냉난방·시설 위험 판단을 돕는 보조 정보로 연결한다. 내부 공기와 뿌리 주변 조건을 실외 예보로 대신하지 않는다.

온도·광·CO₂·EC·pH의 수치를 모든 화훼의 공통 정상 범위로 넣지 않는다. 품종·단계·재배 방식·측정 위치/방법과 함께 적용한다. 사진·환경값만으로 원인을 확정하지 않는다.

## 5. 국화와 호접란에서 달라지는 부분

| 구분 | 절화 국화 | 분화 호접란 |
| --- | --- | --- |
| 생육을 보는 중심 | 줄기 신장·잎·분지·굵기와 개화 | 잎·뿌리 상태와 꽃대·봉오리·개화 |
| 작업·단계에서 확인 | 정식·단일처리·적심/중심화 제거 등 실제 적용 작업과 개화 반응 | 순화/활착·영양생장·개화 유도·꽃대 발달·유인·상품 마무리 |
| 정밀 조사 항목 | 채택한 국화 매뉴얼의 항목·측정 부위·단위·주기를 적용 | 잎·뿌리·꽃대·꽃을 구분하되 조사 규칙을 현장과 합의 |
| 출하 품질 | 절화 길이·굵기·무게·꽃·잎 외관 등 납품 규격 | 화분/합식 구성·꽃대·개화 상태·꽃 배열·잎/뿌리 외관 등 납품 규격 |
| 자료 확보 상태 | 농촌진흥청 2025년 개정 생육조사 매뉴얼 확인 | 동일 형식의 독립 공개 수집 매뉴얼 원문은 이번 검색에서 미확인 |

**국화:** 2025년 매뉴얼의 국화 부분은 97~122쪽이다. 98~100쪽의 정의표와 101쪽 이후 측정 설명을 함께 읽는다. [공식 원문 뷰어](https://lib.rda.go.kr/search/mediaView.do?mets_no=000000322330), [공개 재게시·다운로드 안내](https://www.urbanagrikorea.com/post/2094)

**호접란:** 농사로의 생육단계 소개와 국내 논문은 조사 항목을 검토하는 참고자료다. 국화의 조사법이나 주기를 호접란 표준으로 전환하지 않는다. [농사로 생육단계 소개](https://www.nongsaro.go.kr/portal/ps/psb/psby/vodPlay.ps?menuId=PS65512&mvpClipNo=2&mvpNo=641), [국내 품종 특성조사 논문](https://www.koreabreedjournal.org/journal/view.php?number=451)

### 호접란 생육을 구체적으로 기록하는 방법 — 현장 합의용 제안

아래는 앱의 조사표를 만들기 위한 제안이다. 확인된 공식 호접란 생육조사 표준이 아니며, 실제 품종·입고 단계·관찰 가능 범위에 맞게 농가와 확정한다.

| 대상 | 무엇을 남기는가 | 측정·관찰 규칙으로 정할 내용 | 판단에 쓰는 목적 |
| --- | --- | --- | --- |
| 잎 수·새잎 | 정한 기준에 따른 잎 수, 새잎 출현일 | 펼쳐진 잎의 기준, 새잎 포함 여부, 탈락/제거 잎 구분 | 새잎 발생·잎 손실과 개체 간 편차 추적 |
| 잎 크기 | 잎 길이·너비(cm), 대상 잎 ID | 최대 잎 비교인지 같은 잎의 변화인지 구분; 잎의 시작/끝점과 너비 위치 통일 | 식물 크기·잎 발달의 변화 확인 |
| 잎 상태 | 색·황화·반점·주름·손상 부위와 관찰 주수 | 사진 각도·배경·촬영 조건, 전체 조사 주수와 이상 주수 | 이상 발생 범위와 변화 확인 |
| 뿌리 | 보이는 새뿌리/뿌리 끝, 변색·마름·손상 | 투명 화분 등 실제 관찰 범위 명시; 미관찰과 정상 구분 | 배지·관수·시비 이력과 함께 상태 검토 |
| 꽃대 | 첫 확인일·개수·길이·유인 작업 | 길이 시작/끝점·굽은 꽃대 측정법·대상 꽃대 ID 통일 | 꽃대 발달과 작업 일정 확인 |
| 봉오리·꽃 | 봉오리 수·열린 꽃 수, 첫 개화일·낙화/손상 | 미개화와 개화 구분; 조사 시점·화분/꽃대 단위 통일 | 목표 출하 시점의 개화 상태 확인 |
| 상품 균일도 | 배치 내 크기·꽃대·개화 상태의 차이 | 조사 개체 선정법·전체/표본 수와 납품 규격 | 선별·보류·출하 가능 수량 판단 |

같은 개체를 반복 측정하면 변화 이력을 볼 수 있다. 이때 표본 개체 교체·고사·이동을 기록하며, 표본 결과를 전체 배치의 전수 검사처럼 표시하지 않는다. 농가에서 쓰지 않는 항목을 일괄 필수 입력으로 만들지 않는다.

## 6. 매일·정기·사건별로 나누는 기록

| 빈도/시점 | 우선 확인·기록 | 운영 원칙 |
| --- | --- | --- |
| 매일 순회 | 환경·설비 이상, 잎/뿌리/꽃 이상, 수분 상태, 지난 미해결 사항, 오늘 작업 | 모든 항목의 정밀 측정·사진을 매일 강제하지 않음 |
| 작업할 때 | 실제 대상·시각·양·자재·담당자·계획과의 차이 | 예정·완료·미실시·부분 수행 구분 |
| 정기 조사 | 정한 표본의 생육 측정·비교 사진, 계획에 따른 배지/수질 검사 | 조사법과 주기를 품목·목적에 맞게 정함 |
| 단계/변경 발생 | 입고·이식·이동·처리 시작·첫 꽃대/개화·배지/설정 변경 | 사건 날짜와 예정 날짜를 분리 |
| 출하/피해 발생 | 적합·보류·폐기·실제 출하·반품·수량·사유 | 단위·원래 배치·실제 거래 결과 연결 |

센서가 연결되어 있으면 측정 시각·위치와 함께 환경 이력을 불러온다. 미연결·미수신·미관찰을 0이나 정상으로 저장하지 않는다. 수기로 확인한 사실은 자동 수집 데이터와 출처를 구분한다.

## 7. 출하·비용·다음 재배에서 고려할 내용

- 납품처의 실제 규격과 현재 식물 상태를 비교해 적합·보류·제외를 판단한다.
- 목표 출하일·예정 수량과 실제 출하일·수량을 나누어 관리한다.
- 주·재배 화분·합식 상품·속·상자 등 사용하는 단위의 의미와 환산 기준을 남긴다.
- 선별·지주/유인·합식·포장·운송 중 품질 변화와 반품을 원래 배치에 연결한다.
- 입고·폐기·이동·출하·잔량을 연결해 수량을 확인한다. 이동으로 생산 수량이 늘어나지 않게 한다.
- 묘·배지·화분·비료·방제·포장·인력·에너지를 필요한 범위에서 배치/작업과 연결한다.
- 판매액·입금액·수수료·운송비를 구분한다. 현금 수입−지출을 순이익으로 단정하지 않는다.
- 다음 재배 전에는 생육 지연·품질·불량·작업량·비용을 비교한다. 동시 발생한 기록만으로 원인을 입증했다고 하지 않는다.

하나의 실제 작업이 일지·장부에 각각 필요하더라도 같은 내용을 다시 입력시키지 않고 연결 기록으로 조회하게 한다. 기준·계획·실적이 같은 값으로 덮이지 않도록 한다. 이 표는 메뉴 설계 제안이며 기능 구현 완료를 의미하지 않는다.

## 9. 기록을 남기는 한 가지 공통 형식

**대상 → 발견 사실 → 판단 근거 → 실제 수행 → 재확인 일정 → 이후 결과**

가상 예시:

- 대상: C동 베드 2·호접란 배치 P-03.
- 발견: 일부 표본의 새뿌리 끝 마름. 위치·관찰 범위·사진 기록.
- 판단: 원인 미확정. 배지 수분·수태 배치·관수/시비·검사 이력 추가 확인.
- 수행: 실제로 한 표시·측정·검사 의뢰를 기록. 예정 작업은 별도 유지.
- 후속: 담당자가 정한 시점에 같은 대상의 뿌리 상태·검사 결과 확인.
- 결과: 관찰 지속·추가 대응·해결 여부와 판단 이유 기록.

가상 흐름이며 관수·비료·방제 처방이 아니다. 실제 국내 호접란 현장에서도 배지 변경 이력과 뿌리·잎 증상, 배지 분석을 함께 조사한 사례가 있다. [농촌진흥청 현장 사례](https://nongsaro.go.kr/portal/ps/psz/psza/contentSub.ps?cntntsNo=257535&menuId=PS00077&totalSearchYn=Y)
