# 화훼농가 메뉴 역할 비교 — 재배관리·영농일지·마이영농·현황·통계

정리일: 2026-11-01
범위: AgriComp 화훼농가 서비스의 메뉴 역할·정보 소유·화면 연결 비교안. 현재 구현에 대한 확인 범위와 향후 설계 제안을 구분한다. 공인된 메뉴 분류나 다른 서비스의 기능 검증 결과가 아니다.

## 1. 비교 결론

다섯 용어는 같은 종류의 분류가 아니다. 마이영농은 반복 사용하는 공통정보·설정, 재배관리는 배치별 운영, 영농일지는 실제 발생 기록, 현황은 현재 판단을 위한 조회, 통계는 기간·대상별 집계와 비교다.

화면은 사용 목적에 따라 나누되 입력한 사실은 공통으로 재사용한다. 같은 값을 메뉴별로 따로 저장하면 기록 불일치·중복 입력이 발생하기 쉽다.

## 3. 재배관리와 영농일지의 경계

재배관리는 배치 중심의 운영 공간이고, 일지는 날짜·사건 중심의 이력 공간이다.

- 재배관리: 배치 생성, 입고 조건, 위치, 출하 목표, 적용 기준, 현재 단계, 할 일/후속 확인 운영.
- 영농일지: 실제 관찰·측정·작업·단계 변경·이동·출하 등의 사건과 사유·결과를 추적.
- 같은 배치 상세에서 생육 조사나 작업 완료를 입력할 수 있다. 저장하면 같은 사건이 일지에도 보인다.
- 일지에서 기록한 실제 작업도 해당 배치 이력과 작업 상태에 연결한다.
- 모든 일지가 작업 완료는 아니다. 관찰만 한 기록·검사 결과도 독립적으로 저장한다.
- 실제 단계 전환과 위치 이동은 별도의 날짜/대상 필드를 가진 기록으로 저장한다. 자유 메모에서 문장을 추측하여 수량·위치·단계를 변경하지 않는다.
- 현재 단계는 실제 확인·등록한 단계 변경 기록을 반영한다. 재배 경과일만으로 단계나 진행률을 확정하지 않는다.

## 4. 영농현황과 통계의 경계

| 상황 | 영농현황 | 통계·분석 |
| --- | --- | --- |
| 온실 환경 | 선택 구역의 최근값·측정 시각·미수신·오늘 확인할 이탈 | 선택 기간의 주야간 추이·설정 범위 이탈 시간·구역 비교 |
| 생육 | 현재 단계·최근 조사일/값·미확인 이상 | 같은 조사법의 반복 측정 추이·배치/표본 간 편차 |
| 작업 | 오늘 예정·미완료·후속 확인 | 기간별 작업 건수·완료율·실제 노동시간 |
| 출하 | 임박한 출하·예정 수량·선별/보류 상태 | 목표 대비 실제 출하일·수량·규격 충족 결과 |
| 비용 | 이번 달 입출금 요약 등 현재 확인용 수치 | 기간·배치별 비용 구성, 판매/입금 비교 |

현황에도 그래프·집계가 들어갈 수 있고 통계에도 최신 수치가 들어갈 수 있다. 구분 기준은 차트 모양이 아니라 이용 목적이다. 현황은 지금 할 일을 찾게 하고, 통계는 차이를 비교하여 다음 계획을 검토하게 한다.

메인의 현황을 별도 상위 메뉴와 중복해서 만들 필요는 없다. 메인 자체를 '영농현황'으로 정의하고 환경·생육의 상세 분석은 해당 대상의 상세 화면 또는 통계로 연결한다.

통계에서 발견한 동반 변화는 원인 확정과 구분한다. 품종·단계·측정 방법·단위·비교 기간이 다른 값을 근거 없이 합치지 않는다.

## 8. 현재 시안에서 확인한 문제와 권고

현재 코드에서 확인한 범위:

- producerMain.html의 문서 제목과 본문 h1이 '재배관리'다.
- 공통 내비게이션은 재배관리·장부·영농일기·마이영농으로 구성되어 있다.
- 메인에는 선택 온실의 재배/내부 환경 요약과 오늘 할 일 등이 있다.
- 일기는 시안 모달에서 조회·작성하고 작업 완료 기록과 연결한다.
- 마이영농은 농장 정보를 안내하는 시안 모달이다.
- 따라서 이번 문서의 전체 기능 체계가 구현되었다고 볼 수 없다.

권고하는 정보 구조:

- 영농현황: 접속 첫 화면. 현재 메인의 역할.
- 재배관리: 재배 배치 목록·상세·계획·생육 조사·단계/수량/출하 운영.
- 영농일지: 날짜별·대상별 실제 기록과 후속 결과.
- 통계·분석: 기간/배치/품종/구역별 추이와 결과 비교.
- 장부: 실제 거래·비용·입출금.
- 마이영농: 농장·시설·목록·기준·계정/알림 설정. 설정 성격이므로 별도 설정 위치 또는 하위 메뉴 배치를 검토.

'메인'과 '현황'을 별도 최상위 메뉴로 중복하지 않는다. 환경·생육·출하를 모두 독립 최상위 메뉴로 늘리기 전에 배치 상세 안의 탭으로 연결할 수 있는지 확인한다.

메뉴 표기는 현재 '영농일기'와 기획 문서의 '영농일지'가 다르다. 이번 구조는 측정·작업·이력을 담으므로 '영농일지'로 통일하는 것을 제안한다. 자유 메모·사진도 일지 안에 포함할 수 있다. 실제 메뉴명·노출 위치와 구현 범위는 후속 화면 설계에서 확정한다.

## 9. 시안 검토 기준

- 사용자가 지금 확인·계획·실제 기록·비교·설정 중 무엇을 하는지 명확한가?
- 온실/배치/날짜 선택이 화면 이동 때 유지되는가?
- 같은 작업을 완료하고 일지에 다시 입력하도록 요구하지 않는가?
- 예정과 실제, 현재값과 과거값, 수기와 센서, 미관찰과 정상을 구분하는가?
- 현황·통계의 수치에서 원래 기록을 확인하고 정정할 수 있는가?
- 정정·취소·이동 후 연결된 잔량·완료 상태·집계가 일관되게 바뀌는가?
- 마이영농 설정 변경으로 과거 재배 조건이 바뀌지 않는가?
- 메인에서 선택 온실·배치 기준인지 전체 농장 기준인지 표시하는가?

관련 정리: [하우스 화훼 재배관리 고려사항](floriculture-greenhouse-management-framework-2026-11-01.md).

## 10. 대안 검토 — 재배관리 상위 메뉴를 없애고 두 메뉴로 통합

사용자 제안에 따른 검토안이며 메뉴 개편을 확정하거나 화면에 적용한 상태는 아니다.

권고: 재배 관련 상위 메뉴를 '마이영농'과 '영농일지'로 단순화하는 구성이 가능하다. 이 경우 마이영농의 역할을 앞선 비교안의 '공통정보·설정'에서 '내 농장과 현재 재배를 운영하는 공간'으로 확장한다.

| 구분 | 마이영농 | 영농일지 |
| --- | --- | --- |
| 중심 관점 | 온실·재배 건 중심 | 날짜·발생 기록 중심 |
| 목적 | 지금 키우는 대상·상태·앞으로 할 일 관리 | 실제 관찰·작업·변경·후속 결과 기록 |
| 포함 기능 | 온실/구역·재배 건 등록, 입고 조건, 현재 단계/위치/잔량, 목표 출하, 작업·재확인 계획, 내부 환경, 통계, 농장 설정 | 생육 조사, 작업 실적, 이상 발견, 단계 전환·이동·폐기·출하 사건, 사진·판단 근거·후속 결과 |
| 대표 행동 | 호접란 3차 재배 건을 열어 상태 확인·다음 작업 계획 | 오늘 호접란 3차의 관찰·실제 작업 기록 |
| 연결 | 재배 상세에서 기록 입력·필터된 일지 열기 | 일지에서 해당 재배 상세 열기 |

마이영농 첫 화면은 계정 설정이 아니라 '우리 온실'의 현재 재배·내부 환경·오늘 할 일·미해결 이상을 보여준다. 온실마다 여러 재배 건을 구분한다. '배치'는 내부 개념으로 유지할 수 있으나 사용자 화면에서는 '호접란 3차' 같은 농가 명칭을 사용한다.

하위 구성 제안:
- 우리 온실: 현재 현황과 내부 환경, 오늘 작업. 별도 상위 '현황'과 중복하지 않음.
- 재배 목록/상세: 진행 중·종료된 재배 건, 목표·계획·생육·출하와 연결 이력.
- 통계: 해당 농장·온실·재배 건의 기간별 비교. 별도 상위 메뉴 필요성은 사용 빈도로 재검토.
- 농장 설정: 온실/시설·목록·조사법·기준 등 변경 빈도가 낮은 정보. 계정 설정과 구분.

영농일지는 달력·목록에서 날짜/온실/재배 건/유형별로 실제 기록을 조회·작성한다. 계획을 같은 달력에 표시하더라도 예정과 실적을 명확히 구분한다. 실제 작업 저장은 한 번만 하고 두 메뉴에서 같은 기록을 조회한다.

이동·출하·단계 전환을 마이영농 재배 상세에서 입력해도 같은 사건 이력이 일지에 남는다. 일지에서 해당 유형으로 기록해도 재배 건의 현재 상태에 연결한다. 자유 메모를 분석해 위치·수량·단계를 임의로 바꾸지 않는다. 정정/취소 때 연결 상태도 일관되게 처리한다.

장점은 상위 메뉴 선택 부담과 재배관리/일지의 진입 경계가 줄어드는 것이다. 부담은 마이영농이 커지는 것으로, 기본정보와 현재 재배를 한 화면의 긴 입력 폼으로 합치지 않고 하위 구성·재배 상세로 나누어 해결한다. 다수 농장·다수 작업자·대량 배치 운영에서 직접 진입 필요가 커지면 그때 별도 재배관리 메뉴를 재검토한다.

예시 흐름: 마이영농에서 A동·호접란 3차 확인 → 기록하기 → 영농일지에 대상이 선택된 상태로 관찰/실제 작업 저장 → 마이영농의 최근 조사·작업 이력과 통계에서 같은 기록 사용.

이 대안에서는 '재배관리' 기능을 마이영농의 재배 목록/상세로 포함한다. 메인 코드·내비게이션은 이번 검토 단계에서 변경하지 않는다.
