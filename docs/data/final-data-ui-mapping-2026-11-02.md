## 단위와 집계

- 재배수량 단위와 출하 단위를 분리한다. 단·속·kg·박스 등을 본·주·화분과 자동 환산하지 않는다.
- 단위가 다르면 사용자가 확인한 차감 재배수량을 별도 입력한다. 같은 단위면 실제 출하량과 차감량이 같다.
- 소수 kg 출하를 허용한다. 재배 차감 수량은 현재 개체 수량 모델에 맞춰 정수로 기록한다.
- 등급별 수량을 입력했다면 합계가 총출하량과 같아야 한다. 같은 등급의 중복 입력도 막는다.
- 기간별 출하 비교는 선택한 출하 단위끼리 집계한다. 목표 대비 실적은 재배 단위로 확인한 차감 수량으로 계산하고 화면에 기준을 밝힌다.
- 총금액은 거래 금액이며 입금·수금 완료·손익으로 처리하지 않는다. 입출금 장부는 추가하지 않았다.

## 원자료 표기 확인 사항

- 사용자가 출하 등급을 **특상/상/중**으로 확정했다. 새 출하는 이 세 등급을 선택하고 등급별 수량도 동일한 명칭으로 입력한다. 원본의 특 표기와 기존 저장 기록은 자동으로 상으로 바꾸지 않고 보존한다.
- 화서수는 원자료 항목명으로 보존하고 기존 봉오리 수와 자동으로 합치지 않는다. 실제 계수 대상은 조사 방법에 남긴다.
- 화색은 최종 자료의 0~5 점수를 입력한다. 실제 꽃 색상명이나 사진을 점수로 자동 변환하지 않는다. 중간 점수 기준은 조사 방법에 기록한다.
- 대표 식물체 10%는 자료의 권장 문구로 보존한다. 표본 수 자동 생성·의무 입력 검증으로 적용하지 않는다.
- 수확일과 작기 운영 종료일은 별도 보존한다. 종료일·정식일·출하일을 수확일로 덮어쓰지 않는다.
- 기존 온습도 예시 외의 환경 단위는 원자료 단위를 받아 표시한다. 단위·수신값이 없는 항목에는 임의의 정상값이나 0을 만들지 않는다.
- 경영체 인증 API·권한 API·실제 비밀번호 변경은 연결되지 않았다. 인증 성공값을 만들거나 신규 식별정보·비밀번호를 브라우저에 저장하지 않는다.

## 확인 결과

기존 도메인 12개, 16개 경로×5개 폭 CRUD 회귀, 용어/공유 HTML 검증을 통과했다. 새 검증은 소수 kg·명시적 재배 차감·출하 정정/취소·등급 합계/중복·수확일·0 차광값·선택 필드 저장/재조회·15개 환경 선택·펼친 입력 폼 5개 폭을 포함한다. 주요 13개 기본 업무 화면은 1366×768에서 첫 뷰포트에 들어온다. 추가 항목 펼침과 긴 내용은 자연스럽게 스크롤한다.
