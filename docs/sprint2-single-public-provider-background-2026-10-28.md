# 1차 기반 2차 스프린트 — 단일 공공 제공기관과 서비스 배경

작성일: 2026-10-28 / 상태: 이전 기관 선정 검토 이력

> 최신 기준은 [생산자 지원기관 선정과 향후 보상환경 서비스 제안](public-provider-selection-proposal-2026-10-28.md)이다. **생산자를 실제 지원하는 기관을 먼저 선정하고, 같은 기관에 보상환경 서비스를 추가 제안한다.** 아래의 ‘기존 보상 업무까지 동시에 확인해야 기관을 선정할 수 있다’는 조건과 남양주 중심 검토는 이전 이력으로만 보존한다. 현재 우선 후보는 생산자 지원 업무를 근거로 한 예산군농업기술센터 스마트원예팀이다.

## 1. 확정된 기획 조건

- 1차의 피해보상 모니터링과 2차의 생산자 재배공정 서비스는 **같은 기관이 제공하는 하나의 서비스**로 설정한다.
- 품질담당자의 업무 영역은 **피해보상 모니터링·통계 분석·보상 품질 평가·예측 기반 전략 수립과 예산 책정**이다. 복구지원·현장 집행을 직접 수행하는 역할이 아니다.
- **2차 스프린트의 액터는 생산자**이며, 생산자의 재배공정 업무를 이번 기획의 중심에 둔다.
- 품질담당자·피해보상 관련 추가 작업은 후속 스프린트에서 진행한다. 2차에 신규 개발 대상으로 포함하지 않는다.
- 기관이 같아도 생산자와 내부 담당자의 업무·권한은 구분한다. 생산자는 해당 기관이 제공하는 서비스의 이용자다.

앞선 기관별 페르소나 문서는 비교 조사다. 이번 안에서는 여러 기관을 각각의 서비스 제공자로 배치하지 않고, 단일 제공기관을 정하는 근거로 활용한다.

## 2. 제공기관의 역할과 선정 상태

**제공기관의 기획 역할: 생산자의 재배공정을 지원하고, 보상 결과를 평가·예측하여 보상 전략과 예산을 계획하는 단일 공공 농업지원기관.**

농업기술센터를 구체 후보로 검토하되, 앞서 제시한 **남양주시 농업기술센터는 생산자 지원 업무의 참고기관**으로 둔다. 복구지원 업무가 있다는 사실만으로 사용자가 정의한 보상 품질 평가·예측·예산 책정 역할까지 일치한다고 확정하지 않는다.

남양주시 농업기술센터의 공식 기능 안내에는 다음 업무가 같은 센터 안에 명시돼 있다.

| 공식 업무 | 기획과 연결되는 부분 |
|---|---|
| 농업기술팀의 화훼 재배기술 지도·시범사업 | 생산자의 재배공정 지원을 설명할 근거 |
| 친환경농업팀의 시설원예 현대화·원예작물 경쟁력 강화 지원 | 온실 재배환경 관리 서비스의 제공 배경 |
| 같은 팀의 농업재해 복구지원 | 공식 업무로 확인되지만 이번 서비스의 직접 수행 기능이나 기관 선정의 결정 근거로 사용하지 않음 |

근거: [남양주시 농업기술센터 공식 기능 안내](https://www.nyj.go.kr/agri/contents.do?key=505), 확인일 2026-10-28.

단일 기관이라는 사용자 조건은 유지한다. 다만 실제 기관 선정에는 **생산자 재배공정 지원과 보상 결과의 평가·예측·예산 계획을 같은 조직의 업무로 설명할 근거**가 필요하다. 현재 확인한 안내만으로 해당 기관의 보상 품질 평가·예측·예산 책정 업무까지 입증한 것은 아니다. 실제 센터가 우리 시스템을 운영하거나 ‘품질담당자’라는 동일한 직함을 사용한다고 설명하지 않는다.

예산·남양주 지역은 조사 후보였으며 사용자가 확정한 지역이 아니다. 시연 품목으로 절화국화를 채택하는 것도 기획 가정이다. 기관의 실제 업무와 프로젝트의 제공자 역할을 대조할 때 이번 사용자 설명을 우선한다.

### 품질담당자의 업무 흐름

보상 처리 결과 모니터링 → 통계 분석 → 보상 품질 평가 → 향후 보상 수요·소요예산 예측 → 보상 전략 수립·보상 여건 개선·예산 책정.

‘보상 품질’은 이 프로젝트에서 보상 체계와 결과를 평가하는 개념이다. 구체적인 지표와 평가 기준은 후속 설계에서 정한다. 생산물의 상품 등급 평가나 복구작업 수행으로 해석하지 않는다.

기관의 전략·예산 계획이라는 목표와 1차의 실제 구현 범위는 구분한다. 통계·평가·예측·예산 기능이 1차에 모두 구현됐다는 의미는 아니다.

## 3. 1차에서 2차로 이어지는 배경

### 1차가 다룬 문제

피해가 발생하고 보상 처리가 이루어진 뒤, 품질담당자가 지급결과와 관련 정보를 확인하는 업무를 지원했다. 확인된 구현 범위는 로그인·지급결과 목록 및 검색·상세 조회·로그아웃이다. 보상 승인이나 송금을 구현한 것으로 설명하지 않는다.

근거: [1차 발표 스크립트](1차_스프린트_10분_발표스크립트.md), [1차 통합본 소스 리뷰](sprint1-latest-review.md).

### 2차에서 다룰 문제

생산자는 피해가 발생하기 전부터 온실별 상태를 확인하고 재배 단계에 맞는 환경과 작업을 관리한다. 온실을 이동하며 확인하는 부담, 설정·조작·작업 기록을 다시 찾는 어려움, 외부에서 상태를 확인할 필요를 생산자 문제의 가설로 둔다.

이에 2차는 같은 공공 제공기관의 서비스를 **생산자의 일상적인 재배공정 운영까지 확장**한다. 향후에는 생산 과정의 기록과 보상 결과를 연결해 보상 환경을 이해하고 전략·예산 계획에 참고하는 구조를 검토한다. 2차는 생산자가 직접 사용하는 공정 기능에 집중하며, 예측 기능과 데이터 연결을 이번에 함께 구현하는 것으로 확대하지 않는다. 재배공정 관리의 피해 저감 효과나 예측 정확도는 아직 검증되지 않았다.

| 구분 | 1차 스프린트 | 2차 스프린트 | 후속 작업 |
|---|---|---|---|
| 서비스 제공기관 | 단일 공공 농업지원기관이라는 기획 설정 적용 | 같은 기관 유지 | 같은 기관 유지 |
| 작업 중심 액터 | 품질담당자 | **생산자** | 품질담당자·피해보상 관련 액터 |
| 업무 | 구현은 지급결과 목록·상세 조회 중심 | **온실 재배공정 현황·환경·운영 이력 관리** | 보상 통계·품질 평가・예측・전략・예산 관련 기능 보완 |
| 기획상 연속성 | 보상 결과를 파악하는 기반 | 생산 과정의 일상적 관리와 기록 기반 | 생산·보상 정보를 참고한 보상 전략·예산 계획 검토 |
| 이번 변경 상태 | 완료 범위는 기존 자료를 따름 | 구체 기능은 2차 명세에서 확정 | 이번 2차 구현 범위에서 제외 |

## 4. 서비스 제공자 페르소나 — 단일 공공 농업지원기관

기관을 서비스 제공자로 보는 조직 페르소나다. 모든 업무를 한 직원이 수행한다는 의미가 아니다.

| 항목 | 정의 |
|---|---|
| 제공자 | 생산자 지원과 보상 평가·전략·예산 계획을 제공하는 공공기관. 실제 기관명은 역할 대조 후 확정 |
| 서비스 대상 | 관내 화훼 온실 생산자. 최초 시연은 절화국화 한 품종·작형을 가정 |
| 제공 배경 | 보상 결과·통계를 평가하고 미래 보상 여건과 예산을 계획하려는 기관이 생산자의 일상적 재배공정 지원도 함께 제공 |
| 기관 목표 | 생산자의 공정 관리를 지원하고, 보상 품질을 평가하여 예측 기반 전략과 예산 계획을 마련 |
| 현행 프로젝트의 한계 | 1차는 품질담당자의 결과 조회에 집중해 생산자가 평상시 사용하는 재배공정 기능을 다루지 않음 |
| 제공 서비스 제안 | 생산자용 재배공정 관리와 내부 담당자용 보상 모니터링·평가·계획 서비스를 역할별로 제공. 이번 개발은 생산자에 집중 |
| 운영 니즈 가설 | 농장·온실·품종·재배 단계의 일관된 구분, 기록의 신뢰성, 이용자별 접근 범위, 기술자료 출처 관리 |
| 대표 발화 | “생산자의 재배공정 관리를 지원하고, 보상 결과와 통계를 평가해 앞으로 필요한 보상 전략과 예산을 계획하고자 합니다.” |

생산자가 자신의 재배공정을 운영하며, 제어 기능을 포함할 경우 현장 장비 연동·유지보수는 별도 기술 수행 역할로 정한다. 기술업체를 활용하더라도 단일 공공 서비스 제공기관이라는 설정은 유지한다.

## 5. 2차 액터 페르소나 — 화훼 온실 생산자

| 항목 | 정의 |
|---|---|
| 역할 | 온실의 재배 단계·환경·설비·작업을 직접 관리하는 농장주 겸 재배 책임자 |
| 배경 | 품종과 출하계획에 맞춰 정식·생육관리·개화 조절·수확을 수행하며 여러 온실이나 구역을 확인 |
| 목표 | 어느 구역에 확인이 필요한지 파악하고 필요한 작업·환경 관리를 수행 |
| 불편 가설 | 현장 순회에 의존하고, 현재 상태와 적용 설정을 함께 보기 어렵고, 과거 조작·작업 이력이 흩어져 있음 |
| 니즈 | 구역별 현황, 품종·재배 단계, 환경 측정값과 설정, 조작 결과, 공정 이력 |
| 서비스 관계 | 품질담당자의 보상 모니터링·평가 서비스와 같은 공공기관이 제공하는 생산자용 서비스를 이용 |
| 대표 발화 | “어느 온실이 어떤 단계인지 보고, 필요한 관리를 한 다음 결과와 이력을 확인하고 싶습니다.” |

생산자 불편과 이용 의향은 인터뷰 전 가설이다. 공공 지원사업의 존재가 해당 서비스의 수요를 자동 입증하지는 않는다.

## 6. 재배공정과 2차 기능의 연결

**공정 배경:** 품종·묘 준비 → 정식 → 생육관리 → 전조·차광 등 개화 조절 → 수확·선별 → 수확 후 관리 → 출하.

근거: [농사로 국화 농작업 일정](https://nongsaro.go.kr/portal/ps/psb/psbl/workScheduleDtl.ps?cntntsNo=30672&menuId=PS00087&sKidofcomdtySeCode=210003&totalSearchYn=Y). 국화는 품종·작형에 따른 차이가 있으며 온도만으로 전체 공정과 생육 결과를 판정하지 않는다.

기존 [27일 재배공정 기획안](floriculture-greenhouse-service-brief-2026-10-27.md)의 기능을 다음과 같이 공공 제공기관 배경에 연결한다. 아래는 기획 기능이며 전체의 2차 구현 확정이나 완료를 뜻하지 않는다.

| 생산자 기능 | 공정에서의 사용 목적 |
|---|---|
| 재배공정 현황 | 온실·구역별 품종·단계·환경·설비 상태 확인 |
| 재배공정 이력 | 작업·환경·설정·조작 내역을 다시 확인 |
| 재배환경 레시피 설정 | 생산자가 적용할 관리 조건을 저장·확인 |
| 레시피 비교 | 설정·적용 기간별 차이를 확인 |
| 중앙·원격제어 | 연동 가능한 설비에 대해 생산자가 조작하고 결과 확인 |
| 재배공정 운영 통계 | 기록된 환경·설비 운영 현황을 집계 |

2차 완료 기준은 생산자의 업무 흐름으로 정한다. 예를 들어 ‘구역 선택 → 현황 확인 → 필요한 설정·조작 → 결과와 이력 확인’이다. 장비가 연동되지 않은 시연은 시뮬레이션으로 표시한다. 피해신청·보상조회·품질담당자 화면 추가는 별도 후속 범위로 둔다.

## 7. 다른 공공기관과의 위치

농진청·화훼연구소·농관원을 별도의 서비스 제공기관으로 추가하지 않는다. 기관 비교는 생산자 지원과 보상 평가·예측·전략·예산 계획이 같은 기관의 서비스로 성립하는지를 기준으로 한다. 재배기술 지원이나 재해복구 업무 한 가지의 존재만으로 전체 역할을 충족한다고 판단하지 않는다.

기관 간 실제 전산 연계를 2차에 새로 전제하지 않는다. 농진청·연구소의 자료를 사용할 경우 출처를 표시하고, 농관원 정보가 필요하면 공식 안내와 필요한 범위부터 검토한다.

비교 조사 근거는 [공공 제공자별 페르소나](producer-public-provider-personas-2026-10-28.md)를 참고한다. 해당 문서는 이번 선정 이전의 비교안이다.

## 8. 발표용 문안

> 본 서비스는 공공기관이 생산자의 재배공정을 지원하고, 품질담당자가 보상 결과와 통계를 분석해 보상 품질을 평가하며 예측을 통해 향후 보상 전략과 예산을 계획하도록 돕습니다. 1차 스프린트에서는 그 기반인 보상 지급결과 조회를 구현했습니다. 2차 스프린트에서는 같은 기관의 생산자용 서비스를 개발하여 화훼 온실의 재배공정과 환경·운영 이력을 관리하도록 합니다. 생산자의 일상적 공정 관리와 기관의 보상 평가·계획을 하나의 서비스 맥락으로 연결하는 것이 배경입니다. 품질담당자의 통계·평가·예측·예산 관련 추가 작업은 후속 스프린트에서 진행합니다.

서비스 소개 한 문장:

> **동일 공공기관이 생산자의 재배공정 관리와 품질담당자의 보상 모니터링·품질 평가·예측 기반 전략 및 예산 계획을 지원하는 농업 서비스.**

## 9. 구체 설계 전 확인할 사항

- 품질담당자는 프로젝트 역할명으로 유지하며, 실제 참고기관의 직위·권한과 같다고 단정하지 않는다.
- 기관 선정에는 생산자 지원과 보상 품질 평가·전략·예산 계획의 실제 업무 근거가 함께 필요하다. 앞선 복구지원 중심의 선정 근거는 수정한다.
- 보상 품질의 평가 기준, 예측 대상과 입력자료, 예산 책정의 사용처는 후속 피해보상 설계에서 구체화한다.
- 최초 품종·작형, 현장 장비, 센터의 실제 서비스 운영 수요는 검증 대상이다.
- 이번 문서는 제공기관과 배경 정리다. 소스·DB·Jira·발표자료의 기능 변경은 수행하지 않았다.
