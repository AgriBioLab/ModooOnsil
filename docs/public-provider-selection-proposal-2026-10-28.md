# 지자체 농업지원기관의 AI·디지털 전환과 생산자 서비스 배경

작성일: 2026-10-28 / 최신 사용자 설명 반영본

> 최신 서비스 개요는 [1차·2차 스프린트 — 생산자 정보와 피해보상 업무 연결](sprint1-sprint2-service-overview-2026-10-28.md)을 따른다. 1차 보상 모니터링을 바탕으로 2차에서 농민의 정보·영농·재배공정 기록을 관리하고, 후속 지원·보상 업무에서 그 정보를 활용하는 것이 중심이다. 아래 기관·AI 배경은 보조 검토자료다.

현재 제공기관 설정: **지자체 농업 관련 공공기관(농업기술센터 등 생산자 지원기관)**. 특정 지자체는 확정하지 않으며 예산군 사례는 실제 업무의 참고로 사용한다. 설명의 중심은 생산자 지원의 디지털 전환과 향후 AI 활용이다.

실무 검토: [공공 소프트웨어 발주·운영 사례 비교](public-software-proposal-comparison-2026-10-28.md). 실제 과업지시서와 공공누리 표시 운영자료를 비교했다. 지역 한정은 실제 대상사업에 따라 구체화하며, 서비스 제공자 명칭은 우선 ‘농업 관련 공공기관’으로도 사용할 수 있다.

## 1. 기획 방향

**실제로 생산자를 지원하는 공공기관·부서를 선정한다 → 그 기관의 생산자 지원을 바탕으로 2차 재배공정 서비스를 설명한다 → 같은 기관이 향후 보상환경 지원 서비스까지 제공하면 좋겠다고 제안한다.**

기관 선정의 출발점은 생산자 지원이다. 기존 보상기관을 찾아 재배공정 지원을 추가하는 방향으로 설정하지 않는다. 보상 모니터링·평가·예측·전략·예산 기능은 선정한 생산자 지원기관에 제안하는 확장 서비스다.

## 2. 사기업에서 공공 제공기관을 선택한 이유

생산자의 재배공정 지원을 특정 업체의 설비·고객 관리에 한정하지 않고 지역 생산자의 영농 지원이라는 공공 목적에서 제공하려는 기획이다. 실제 생산자 지원기관의 기술지도·상담·교육·시설원예 지원 업무를 서비스 배경으로 삼고, 생산자가 재배 현황과 기록을 관리하는 도구를 제안한다.

| 선택 근거 | 서비스 배경 |
|---|---|
| 생산자 지원이라는 공공 목적 | 지역 농가가 재배공정을 관리하고 필요한 기술을 활용하도록 지원 |
| 실제 현장 지원 업무와의 연결 | 기술지도·상담·생육환경 개선 업무를 디지털 공정 서비스로 확장 |
| 지속적인 생산자 지원 | 평상시 재배공정 지원을 바탕으로 향후 피해·보상 여건까지 살피는 방향 |
| 역할별 서비스 제공 | 같은 기관의 생산자용 공정 서비스와 내부 담당자용 보상환경 서비스를 구성 |

위 표는 기획 판단이다. 공공기관이 사기업보다 항상 효과적이라는 비교 통계에 근거한 결론은 아니다. 사기업은 장비 연동·개발·유지보수 등 기술 수행에 참여할 수 있다.

### AI·디지털 전환과 연결한 서비스 제공 배경

**기술·정책 변화 → 생산자의 활용 문제 → 지자체의 지원 역할 → 재배공정 디지털화 → 향후 AI 활용** 순서로 설명한다.

**① 기술·정책 배경 — 농업 지원도 데이터와 AI를 활용하는 방향으로 변화**

농촌진흥청은 2026년 2월 농업지능데이터팀 신설을 발표하며 현장 AI 서비스, 농업 데이터 관리, 의사결정 지원을 추진 방향으로 제시했다. 도 농업기술원·시군농업기술센터의 데이터 플랫폼 확산 지원도 포함된다. 중앙의 기술·정책 흐름을 지역 생산자가 활용할 서비스로 연결한다는 기획 근거다. 추진 계획을 모든 지자체의 도입 완료로 해석하지 않는다. [농진청 공식 발표, 2026-02-28](https://www.rda.go.kr/board/board.do?dataNo=100000807900&mode=view&prgId=day_farmprmninfoEntry)

**② 현장 문제 — 생산자가 재배 상황과 기록을 활용할 수 있어야 함**

이번 기획은 생산자가 여러 온실·구역을 관리하면서 현재 재배 단계와 환경, 적용 설정, 실제 조작 결과를 함께 파악하기 어렵고 기록이 흩어져 있다는 문제를 가설로 둔다. AI 기술의 확산이 생산자의 사용 편의로 바로 이어지는 것은 아니므로, 먼저 현황과 이력을 쉽게 확인하고 일상 업무에 활용할 수 있는 서비스가 필요하다고 본다. 실제 불편과 입력 부담은 현장 검증 대상이다.

**③ 공공기관의 역할 — 기존 영농 지원을 현장 데이터 기반 서비스로 확장**

지자체 농업지원기관은 생산자를 대상으로 기술지도·교육·현장 지원을 수행하는 기관 모델이다. 이 역할을 바탕으로 지역 생산자가 디지털 기술을 접하고 실제 재배공정에 활용하도록 지원하는 서비스를 제안한다. 생산자용 도구, 이용 교육, 공정별 기술정보를 함께 제공하고 향후 현장 맥락을 참고한 지원으로 발전시키는 것이 기획 방향이다.

공공 농촌지도의 디지털화는 실제 추진 사례도 있다. 농진청은 2024년 ASTIS 운영을 시작하며 비대면 신청·상담, 과학영농서비스 이용 이력 확인과 담당자의 데이터 기반 사업계획을 설명했다. 이는 공공 생산자 지원의 디지털 전환 근거이며, 우리 재배공정 관리·원격제어 서비스가 ASTIS의 기존 기능이라는 뜻은 아니다. [농진청 ASTIS 운영 발표, 2024-07-08](https://www.rda.go.kr/board/board.do?boardId=farmprmninfo&currPage=116&dataNo=100000796868&mode=updateCnt&prgId=day_farmprmninfoEntry&searchEDate=&searchKey=subject_content&searchOrgDeptKey=org&searchOrgDeptVal=&searchSDate=&searchVal=%EA%B3%84%ED%9A%8D)

**④ 2차 서비스 — 생산자가 직접 쓰는 재배공정의 디지털화**

온실·구역·품종·재배 단계를 기준으로 환경·작업·설정·조작 이력을 연결한다. 생산자는 현재 상태를 확인하고 필요한 관리를 수행한 뒤 결과와 이력을 확인한다. 이를 생산자의 일상 업무를 돕는 디지털 전환으로 설명한다. 장비 제어를 포함한다면 실제 연동 범위와 상태 피드백을 확인하고, 미연동 시연은 시뮬레이션으로 구분한다.

**⑤ 향후 AI 활용 — 기록을 바탕으로 한 분석·판단 지원**

데이터와 검증 기반을 확보한 뒤 재배환경 변화 분석, 이상 징후 탐색, 상황에 맞는 정보 제공 등을 후속 후보로 검토할 수 있다. 더 나아가 같은 기관에 제안할 보상환경 서비스에서는 보상 결과의 품질 평가, 수요·소요예산 예측, 전략·예산 계획으로 활용 범위를 넓히는 안을 제시한다. 이는 확장 방향이며 2차에 AI 모델을 구현했다는 뜻은 아니다.

농식품부도 2026년 생육 이미지 등 AI 학습용 데이터 구축과 민간 AI 솔루션 개발 지원을 발표했다. 이 자료는 AI 활용을 뒷받침할 데이터와 현장 서비스의 중요성을 설명하는 참고이며, 사업 참여나 데이터 연계가 우리 프로젝트에 확보됐다는 뜻은 아니다. [농식품부 공식 발표, 2026-04-22](https://www.mafra.go.kr/bbs/home/792/577708/artclView.do)

### 서비스에서 디지털 전환과 AI를 구분하는 방법

| 구분 | 이번 기획에서의 의미 | 설명 예시 |
|---|---|---|
| 디지털 전환 | 생산자의 공정·환경·작업 정보를 연결하여 업무에 활용 | 구역별 현황 확인, 기록 조회, 설정·조작과 결과 확인 |
| 통계·조건 기반 기능 | 정한 기준으로 집계하거나 상태를 표시 | 기간별 온도 변화, 기준 이탈 표시, 설비 가동시간 집계 |
| 향후 AI 활용 | 데이터·모델·성능 검증 후 판단을 보조 | 이상 징후 분석, 상황별 정보 제공, 보상 수요 예측 등 후보 |

일반 조회·통계·설정 조건에 따른 자동제어를 AI 기능으로 소개하지 않는다. **2차의 중심은 생산자의 디지털 공정 관리이며, AI는 검증을 거쳐 고도화할 방향**으로 둔다.

## 3. 제공기관 유형과 실제 업무 참고

**제공기관 유형: 지자체 농업 관련 공공기관 — 농업기술센터 등**  
**실제 업무 참고 사례: 예산군농업기술센터 스마트원예팀**

공식 직원·업무 안내에는 스마트원예팀의 화훼 관련 민원과 시설원예 생육환경 개선 시범사업 등이 명시돼 있다. 같은 센터의 스마트팜지원팀에는 중소농가 스마트팜 시설보급 등 업무가 제시돼 있다. 생산자·화훼·온실 환경이라는 2차 주제와 직접 연결되는 근거다. [예산군농업기술센터 공식 업무 안내](https://www.yesan.go.kr/prog/deptOnnaraPerson/farm/sub01_01_04/list.do?deptparentcode=4610033%2C4610070%2C4610170%2C4610171)

이 기관 유형을 고르는 이유는 **실제 생산자 지원업무를 바탕으로 디지털 재배공정 서비스를 제공할 배경을 설명할 수 있기 때문**이다. 특정 지자체·부서의 최종 지정이나 실제 도입 협의가 완료된 것은 아니다.

품종별 전문 자료는 충남농업기술원 화훼연구소의 국화 재배법 연구·종묘 보급 자료 등을 참고할 수 있다. 이는 기술 근거의 참고이며 제공기관을 나누는 설정은 아니다. [화훼연구소 공식 소개](https://cnnongup.chungnam.go.kr/sub.cs?m=166)

## 4. 기존 업무를 바탕으로 제안하는 2차 생산자 서비스

**제안:** “화훼 생산자를 지원하고 있는 센터가, 생산자가 평상시 재배공정을 관리할 수 있는 디지털 서비스도 제공하면 좋겠습니다.”

| 구분 | 내용 |
|---|---|
| 실제 업무 배경 | 화훼 관련 현장 업무, 시설원예 생육환경 개선 등 생산자 지원 |
| 2차 액터 | 온실 화훼 생산자 |
| 생산자 문제 가설 | 구역별 상태를 일일이 확인하고, 재배 단계·환경 설정·작업·조작 기록을 다시 찾기 어려움 |
| 서비스 제안 | 재배공정 현황·이력, 환경 설정·비교, 연동 가능한 설비의 중앙·원격제어, 운영 통계 |
| 생산자에게 주는 가치 | 자신의 온실 공정을 파악하고 필요한 관리 후 결과·이력을 확인 |
| 기관과의 관계 | 센터는 서비스 제공기관, 생산자는 해당 서비스를 이용하는 외부 액터 |

공정 예시는 절화국화의 묘 준비 → 정식 → 생육관리 → 개화 조절 → 수확·선별 → 수확 후 관리 → 출하다. 품종·작형에 따라 세부 단계는 달라진다. [농사로 국화 농작업 일정](https://nongsaro.go.kr/portal/ps/psb/psbl/workScheduleDtl.ps?cntntsNo=30672&menuId=PS00087&sKidofcomdtySeCode=210003&totalSearchYn=Y)

생산자 불편과 세부 기능은 설계 가설이며, 센터가 현재 우리 서비스와 같은 온실 제어 플랫폼을 제공한다는 확인 결과는 아니다. 이번 2차는 생산자용 재배공정에 집중한다.

## 5. 같은 기관에 향후 제안할 보상환경 지원 서비스

**제안:** “생산자의 재배를 지원하는 기관이 향후에는 피해·보상 결과까지 분석하여 더 나은 보상환경과 예산 계획을 마련하는 서비스도 제공하면 좋겠습니다.”

| 향후 제안 기능 | 품질담당자가 하는 일 |
|---|---|
| 보상 모니터링 | 보상 처리 현황과 결과를 조회 |
| 통계 분석 | 기간·품목·지역 등 정한 기준으로 보상 현황 비교 |
| 보상 품질 평가 | 후속 설계에서 정할 평가 기준에 따라 보상 결과와 개선점 검토 |
| 예측 | 향후 보상 수요·소요예산 등의 시나리오 검토 |
| 전략·예산 계획 | 평가·예측을 바탕으로 보상환경 개선 전략과 예산 계획 마련 |

이것은 **선정한 생산자 지원기관에 추가로 제안하는 기능**이다. 해당 기관이나 스마트원예팀이 현재 이 모든 보상 업무를 수행한다고 설명하지 않는다. 복구지원·보상금 지급을 직접 수행하는 서비스로 설정하지 않는다.

현재 조직에 전담 기능이 확인되지 않는다면, 같은 센터에 **‘생산자 지원·보상환경 기획 서비스’ 또는 이를 담당할 전담 기능을 두면 좋겠다**고 제안한다. 전담 기능은 가칭이며, 기존 부서의 역할 확장 또는 신규 운영 기능으로 검토할 수 있다. 실제 예산 권한·자료 접근 범위는 도입 설계에서 정한다.

## 6. 같은 기관 안의 두 액터

| 구분 | 생산자 | 품질담당자 |
|---|---|---|
| 관계 | 기관의 생산자 지원 서비스를 이용 | 제안하는 보상환경 서비스를 사용하는 내부 액터 |
| 업무 | 자신의 재배공정·환경·작업·설정·조작 이력 관리 | 보상 모니터링·통계·품질 평가·예측·전략·예산 계획 |
| 기관 설정 | 지자체 농업지원기관의 생산자용 서비스 | 같은 기관에 제안하는 확장 역할 |
| 개발 범위 | **2차의 중심** | 1차 조회 기반은 유지하고 추가 작업은 후속 |

품질담당자는 프로젝트 역할명이다. 실제 스마트원예팀의 공식 직위와 같다고 가정하지 않는다.

## 7. 기획 방향과 구현 순서

- **기획을 설명하는 방향:** 생산자 지원기관의 기존 업무 → 생산자 재배공정 서비스 → 향후 보상환경 서비스 확장 제안.
- **프로젝트 구현 순서:** 1차 보상 지급결과 조회 기반 구현 → 2차 생산자 재배공정 → 후속 품질담당자·피해보상 기능 보완.

1차에 보상 조회를 먼저 구현했다는 사실 때문에 보상 전문기관을 서비스 제공기관으로 골라야 하는 것은 아니다. 1차 결과물은 같은 기관에 제안할 보상환경 서비스의 초기 구현 기반으로 위치시킨다.

## 8. 발표용 문안

> 농업 분야에서도 AI와 데이터 활용이 확대되면서 생산자가 디지털 기술을 실제 영농에 활용하도록 돕는 지원이 필요해지고 있습니다. 이에 저희는 지역 생산자를 지원하는 지자체 농업 관련 공공기관을 서비스 제공자로 설정했습니다. 기존 기술지도와 현장 지원을 디지털 서비스로 확장하여, 화훼 생산자가 온실별 재배 단계·환경·설정·작업 이력을 한곳에서 확인하고 공정을 관리하도록 돕고자 합니다. 2차 스프린트에서는 생산자가 직접 사용하는 재배공정 관리에 집중하고, 축적된 기록을 바탕으로 향후 AI 분석과 맞춤형 지원으로 고도화하는 방향을 제안합니다. 나아가 같은 기관이 보상 결과의 품질을 평가하고 예측을 통해 보상환경 개선 전략과 예산을 계획하는 서비스까지 제공하는 확장안을 제안합니다.

짧은 소개:

> **지자체 농업지원기관이 생산자의 재배공정을 디지털로 연결하고, 향후 AI 기반 분석·지원으로 발전시키는 생산자 중심 농업 서비스.**

## 9. 사실과 제안 구분

- **공식 확인:** 선정 후보 기관·부서의 생산자 지원 업무.
- **이번 제안:** 해당 기관의 생산자용 디지털 재배공정 서비스.
- **향후 확장 제안:** 같은 기관의 보상환경 서비스와 품질담당자 역할.
- **프로젝트 구현 사실:** 1차 지급결과 조회 기반. 통계·평가·예측·예산 전체가 구현된 것은 아님.
- 농금원 정책보험본부를 출발점으로 재배공정을 추가했던 이전 선정안은 사용자 방향과 반대여서 철회한다. 본 문서를 최신 기준으로 사용한다.
