# 시설 화훼 재배 점검표 — 분화 호접란 상세 검토

작성·자료 확인: 2026-11-01  
사용자 선택 품목: **분화 호접란(Phalaenopsis)**  
목적: 메인 UI를 결정하기 전에 실제 재배에서 판단·관찰·측정·기록할 내용을 확인한다.

## 1. 먼저 정할 기준

호접란 재배를 관리하려면 **잎·뿌리를 키우는 과정, 개화를 유도하는 과정, 꽃대·꽃을 상품으로 완성하는 과정**을 나누어야 한다. 잎 길이가 늘어난 것, 꽃대가 나온 것, 출하할 수 있게 된 것은 서로 다른 결과다.

이 문서는 공식 기술자료·원논문에서 확인한 재배 특성과, 서비스 설계를 위해 제안하는 현장 기록 방식을 구분한다. 표의 관찰 빈도·측정 규칙·데이터 구조는 **현장 검토용 제안**이다. 공인 생육조사 표준이나 특정 농장의 검증된 재배 처방으로 간주하지 않는다. 실제 품종·묘 규격·수태·화분·시설 조건은 아직 확인되지 않았다.

### 재배 시작 전에 확인할 질문

| 확인할 내용 | 구체적인 질문 | 관리에 미치는 영향 |
|---|---|---|
| 상품 형태 | 대륜·중륜·미니 중 무엇인가? 한 주씩 출하하는가, 여러 주를 합식하는가? | 목표 크기·꽃대 수·출하 단위가 달라짐 |
| 품종·계통 | 정확한 품종명·공급처 코드·번식 방식은 무엇인가? | 서로 다른 품종의 생육·개화 속도를 같은 기준으로 비교하지 않음 |
| 입고 단계 | 플라스크묘, 순화묘, 중묘, 개화 유도 가능한 성숙묘 중 어느 단계인가? | 농장이 실제 수행할 재배 공정 결정 |
| 입고 품질 | 입고일·수량, 잎·뿌리 상태, 크기 편차, 병해충 의심주는? | 입고 당시 문제와 재배 중 발생 문제를 구분 |
| 목표 출하 | 언제, 누구에게, 어떤 개화 상태와 규격으로 납품하는가? | 개화 유도·선별·포장 일정의 출발점 |
| 재배 위치 | 어느 온실·환경 제어구역·베드에 어느 배치가 있는가? | 환경·작업·생육을 같은 대상에 연결 |
| 온실 역할 | 육묘·영양생장·개화 유도·개화 마무리 구역이 구분되는가? | 서로 다른 단계에 같은 설정을 적용하지 않음 |
| 화분·배지 | 화분 직경·용량·배수구, 수태/바크 조성, 충전량·조밀도는? | 마르는 속도와 뿌리 주변 공기·수분 조건에 영향 |
| 원수 | 상수·지하수·빗물 중 무엇이며 수질 분석 이력이 있는가? | 관수·양분 관리 기준 결정 |
| 노동·설비 | 누가 생육을 확인하고 어떤 난방·냉방·차광·관수 설비를 쓰는가? | 실제 실행 가능한 기록·조치 수준 결정 |

농사로의 소형 호접란 연구 소개도 식물체 크기·엽수·엽폭과 꽃대 수·길이·꽃 수를 함께 조사한다. 대형·미니의 시험 결과가 다르므로 재배 기간 하나를 모든 호접란에 적용하지 않는다. [S1]

## 2. 재배 단계별로 무엇을 판단하는가

아래는 관리상 사용하는 단계 구분안이다. 실제 재배에서는 잎·뿌리 생장과 꽃 발달이 겹칠 수 있다. 날짜만 지났다고 다음 단계로 자동 전환하지 않는다.

| 관리 단계 | 가장 중요한 질문 | 식물에서 확인할 내용 | 환경·작업에서 함께 확인할 내용 | 남길 사건 |
|---|---|---|---|---|---|
| 입고·검수 | 계획한 묘가 건강하게 들어왔는가? | 잎·뿌리 손상, 균일도, 병해충 의심, 고사 | 운송 이력, 입고 배지·화분, 분리 관찰 위치 | 입고일·배치·검수 결과 |
| 순화·활착 | 새 환경에서 수분 균형을 회복하고 새뿌리가 나오는가? | 시듦 변화, 새뿌리 끝, 새잎, 생장점 상태 | 급격한 광·온습도 변화, 배지 수분, 환기 | 이식·분갈이일, 활착 확인일 |
| 영양생장 | 출하 목표에 필요한 잎과 뿌리를 확보하고 있는가? | 새잎 전개, 같은 잎의 길이·폭 변화, 엽수, 엽폭장, 뿌리 활력 | 주야 온도, 광량, 관수·양분, 밀도·간격 | 정기 생육 조사, 간격 조정 |
| 개화 유도 준비 | 이 배치를 유도 구역으로 옮겨도 되는가? | 품종별 성숙도·균일도, 건전한 뿌리, 불량주 비율 | 출하 역산 일정, 냉방 능력, 적용할 품종별 조건 | 유도 대상 선정·제외 이유 |
| 개화 유도 | 적용 조건과 실제 식물 반응이 일치하는가? | 눈에 보이는 꽃대 발생일·발생 주수, 무반응주 | 유도 시작일, 실제 주야 온도 이력, 광량, 구역 이동 | 유도 시작·종료, 첫 꽃대 확인 |
| 꽃대 신장·봉오리 발달 | 꽃대와 봉오리가 상품 규격으로 발달하는가? | 꽃대 수·길이·방향, 분지, 봉오리 수·탈락·기형 | 지주·유인, 광 방향, 온습도 변화, 작업 손상 | 유인일, 봉오리 관찰 기록 |
| 개화·상품 마무리 | 주문에 맞는 개화 상태와 외관인가? | 개화 수, 봉오리 수, 꽃 크기·색·배열, 잎·뿌리 품질 | 화분 정리, 선별, 합식, 포장, 출하 환경 | 첫 개화일, 등급·보류 사유 |
| 출하·재배 결과 | 어느 배치가 얼마나 출하되고 무엇이 남았는가? | 출하 적합주, 보류·폐기·반품 | 수량·출하일·판매 규격·실제 비용 | 출하·폐기·반품·잔량 |

**개화 유도를 시작했다는 작업 기록과 꽃대가 보였다는 관찰 기록은 분리한다.** 내부의 꽃눈 분화를 일반 사진으로 직접 확인했다고 기록하지 않는다.

온도는 영양생장 유지와 꽃대 발생에 중요한 요인이다. 두 클론을 시험한 원논문에서는 낮 29℃/밤 17℃ 조건에서도 꽃대 발생이 억제되었고, 주야 온도차 자체가 꽃대 발생의 필수 조건은 아니었다. 따라서 ‘밤만 낮추면 된다’는 규칙으로 설계하면 안 된다. 논문의 온도는 특정 시험 조건이며 해당 농장 설정값으로 바로 사용하지 않는다. [S2]

## 3. ‘생장을 어떻게 확인하나’ — 실제 측정 항목

### 3.1 잎·뿌리: 식물체를 키우는 과정

| 항목 | 현장에서 확인·측정하는 방법 제안 | 기록 단위·형식 | 무엇을 판단할 때 쓰는가 / 주의점 |
|---|---|---|---|
| 새잎 발생·전개 | 생장점에서 새잎이 보인 날짜와 전개 상태를 구분 | 날짜, 미전개/전개 중/전개 확인 | 새잎 생성과 기존 잎의 신장을 구분 |
| 엽수 | 정한 기준으로 잎을 세고 새잎·탈락 잎을 별도 기록 | 매/주 | 작은 새잎을 포함했는지 조사자마다 달라지지 않게 정의 |
| 같은 잎의 길이 | 잎 ID를 붙여 기부부터 끝까지 정한 경로로 측정 | cm, 잎 ID, 측정일 | 다른 잎을 비교하면 신장량으로 해석할 수 없음 |
| 같은 잎의 폭 | 같은 잎의 가장 넓은 부분을 잎을 손상시키지 않고 측정 | cm, 잎 ID | 길이만 늘어나는지 폭도 함께 발달하는지 확인 |
| 잎 전체 펼침 폭 | 위에서 본 자연스러운 잎 끝 간 폭을 같은 방향·자세로 측정 | cm, 측정법 코드 | 공간 점유·균일도 확인. 잎 하나의 폭과 구분 |
| 잎의 탄력·주름 | 같은 관찰 기준과 사진으로 비교 | 정상/주름/시듦 등 관찰 분류 | 수분 스트레스의 단서. 원인을 바로 확정하지 않음 |
| 잎 색·반점·손상 | 위·아래 잎, 잎 앞·뒷면과 발생 위치 확인 | 사진, 위치, 증상, 영향 주수 | 황화·반점·일소 의심 등을 구분하여 추적 |
| 생장점·잎 사이 | 생장점 손상, 물 고임, 물러짐 등 확인 | 관찰·사진·발견일 | 계속 새잎을 만들 수 있는지 확인 |
| 새뿌리 활동 | 보이는 새뿌리 끝의 유무·활동 위치를 같은 각도에서 비교 | 활동 있음/미관찰/확인 불가, 사진 | 색 하나로 정상·비정상을 단정하지 않음 |
| 뿌리의 상태 | 투명 화분 등에서 보이는 범위의 굵기·탄력·마름·물러짐 확인 | 관찰 범위, 증상, 사진 | 보이지 않는 화분 내부까지 건강하다고 확대 해석하지 않음 |
| 뿌리 손상 분포 | 화분 위·측면·바닥, 특정 수태 배치에 집중되는지 확인 | 위치·발생 주수·배지 배치 | 관수 편차·염류·배지 품질 등 확인 대상 좁히기 |
| 고사·불량주 | 발견일과 분류·처리 내용을 기록 | 주, 원인 미확정/검사 확인 구분 | 정상 표본만 남아 평균이 좋아 보이는 현상 방지 |

**측정 규칙 예시:** 새잎이 나와도 기존 잎의 ID는 바꾸지 않는다. 새잎을 L07로 등록했다면 이후에도 같은 L07을 측정한다. 잎을 교체해 조사할 때에는 교체를 기록한다. 자의 눈금·측정 경로·사진 방향도 통일한다.

예를 들어 L07이 10월 25일 8.0cm, 11월 1일 9.4cm이면 관찰된 신장량은 7일간 1.4cm다. 이는 **계산 예시**이며 정상 신장 속도를 뜻하지 않는다. 해당 품종·단계의 이전 기록과 비교해야 한다. ‘이번 주 가장 큰 잎’과 ‘지난주 가장 큰 잎’이 다른 잎이면 같은 방식으로 계산하지 않는다.

뿌리는 젖음에 따라 외관 색이 달라지며, 활동하는 끝부분의 색도 달라질 수 있다. 뿌리 색만으로 관수를 결정하지 않고 탄력·손상·배지 수분을 함께 확인한다. 가정 재배 자료의 고정 관수 간격을 상업 농장의 수태·화분에 그대로 옮기지 않는다. [S3]

### 3.2 꽃대·꽃: 발달과 상품 완성 과정

| 항목 | 측정·관찰 규칙 제안 | 단위·형식 | 해석할 때 확인할 내용 |
|---|---|---|---|
| 첫 꽃대 확인일 | 꽃대임을 확인할 수 있는 상태와 사진을 기준으로 기록 | 날짜·사진 | 유도 시작일과 구분; 뿌리와 혼동하면 미확정 |
| 꽃대 발생 주수 | 조사한 주 중 꽃대가 확인된 주 수 | 발생 주수/조사 주수 | 표본 조사인지 전수 조사인지 표시 |
| 꽃대 수 | 한 주에서 나온 주 꽃대와 분지를 구분 | 개/주 | 한 화분 안 여러 주를 합친 값과 혼동 방지 |
| 꽃대 길이 | 꽃대 ID별로 발생 기부부터 끝까지 같은 경로로 측정 | cm, 꽃대 ID | 유인 후 높이와 실제 길이는 다름 |
| 꽃대 굵기 | 필요할 때 정한 위치에서 손상 없이 측정 | mm, 측정 위치 | 위치가 다르면 비교 불가; 모든 농가의 필수 입력으로 두지 않음 |
| 봉오리 수 | 봉오리·개화·탈락을 구분하여 셈 | 개/꽃대 | 개화 때문에 줄어든 봉오리를 피해로 계산하지 않음 |
| 첫 개화일 | 정한 개화 판정 기준을 적용 | 날짜 | 유도·꽃대 확인 후 소요일수 확인 |
| 개화 수·남은 봉오리 | 같은 날 꽃대별 개화 수와 봉오리 수 기록 | 개/꽃대 | 주문한 출하 상태와 비교 |
| 꽃 품질 | 꽃 크기·색·배열·반점·기형·손상과 지주·유인 상태 | cm 또는 정의한 분류·사진 | 품종별 특징과 납품처 규격을 기준으로 평가 |
| 출하 적합 여부 | 합의된 규격을 만족하는지 판정 | 적합/보류/제외, 사유 | 개화 수만으로 상품성을 판정하지 않음 |

농사로 자료에서 사용하는 엽수·엽폭·꽃대 수·꽃대 길이·꽃 수는 이 항목 구성의 근거다. 위의 잎 ID·사진 방식 등은 이 서비스에서 비교 가능한 기록을 얻기 위한 제안이다. [S1]

## 4. 표본은 어떻게 뽑고 얼마나 자주 볼 것인가

### 현장 운영안

1. **같은 품종·입고 배치·재배 단계·화분·배지 조건**을 우선 하나의 비교 집단으로 정한다.
2. 구역 안 위치 차이를 반영하여 표본을 나눈다. 중앙과 출입구·측창·냉난방 영향 구역 등을 구분하고 위치를 남긴다. 상태가 좋아 보이는 주만 골라서는 안 된다.
3. 추적할 주에 ID를 붙이고 같은 주·잎·꽃대를 반복 조사한다. 이동·폐기·표본 교체 이력을 보존한다.
4. 시간대·관수 전후·사진 거리·측정법을 가능한 한 일정하게 한다. 시듦과 배지 수분은 특히 관수 전후가 중요하다.
5. 평균과 함께 조사 주수, 분포·편차, 이상주 수를 본다. 표본이 작거나 편향되면 배치 전체의 비율로 단정하지 않는다.
6. 이상주와 정상주를 따로 비교하되, 이상주만 골라 조사한 결과를 전체 발생률로 쓰지 않는다.

**조사 주수는 미확정이다.** 면적·배치 규모·균일도·위치 편차·인력·판단 목적을 보고 정한다. 기존 자료에 있는 일정 비율을 검증 없이 ‘전체의 10% 이상 필수’로 채택하지 않는다.

빈도는 우선 **매일 순회 관찰 + 주 1회 같은 표본의 잎·뿌리 조사 + 꽃대·봉오리 발달기에는 필요한 항목을 더 자주 확인**하는 안으로 검토한다. 이는 농가의 노동량과 변화 속도로 조정할 운영 제안이며 공인 권장 주기가 아니다. 이상 발생·이식·설정 변경·정전 후에는 별도 확인을 남긴다.

## 5. 온실 내부 환경 — 숫자마다 대상과 위치가 있어야 한다

| 관리 요소 | 확인할 값·이력 | 측정 위치·방법에서 확인할 것 | 농가의 판단과 연결 |
|---|---|---|---|
| 공기 온도 | 현재, 주야·24시간 평균, 최저·최고, 설정 범위 밖 지속시간 | 식물 높이·차광·통풍 조건, 직사광·난방기 영향, 구역 ID | 생장·개화 단계의 목표와 실제가 맞는가? |
| 상대습도 | 현재·주야 변화, 높은 습도가 지속된 시간 | 온도 센서와 가까운 위치·같은 시각 | 잎 젖음·건조·환기 상태를 함께 볼 필요가 있는가? |
| 이슬점·결로 | 계산 이슬점, 잎·꽃 젖음, 필요시 잎 온도 | 공기 온습도만으로 잎 표면 결로를 직접 측정했다고 하지 않음 | 특히 야간·새벽의 젖음과 건조 지연 확인 |
| VPD | 온도·습도에서 계산한 공기 VPD, 계산 시각 | 공기 기준인지 잎 온도를 반영한 값인지 명시 | 수분 손실 환경을 해석하는 보조 지표 |
| 빛 | 식물 높이의 PPFD, 하루 누적 DLI, 차광·보광 이력 | 차광막 아래 실제 작물 위치, 센서 수평·청결·그늘 편차 | 빛 부족·과다 가능성을 생육과 함께 확인 |
| CO₂ | 주야 변화, 환기·공급 설비 작동 이력 | 센서 위치·교정·실제 공급 여부 | 호접란 생리와 설비 조건을 반영해 해석 |
| 배지 수분 | 대표 화분의 젖음·건조 변화, 가능하면 무게·수분 센서값 | 화분·수태별 센서 보정, 삽입 위치, 관수 전후 | 오늘 물을 줄 필요가 있는가? 구역별 편차가 있는가? |
| 뿌리 주변 온도 | 화분·배지 온도와 주야 변화, 필요시 측정 | 공기 온도와 구분, 대표 화분 위치 | 차가운 관수·시설 위치 등의 영향을 확인 |
| 배지·급수 화학성 | 원수·급액·배액·배지 추출액의 EC·pH | 시료 구분, 추출법, 단위, 관수 후 경과시간 | 공급과 실제 뿌리 주변 상태가 다른가? |
| 공기 흐름·설비 | 환기·순환팬·차광·난방·냉방·관수의 상태와 고장 | 명령·실제 작동·피드백을 분리 | 설정값은 맞는데 실제 환경이 다른 이유 확인 |

온도·습도는 함께 해석해야 한다. UMass는 온습도 센서의 차광·통풍과 가까운 위치 측정을 설명한다. **공기 VPD만으로 뿌리의 물 흡수나 호접란의 생장을 직접 측정한 것으로 표현하지 않는다.** [S4]

빛은 ‘지금 몇 lx인가’와 ‘오늘 식물이 받은 광량’을 구분한다. PPFD는 순간 광자속 밀도(μmol·m⁻²·s⁻¹), DLI는 하루 누적 광량(mol·m⁻²·d⁻¹)이다. lux는 사람의 시감도 기준이므로 광원·조건을 모른 채 PPFD로 고정 환산하지 않는다. 하루 중간의 누적값과 종료된 하루의 DLI도 구분한다. [S5]

호접란은 CAM 광합성을 하므로 야간 CO₂ 흡수와 주야 변화가 중요하다. 일반적인 주간 흡수 작물의 규칙을 그대로 적용하지 않는다. 이 점은 야간 환경을 기록해야 하는 근거이며, CO₂ 공급 설비 도입이나 농도·공급 시간 처방을 뜻하지 않는다. [S6]

**최소 확인 수단과 추가 센서를 구분한다.** 뿌리·잎 육안 관찰, 휴대 측정기, 대표 화분 수분 확인부터 시작할 수 있다. 잎 온도·연속 배지 수분·CO₂ 등은 현장 설비와 실제 판단 필요성을 확인해 추가한다. 센서가 없으면 ‘미측정’으로 남긴다.

### 온실마다 값 하나로 충분한가

온실별 대표 센서값은 빠른 확인에 유용하지만 같은 동 안에서도 제어구역·베드·차광·위치에 따라 조건이 다를 수 있다. 다음 정보를 연결한다.

- 어느 온실·제어구역·센서인지, 어느 배치를 대표하는지.
- 마지막 측정 시각과 정상 수신 여부.
- 대표 센서값인지 여러 센서의 평균인지, 평균이라면 포함 센서와 집계 방법.
- 주야 이력과 위치별 차이. 미수신·센서 이상을 정상값이나 0으로 표시하지 않음.

## 6. 관수·수태·뿌리 관리에서 놓치기 쉬운 내용

### 관수 전

- 같은 구역의 화분들이 비슷한 속도로 마르는가? 중앙·가장자리, 큰 주·작은 주가 다른가?
- 수태 표면만 마르고 화분 안쪽은 계속 젖어 있지 않은가?
- 화분 크기·배수구, 수태 충전량·조밀도, 수태 사용 기간·입고 배치가 같은가?
- 보이는 뿌리의 탄력·새뿌리 끝·손상과 잎의 주름을 함께 확인했는가?
- 관수 필요성을 화분 무게로 판단한다면 같은 화분·배지·측정 시점을 쓰는가? 식물체가 자라면서 기준 무게를 갱신하는가?

### 관수 중·후

- 물의 공급 대상·시작/종료 시각·급수량·급액 EC·pH·필요시 수온을 남겼는가?
- 특정 노즐·라인의 막힘이나 과다 공급이 있는가? 대표 화분의 실제 도달량은 비슷한가?
- 물이 빠지는가? 화분 받침·합식 용기·베드에 물이 오래 고이지 않는가?
- 잎 사이·생장점·꽃에 물이 남는가? 젖은 부위가 마르는 조건인가?
- 같은 관수 후에도 계속 젖어 있는 화분과 빨리 마르는 화분이 어디에 있는가?

제주 농업기술원 자료는 수태의 충전량·건조 상태·물리적 변화가 균일한 물 관리에 영향을 줄 수 있음을 설명한다. 오래된 자료의 차광률·관수 수치는 현재 품종의 설정값으로 사용하지 않고, **배지 자체를 관리 단위에 포함해야 한다는 근거**로 활용한다. [S7]

‘매일 물 주기’나 ‘며칠마다 관수’를 모든 배치의 고정 규칙으로 두지 않는다. 물을 줬다는 완료 기록에는 대상·시각·실제 양과 관찰 결과가 필요하다. [S3, S7]

## 7. 양분·EC·pH — 측정값을 해석할 조건

| 구분 | 기록할 내용 | 같은 EC 숫자라도 다른 의미인 이유 |
|---|---|---|
| 원수 | 수원·수질 분석일, EC·pH, 필요시 알칼리도·성분 분석 | 물 자체의 염류와 산 중화 능력 확인 |
| 급액 | 비료 제품·성분, 조제 내용, 측정 EC·pH, 공급 시각·양 | 화분에 공급한 용액의 상태 |
| 일반 관수 배액 | 채취 대상 화분·시간·양·채취 조건 | 관수 방법과 흐름에 영향을 받음 |
| 배지 추출액 | 배지·화분·추출법·희석비·시료 조건·분석 기관 | PourThru, 포화 추출, 희석 추출 등 방법이 다름 |
| 기기 | 교정일·표준액·단위·온도 보정 | 측정 오차와 단위 혼동을 확인 |

배지 검사법별로 EC 해석 범위가 달라진다. **급액 EC, 평소 배액 EC, 표준 방법으로 얻은 배지 추출액 EC를 하나의 정상 범위로 판정하지 않는다.** EC만으로 특정 양분이 충분하다거나 어떤 성분이 쌓였다고 확정하지 않는다. pH와 함께 필요시 원수·배지·식물체 분석을 연결한다. [S8]

국내 현장 지원 사례에서는 수태의 높은 염농도와 낮은 pH, 새뿌리 끝 손상·하엽 황화·생장 저하를 함께 조사하여 염류 축적에 의한 장애로 판단했다. 이는 **잎 이상 → 비료 추가**로 바로 연결하지 말고 뿌리·배지·공급 이력을 확인해야 하는 실제 사례다. 그 사례의 수치·조치가 모든 농가의 기준은 아니다. [S9]

## 8. 이상이 보이면 어떤 순서로 확인하는가

아래는 진단명이 아니라 **추가 확인 순서**다. 동일한 증상에 여러 원인이 있을 수 있고 환경 이력이 겹칠 수 있다.

| 발견한 변화 | 먼저 남길 증거 | 함께 확인할 내용 | 판단·작업 기록 |
|---|---|---|---|
| 새잎이 이전보다 덜 자람 | 같은 잎의 연속 측정, 품종·단계·표본 수 | 뿌리 활동, 배지 수분·EC·pH, 주야 온도·광량, 입고·분갈이 이력 | 측정 재확인, 원인 후보, 재조사 시점 |
| 잎이 쭈글거리거나 처짐 | 어느 잎·어느 위치·몇 주인지, 관수 전후 사진 | 물 부족과 뿌리 손상 모두 확인, 화분 안 수분·배수 | 물이 부족하다고 즉시 단정하지 않음 |
| 새뿌리 끝이 마름·멈춤 | 뿌리 사진, 같은 배지 배치의 정상주 비교 | 염류·수분·배지 품질·작업 손상·병 의심 | 필요시 분석 의뢰, 영향 배치 구분 |
| 유도 후 꽃대가 잘 안 보임 | 유도 시작일·대상 주수·발생 주수·판정 사진 | 묘의 성숙도, 품종, 실제 낮·밤 온도, 광량, 위치 편차 | 유도 설정을 바꾸기 전 실제 이력 확인 |
| 봉오리가 마르거나 떨어짐 | 꽃대 ID, 봉오리/개화/탈락 수, 발생 시점 | 급격한 환경 변화, 수분 상태, 이동·유인 손상, 해충, 배기가스·에틸렌 가능성 | 원인 미확정 표시, 납품 영향·후속 확인 |
| 잎·꽃에 반점·물러짐 | 부위·확산 속도·발생 구역·사진 | 젖음·결로·관수 비산·작업 접촉·해충 흔적 | 의심주 구분, 전문가 확인·검사 결과 |
| 같은 동 안 일부만 불량 | 위치 지도, 정상·불량 표본 비교 | 차광·바람·냉난방 위치, 관수 라인, 품종·입고·수태 배치 | 원인 후보별 추가 측정 |

온실과 출하 과정의 에틸렌 노출은 꽃·봉오리 품질에 영향을 줄 수 있다. 난방기 배기·차량 배기가스 등은 의심 원인을 확인할 때 검토한다. CO₂ 센서가 에틸렌을 측정하는 것은 아니다. [S10]

## 9. 병해충·위생 관리

정기 예찰은 이름·위치·발생 추세와 조치 효과를 확인하는 과정이다. 트랩만으로 모든 해충·병을 확인할 수 없으므로 식물 직접 관찰과 함께 쓴다. [S11]

- 입고 시 의심주를 구분하고 다른 배치로 옮겨가기 전에 확인한다. 분리 관찰 기간은 농장 방침과 위험에 따라 정한다.
- 잎 앞·뒷면, 잎 사이, 꽃대·봉오리, 화분·배지를 정한 동선으로 살핀다.
- 트랩은 ID·위치·설치/교체일·관찰 기간·동정 결과·포획 수를 남긴다. 기간이 다른 포획 수를 그대로 비교하지 않는다.
- 병·해충 이름이 확인되지 않았으면 ‘의심 증상’으로 저장한다. 사진이나 환경값만으로 확진하지 않는다.
- 확인한 주수와 증상 주수를 함께 기록한다. 정기 표본 조사와 이상주 중심 조사는 구분한다.
- 가위·작업대·용기, 작업자 동선, 관수 비산·배수 공유 등을 위생 점검에 포함한다.
- 방제 작업은 대상·확인된 문제·제품·실제 사용 내용·작업자·작업일·후속 결과를 남긴다. 약제 선택·희석·사용 조건은 해당 작목의 최신 등록·표시사항을 확인한다. 과거 자료나 첨부 파일의 제품명을 처방으로 자동 적용하지 않는다.

## 10. 출하·생산계획·비용도 재배와 연결한다

### 상품 규격

- 품종·화색·화분 크기·주 수, 주당 주 꽃대 수와 합식 상품당 꽃대 수를 구분한다.
- 꽃 크기·꽃 수·개화 상태·배열·높이·잎과 뿌리의 외관 등 납품처가 실제 요구하는 항목을 정한다.
- ‘생물학적 첫 개화’와 ‘납품 가능한 상태’를 분리한다.
- 출하 전 지주·유인·청결·포장·운송 중 손상과 품질 변화를 확인한다. 운송 온도 등은 품종·출하 형태에 맞게 별도 정한다.

### 수량·일정

- 입고 주수, 살아 있는 재배 주수, 폐기·시험 채취·이동·출하·반품을 이력으로 관리한다.
- 온실 이동은 생산 수량 증가가 아니다. 이동 전후 위치와 시각을 보존한다.
- 한 배치를 나눠 출하하거나 여러 배치를 합식하면 원래 배치를 추적할 수 있어야 한다.
- 식물체 수(주), 재배 화분 수(분), 합식 상품 수, 상자 수의 환산 기준을 남긴다.
- 계획 출하일과 확정 출하일을 구분하고, 생육 지연을 반영해 계획을 갱신한다.

### 비용·경영

- 묘·화분·배지·비료·방제·포장·지주·인건비·에너지 사용을 가능하면 대상 배치·작업과 연결한다.
- 냉난방·공간 점유·작업 인력의 한계를 출하 계획과 함께 확인한다.
- 판매액·입금액·수수료·운송비·반품 비용을 구분한다. 현금 수입−지출을 곧바로 순이익으로 표시하지 않는다.

## 11. 현장 점검 순서 제안

| 시점 | 우선 점검 | 남길 기록 |
|---|---|---|
| 아침 작업 전 | 야간·새벽 온습도 이력, 설비·정전·미수신, 결로·식물 이상, 배지 건조 상태 | 확인이 필요한 구역·배치와 오늘 작업 |
| 관수 판단 시 | 대표 화분의 내부 수분·무게·뿌리, 위치별 편차, 급수 설비 | 관수 판단 근거·실시 여부 |
| 작업 직후 | 실제 대상·양·시간·작업 결과, 식물 손상 | 계획과 실제, 다음 확인일 |
| 정기 생육 조사 | 같은 표본의 잎·뿌리, 해당 단계의 꽃대·봉오리·개화 | 측정값·사진·조사 주수·편차 |
| 개화 유도 전후 | 대상 성숙도·이동 이력·실제 주야 환경·꽃대 발생 | 단계 변경 근거·발생 주수 |
| 환경 설정·배지·비료 변경 후 | 변경 이유, 대상, 실제 적용, 이후 반응 | 변경 전후 비교와 재확인 결과 |
| 출하 전후 | 주문 규격·적합/보류·실제 출하·잔량·반품 | 배치별 출하 결과 |

## 12. 관리 화면에 연결할 때의 원칙

현재 화면을 바로 수정하기보다 위 점검 항목 중 농가가 실제 판단하는 항목과 기록 가능한 항목을 먼저 확정한다.

1. **온실 선택 안에서 배치·단계·환경·식물 상태를 함께 본다.** 같은 온실에 여러 단계가 있으면 제어구역·베드·배치를 추가로 선택한다.
2. 생육 상태는 최근 관찰일·조사 주수·항목과 함께 표시한다. 센서가 정상이어도 식물 생육 ‘정상’을 자동 확정하지 않는다.
3. 관수 필요는 공기 습도 하나로 판정하지 않는다. 배지 수분·뿌리와 실제 판단 기록을 연결한다.
4. 영양생장 중에는 새잎·뿌리, 유도 중에는 실제 온도 이력·꽃대 발생, 마무리 중에는 봉오리·개화·출하 적합을 우선한다.
5. ‘생장 80%’ 대신 뜻이 분명한 지표를 쓴다. 예: **꽃대 확인 16/20주(표본 조사)**. 이는 조사 대상의 관찰 결과이지 배치 전체의 성장 완료율이 아니다.
6. 최근 기록 없음·측정 불가·설비 미연결·센서 미수신을 각각 표시한다. 공란을 정상으로 해석하지 않는다.
7. 설정 변경·작업 수행과 이후 식물 반응을 시간순으로 연결한다. 동시 발생만으로 원인이 입증됐다고 표시하지 않는다.

### 첫 화면에 검토할 정보

- 선택한 온실·구역 / 품종·배치 / 현재 관리 단계·확인일.
- 실제 내부 환경과 야간 이력, 측정 시각·대표 센서 위치.
- 최근 잎·뿌리 관찰 또는 꽃대·개화 관찰 결과.
- 배지 수분·급액/배지 검사에서 확인이 필요한 사항.
- 오늘 할 일, 미확인 이상, 다음 생육 조사, 목표 출하 일정.

### 처음부터 전부 입력하게 하지 않을 항목

현장 관찰·휴대 측정으로 시작하고, 필요가 확인된 항목을 단계적으로 추가한다. 조직·건물중 등 파괴 조사, 모든 화분의 일일 정밀 측정, 근거가 없는 AI 생장 점수는 기본 필수 입력으로 두지 않는다.

## 13. 농가 확인 후 확정해야 할 사항

현재는 대표 품목이 **분화 호접란**이라는 점만 확정되었다. 다음은 실제 농가 인터뷰·재배 책임자 검토가 필요한 항목이다.

| 항목 | 확정할 결과물 |
|---|---|
| 대표 품종·상품 유형 | 대륜/미니, 화분·합식 구성, 목표 규격 |
| 입고 규격·농장 수행 단계 | 순화부터 하는지, 중묘·성숙묘부터 하는지 |
| 위치·제어 구성 | 온실·제어구역·베드·배치 지도, 이동 방식 |
| 배지·화분·관수 | 수태/바크, 화분 규격, 공급·배수 방식, 수질 |
| 실제 생육 판정 | 농가가 현재 보고 재는 항목, 정상·이상 판단 사례 |
| 조사 운영 | 표본 선정·주수·측정법·빈도·담당자 |
| 단계별 환경 기준 | 품종·단계·주야 목표, 허용 이탈 시간, 근거·수정 이력 |
| 검사 운영 | EC·pH 시료·추출법·단위·분석 기관, 교정 방법 |
| 출하 판정 | 개화 상태·꽃대·외관의 주문별 기준, 보류·폐기 분류 |
| 작업·설비 연계 | 수동 기록/센서/제어기에서 실제 얻을 수 있는 항목 |

**우선 현장 확인할 세 가지:** (1) 현재 쓰는 품종·묘·화분·수태, (2) 영양생장과 개화 유도 구역 운영, (3) 농가가 출하 가능하다고 판단하는 실물 기준. 이것이 정해져야 목표 환경 범위와 메인 화면의 생육 정보를 구체화할 수 있다.

## 14. 조사 출처와 적용 범위

공식 기관·대학 지도자료와 원논문을 우선 확인했다. 검색 결과에 표시된 수집·게시 시각과 원자료의 발행연도는 다를 수 있다. 오래된 기술자료의 온도·광·비료·약제·재배 기간을 최신 처방으로 재사용하지 않았다.

- **S1. 농촌진흥청·국립원예특작과학원, 「난(팔레놉시스) 소형 상품화 기술 — 미니 난의 적정 생육단계」, 2017.** [공식 시나리오](https://www.nongsaro.go.kr/portal/ps/psb/psby/vodPlay.ps?menuId=PS65512&mvpClipNo=2&mvpNo=641). 생육·개화 관찰 항목과 상품 유형에 따른 차이를 참고. 시험 기간·처리 온도의 보편 적용은 하지 않음.
- **S2. Blanchard & Runkle, 2006, Journal of Experimental Botany.** [Temperature during the day, but not during the night, controls flowering of Phalaenopsis orchids](https://academic.oup.com/jxb/article/57/15/4043/548164). 두 클론의 주야 온도 반응 연구. 밤 온도차만으로 유도를 판정하는 설계의 문제를 확인.
- **S3. Wang·Blanchard·Lopez·Runkle, 「Growing the Best Phalaenopsis, Part 2」, Orchids, 2007.** [대학 공개 원문](https://www.canr.msu.edu/uploads/resources/pdfs/5_-_growing_best_phals_part_2.pdf). 뿌리·배지·수분·양분의 연관을 참고. 바크·화분 조건의 관수 간격을 국내 수태 재배에 그대로 적용하지 않음. 뿌리 외관은 [Texas Cooperative Extension 자료](https://bexar-tx.tamu.edu/homehort/archives-of-weekly-articles-davids-plant-of-the-week/growing-phalaenopsis/)도 교차 확인.
- **S4. UMass Amherst Extension.** [What is a Weather Station and Can it Benefit Ornamental Growers?](https://www.umass.edu/agriculture-food-environment/landscape/fact-sheets/what-is-weather-station-can-it-benefit-ornamental-growers). 온습도 센서 조건·VPD의 의미를 참고. 호접란 적정 VPD 수치의 근거로 사용하지 않음.
- **S5. Purdue Extension, HO-238.** [Measuring Daily Light Integral in a Greenhouse](https://ag.purdue.edu/department/hla/extension/extension-publications-library/ext-pubs/ho-238-w.html). PPFD·DLI·lux와 측정 위치의 구분. 오래된 보광 설비 경제성 설명이나 일반 화훼 DLI 수치를 호접란 처방으로 사용하지 않음.
- **S6. 「Effects of chilling on the photosynthetic performance of the CAM orchid Phalaenopsis」, 2022.** [원논문 공개본](https://pmc.ncbi.nlm.nih.gov/articles/PMC9732388/). CAM의 주야 가스 교환과 환경 스트레스 반응을 참고. 실험 품종·저온 결과를 재배 설정값으로 사용하지 않음.
- **S7. 제주특별자치도 농업기술원, 성문석, 「팔레놉시스」.** [기술자료 PDF](https://agri.jeju.go.kr/files/board/화훼류(팔레놉시스).pdf). 순화·수태·균일한 관수 관리 검토. 원문 발행연도는 이번 확인에서 특정하지 못했으며, 현재 품종·종묘 시장 설명이나 수치를 최신 기준으로 사용하지 않음.
- **S8. Purdue Extension, HO-237.** [pH and Electrical Conductivity Measurements in Soilless Substrates](https://ag.purdue.edu/department/hla/extension/extension-publications-library/ext-pubs/ho-237-w.html). 추출법별 EC 해석 차이와 측정 조건. 일반 작물의 수치표를 해당 농장 수태의 기준으로 적용하지 않음.
- **S9. 농촌진흥청 현장기술지원, 울산 북구, 기술지원일 2024-12-17.** [호접란 생육불량 원인규명 현장 기술지원 결과](https://nongsaro.go.kr/portal/ps/psz/psza/contentSub.ps?cntntsNo=257535&menuId=PS00077&totalSearchYn=Y). 수태 화학성·뿌리·잎 증상을 함께 조사한 실제 사례. 사례 속 농약·비료 사용 내용을 추천으로 전환하지 않음.
- **S10. Erik Runkle, Michigan State University, 2019.** [Ethylene in floriculture](https://www.canr.msu.edu/floriculture/uploads/files/ethylene%20in%20floriculture.pdf). 온실·운송의 에틸렌과 배기 등 오염원 점검 근거. 약제·처리 농도는 제안하지 않음. 호접란의 출하 민감성은 [대학 공개 호접란 생산자료](https://www.canr.msu.edu/uploads/resources/pdfs/orchidspart4.pdf)도 확인.
- **S11. UMass Amherst Extension.** [IPM Scouting and Decision Making](https://www.umass.edu/agriculture-food-environment/greenhouse-floriculture/fact-sheets/ipm-scouting-decision-making). 정기 예찰·위치·포획 및 식물 관찰 기록의 근거. 해외 트랩 설치 밀도나 약제 정보를 국내 농장 처방으로 적용하지 않음.
