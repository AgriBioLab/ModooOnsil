## 기능 단위 페어 세션

1. 시작: Jira 목표·완료 기준·설계/테스트 시나리오와 드라이버·내비게이터를 정한다.
2. 분석·설계: 문서·화면·ERD·공통 용어·API·예외·누락을 함께 확인하고 결정/미결을 구분한다.
3. 구현·단위 테스트: 화면→Service→데이터 접근→DB→테스트를 한 기능 단위로 진행한다. 25~30분 교대는 조정 가능한 기본안이다.
4. 종료: 두 사람이 처리 흐름을 설명·재현하고 설계·PR·결과를 연결한다. 가능한 경우 다른 페어가 PR을 검토한다.

신규팀원과 기존 기능에 익숙한 팀원의 짝을 우선 고려한다. Jira 책임자 1명과 페어 파트너를 구분하며 작업을 중복 생성하지 않는다. 2명이 2시간 함께 작업하면 일정은 2시간, 인력 투입은 4인시로 기록한다.

## 업무 우선순위·흐름

Spring 전환·리팩토링 → 품질담당자 통계·전년도 비교 → 공통 계정/역할별 화면 → 생산자 가입·신청·본인 조회 → 통합 검증·발표 준비. 통계는 기존/검증용 데이터로 진행해 생산자 완성을 기다리지 않는다.

생산자 설계 10/26~28 → 가입 10/29~30 → 마이페이지/신청 11/2~4 → 본인 조회 11/5~6. 병렬 작업은 가용 페어 배정에 맞춰 확정한다.
