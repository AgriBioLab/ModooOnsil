### 매일 사용할 양식

- 날짜 / 참석자 / 진행자 / 기록자
- 어제 완료한 일: Jira 업무·PR·검증 근거
- 오늘 할 일: Jira 업무·오늘 완료 목표
- 막힌 점: 원인·필요한 지원·해결 담당·기한
- 결정·변경: 결정 내용·이유·담당·기한·영향 업무
- 후속 조치: 기존 Jira 업무 갱신 또는 중복 확인 후 새 업무 등록
- 회의 종료 전: 상태·시작/완료 목표일·선행 관계 갱신 여부 확인

10/30은 1주차 점검, 11/6은 핵심 흐름 시연·신규 기능 동결 점검, 11/9~13은 통합 검증·수정·보고 준비 구간이다. DAILY 업무는 매일 운영을 보여주는 일정 막대이며 15인일의 개발 공수가 아니다.
