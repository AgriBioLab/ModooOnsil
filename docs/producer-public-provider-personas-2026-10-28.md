# 생산자 중심 공공 서비스 제공자 페르소나

작성일: 2026-10-28 / 대상: 온실 절화국화 생산자를 지원하는 공공 서비스 체계

> 최신 방향: [생산자 지원기관 선정·보상환경 확장 제안](public-provider-selection-proposal-2026-10-28.md). 생산자를 실제 지원하는 기관을 먼저 선정한다. 2차 재배공정은 그 지원업무에 기반하며, 보상 모니터링·평가·예측·전략·예산 서비스는 같은 기관에 향후 추가로 제안한다. 아래 기관별 페르소나는 비교 참고다.

> 후속 사용자 확정: 1차 피해보상 모니터링과 2차 생산자 재배공정은 같은 기관이 제공한다. 아래는 기관별 비교 페르소나이며, 현재 단일 제공기관·스프린트 배경은 [1차 기반 2차 기관 선정안](sprint2-single-public-provider-background-2026-10-28.md)을 따른다. 2차는 생산자 액터에 집중하고 품질담당자·피해보상 추가 작업은 후속으로 둔다.

> 품질담당자 최신 정의: 보상 결과·통계 모니터링 → 보상 품질 평가 → 예측 기반 보상 전략·예산 책정. 복구지원은 직접 수행하지 않는다. 아래 ‘모니터링만’이라는 이전 표현보다 이 정의를 우선한다. 남양주 농업기술센터의 복구지원 업무를 근거로 제공기관을 확정했던 판단은 유보하고 실제 평가·전략·예산 업무와 대조한다.

기관의 제공 업무는 공식 자료에 근거한다. 아래 담당자의 불편·니즈·대표 발화·이용 시나리오는 서비스 설계를 위한 가설이며 현장 인터뷰 결과가 아니다. 여러 기관이 동일한 시스템을 공동 운영하기로 했다는 뜻은 아니다.

## 1. 서비스 배경과 역할 구성

절화국화 생산자는 품종과 출하계획을 정한 뒤 묘 준비·정식·생육관리·개화 조절·수확·출하를 수행한다. 생산자는 공정마다 다른 도움이 필요하다. 재배기술을 찾는 일, 현장 문제를 상담하는 일, 품종별 특성을 확인하는 일, 농업경영체 정보를 등록·변경하는 일은 각각 다른 제공 역할과 연결된다.

**서비스 개요 제안:** 온실 절화국화 생산자가 재배공정별 상황을 정리하고 필요한 공공 기술·현장·품종·행정 지원으로 연결되도록 돕는 생산자 지원 서비스. 피해보상 영역에서는 기존 품질담당자가 보상 처리 현황과 결과를 모니터링한다.

‘공공 농업기술지원’은 기술 개발·보급·현장 적용을 포괄하는 제공 체계로 사용한다. 그 안에서 농진청·농업기술센터·화훼연구소의 담당자를 구분한다. 농관원은 농업경영체 등록 등 행정 지원을 제공하는 별도 관계기관으로 함께 배치한다.

여기서 **생산자 중심은 기관별 서비스의 제공가치를 생산자의 문제에서 설명한다는 뜻**이다. 1차 스프린트 품질담당자의 역할을 변경하거나 기관별 화면 구현을 확정한다는 뜻은 아니다. 품질담당자는 피해보상 모니터링만 수행한다.

## 2. 공통 이용자 페르소나 — 온실 절화국화 생산자

| 항목 | 정의 |
|---|---|
| 대표 역할 | 온실에서 절화국화를 재배하며 작업·환경관리·수확·출하를 결정하는 농장주 겸 재배 책임자 |
| 배경 | 품종과 작형에 따라 재배 단계와 관리 방법이 달라진다. 재배를 운영하면서 기술 문의와 행정 준비도 병행해야 한다. 지역 예시는 충남 예산이며 최종 모집 지역은 미확정 |
| 목표 | 출하계획에 맞춰 재배하고, 이상이 생기면 필요한 도움을 제때 받으며, 지원에 필요한 생산정보를 준비 |
| 불편 가설 | 자료를 찾아도 내 품종·작형에 맞는지 판단하기 어렵다. 상담 때 온실 상황과 과거 작업을 다시 설명한다. 문의할 기관과 준비할 자료를 구분하기 어렵다 |
| 정보 니즈 | 현재 공정에 맞는 기술자료, 현장 상담 창구, 품종별 관리 특성, 경영체 등록·변경 안내 |
| 서비스 니즈 | 온실·품종·재배 단계·작업·사진을 맥락으로 정리하고, 필요한 기관의 안내·상담 준비로 연결 |
| 대표 발화 | “지금 우리 국화에 생긴 문제를 누구에게 물어보고, 무엇을 준비하면 되는지 알고 싶다.” |

품목·단계 선정 근거: [농사로 국화 농작업 일정](https://nongsaro.go.kr/portal/ps/psb/psbl/workScheduleDtl.ps?cntntsNo=30672&menuId=PS00087&sKidofcomdtySeCode=210003&totalSearchYn=Y). 공정별 니즈는 해당 일정과 기관 업무를 바탕으로 도출한 설계 가설이다.

## 3. 제공자 페르소나 ① — 농촌진흥청 기술보급·현장지원 담당자

**한 줄 역할:** 생산자가 활용할 재배·재해 대응 기술을 지역 현장으로 전달하는 공공 기술지원 제공자.

| 항목 | 정의 |
|---|---|
| 서비스 제공 배경 | 생산자가 경험에만 의존하지 않고 검증된 기술을 활용하도록 도울 필요가 있다. 중앙의 기술과 현장의 적용 사이를 연결하는 역할이 필요 |
| 실제 업무 근거 | 농진청은 작목별 스마트팜 현장적용 사례를 제공하고, 재해 대응 시 지역 농촌진흥기관과 함께 현장 기술지원을 수행 |
| 담당자 목표 | 생산자와 지역 지원기관이 상황에 적합한 기술을 이해하고 적용하도록 지원 |
| 불편 가설 | 중앙에서 제공한 자료가 어떤 현장 조건에서 활용되는지 파악하기 어렵고, 현장 문의의 맥락이 부족하면 필요한 기술을 연결하기 어려움 |
| 담당자 니즈 | 품목·작형·단계·문제 유형이 구분된 문의, 기술자료의 출처·적용 조건·갱신 정보, 현장 피드백 |
| 생산자에게 제공할 가치 | 재배·재해 대응 자료와 적용 조건 안내, 필요시 지역·전문 지원 창구 연결 |
| 서비스 기능 제안 | 공정별 기술자료 탐색, 자료의 출처·기준일 표시, 현장 질문과 관련 자료 연결 |
| 대표 발화 | “생산자가 자기 상황에 맞는 기술을 찾고 현장에서 활용할 수 있도록 안내하고 싶다.” |

시나리오 가설: 생산자가 개화 조절 관련 자료를 찾는다. 시스템이 품종·작형·재배 단계에 해당하는 공식 자료를 안내하고, 현장 판단이 필요한 내용은 기술센터 상담 준비로 이어준다.

근거: [농사로 작목별 현장적용기술](https://nongsaro.go.kr/portal/ps/psz/psza/contentMain.ps?menuId=PS65470), [농진청 재해 대응 현장 기술지원 사례, 2025-12-17](https://www.rda.go.kr/board/board.do?boardId=farmprmninfo&currPage=102&dataNo=100000806726&mode=updateCnt&prgId=day_farmprmninfoEntry&searchEDate=&searchKey=&searchOrgDeptKey=&searchOrgDeptVal=&searchSDate=&searchVal=). 스마트팜 자료는 2016~2017년 사례이며 현재 농가 전체의 성과로 일반화하지 않는다.

## 4. 제공자 페르소나 ② — 시군 농업기술센터 화훼·스마트원예 담당자

**한 줄 역할:** 생산자의 실제 재배 상황을 확인하고 현장에 맞는 상담·교육·기술 적용을 돕는 가까운 지원자.

| 항목 | 정의 |
|---|---|
| 서비스 제공 배경 | 같은 기술도 온실과 작형에 따라 적용 방법이 달라진다. 생산자가 현장에서 겪는 문제를 지역 단위에서 구체적으로 지원할 창구가 필요 |
| 실제 업무 근거 | 예산군농업기술센터 스마트원예팀에 화훼 관련 민원과 시설원예 생육환경 개선 시범사업 등의 업무가 명시됨 |
| 담당자 목표 | 생산자의 재배 상황을 이해하고 필요한 기술지도·교육·시범사업 안내를 연결 |
| 불편 가설 | 상담마다 농장 위치·품종·재배 단계·작업 내용을 다시 확인하고, 이전 지도 후 변화가 있었는지 비교하기 어려움 |
| 담당자 니즈 | 상담 전 기초정보, 시점별 사진·관찰·작업 기록, 기존 상담 내용과 후속 확인 결과 |
| 생산자에게 제공할 가치 | 내 온실 상황에 맞는 상담과 현장 적용 지원, 필요시 전문기관 연결 |
| 서비스 기능 제안 | 상담용 재배현황 요약, 문의·방문·후속 확인 이력, 관련 교육·사업의 공식 안내 연결 |
| 대표 발화 | “농가가 무엇을 언제 했고 현재 상태가 어떤지 알아야 상황에 맞는 지원을 할 수 있습니다.” |

시나리오 가설: 생산자가 개화 지연을 문의하면서 품종·정식일·전조 및 차광 기록·사진을 준비한다. 담당자는 자료를 참고해 상담하고, 품종별 검토가 필요하면 화훼연구소 등 전문기관에 문의할 내용을 정리한다.

근거: [예산군농업기술센터 직원·업무 안내](https://www.yesan.go.kr/prog/deptOnnaraPerson/farm/sub01_01_04/list.do?deptparentcode=4610033%2C4610070%2C4610170%2C4610171). 스마트팜 시설보급은 별도 담당팀 업무이므로 화훼 상담자 한 명에게 모든 사업 권한을 부여하지 않는다.

## 5. 제공자 페르소나 ③ — 도 농업기술원 화훼연구소 국화 연구·보급 담당자

**한 줄 역할:** 생산자가 품종 특성을 이해하고 지역에 맞는 재배기술을 적용하도록 돕는 화훼 전문 지원자.

| 항목 | 정의 |
|---|---|
| 서비스 제공 배경 | 국화는 품종·작형에 따라 관리 특성과 생산 결과가 달라질 수 있다. 일반 재배 안내에 더해 품종과 재배법에 대한 전문 연구·현장 적용이 필요 |
| 실제 업무 근거 | 충남농업기술원 화훼연구소는 국화 등 품종 개발·재배법 개선·우량종묘 생산 보급을 담당하며, 직원 업무에 스탠다드국 신품종 실용화·현장 연구가 제시됨 |
| 담당자 목표 | 개발 기술과 품종이 농가에 적합하게 활용되도록 하고 현장 적용 결과를 연구·보급 개선에 참고 |
| 불편 가설 | 농가별 품종명·작형·기록 방식이 달라 같은 증상이나 재배 결과를 비교하기 어려움 |
| 담당자 니즈 | 정확한 품종·작형·재배 단계, 처리 이력, 시점이 있는 생육 관찰, 비교 조건 |
| 생산자에게 제공할 가치 | 품종 특성과 재배법 정보, 전문적인 현장 적용 검토, 종묘 보급 관련 안내 |
| 서비스 기능 제안 | 품종별 공식 기술정보, 공정·처리·관찰 기록의 상담용 정리, 참여가 확정된 경우에 한해 실증 기록 양식 검토 |
| 대표 발화 | “어떤 품종을 어떤 조건에서 재배했는지 알아야 현장 결과를 해석하고 기술을 보완할 수 있습니다.” |

시나리오 가설: 생산자가 새 품종을 검토한다. 품종 정보와 제공 조건을 확인하고, 적용 후 기록을 바탕으로 기술센터·연구소와 상담할 내용을 정리한다. 기록 비교만으로 재배 효과의 인과관계를 확정하지 않는다.

근거: [화훼연구소 소개](https://cnnongup.chungnam.go.kr/sub.cs?m=166), [연구소 직원별 업무](https://cnnongup.chungnam.go.kr/organization/staff/DEPT_000000000000111.cs?m=209).

## 6. 제공자 페르소나 ④ — 농관원 농업경영체 등록·관리 담당자

**한 줄 역할:** 생산자의 실제 영농 현황을 행정정보로 등록·관리하도록 돕는 공공 행정 서비스 제공자.

| 항목 | 정의 |
|---|---|
| 서비스 제공 배경 | 생산자는 영농과 함께 농지·품목 등 경영체 정보를 준비하고 현황 변경을 반영해야 한다. 경영체 등록 안내에는 화훼 재배 관련 요건도 포함됨 |
| 실제 업무 근거 | 농관원은 관할 지원·사무소를 통해 농업경영체 등록을 접수하며, 등록정보에는 인적정보·농지·농작물 생산정보 등이 포함됨 |
| 담당자 목표 | 생산자가 필요한 정보와 증빙을 이해하고 실제 영농 현황에 맞게 등록·변경하도록 지원 |
| 불편 가설 | 생산자가 재배기록과 행정 제출정보의 차이를 이해하기 어렵고, 정보·증빙이 흩어져 보완 안내를 반복할 수 있음 |
| 담당자 니즈 | 신청 목적에 맞는 기초정보, 실제 재배 상황을 설명할 자료, 누락 항목과 보완 상태의 구분 |
| 생산자에게 제공할 가치 | 등록·변경 대상과 준비자료 안내, 공식 신청 창구 연결, 보완할 내용 이해 지원 |
| 서비스 기능 제안 | 농장 기록을 참고한 준비 목록, 공식 안내 링크, 생산자가 직접 확인하는 정보 요약. 실제 등록·변경은 공식 절차에 따름 |
| 대표 발화 | “생산자가 어떤 정보를 준비하고 변경해야 하는지 이해하도록 안내하고 싶습니다.” |

시나리오 가설: 생산자가 재배품목이나 농지 현황의 변경을 준비한다. 기존 영농기록을 참고해 정보를 정리하고 농관원 안내에서 해당 신청에 필요한 자료를 확인한 뒤 공식 창구를 이용한다.

근거: [농관원 농업경영체 등록 안내](https://naqs.go.kr/hp/contents/contents.do?hpMenuId=MN10003&menuId=MN40248&menuType=CON&upMenuId=MN20368). 등록정보의 외부 자동 조회·수정 권한이나 기관 간 공유가 확보된 것은 아니다. 경영체 등록만으로 개별 지원사업 자격이 자동 확정되는 것으로 설명하지 않는다.

이 페르소나는 절화국화 생산자와 직접 연결되는 경영체 업무로 한정했다. 농관원의 다른 업무까지 없다는 뜻은 아니다. 안전성조사·인증·검사 등은 해당 품목과 실제 업무의 적용 범위를 확인한 뒤 별도로 정의한다.

## 7. 생산공정에서 만나는 제공자

| 생산자의 상황 | 우선 연결할 제공 역할 | 서비스가 돕는 일의 예시 |
|---|---|---|
| 품종·묘와 작형을 결정할 때 | 화훼연구소, 기술센터 | 품종·재배법·보급 관련 공식 정보와 상담 준비 |
| 정식 후 재배기술을 찾을 때 | 농진청 기술자료, 기술센터 | 공정·조건에 맞는 자료 탐색과 적용 상담 |
| 생육 이상이나 개화 조절 문제가 있을 때 | 기술센터, 필요시 화훼연구소 | 작업·사진·관찰 내용을 정리해 상담 맥락 제공 |
| 재해 예방·피해 후 영농 회복이 필요할 때 | 농진청·기술센터·전문기관의 기술지원 | 공식 예방·관리 안내와 현장 지원 창구 연결 |
| 경영체 정보를 등록·변경할 때 | 농관원 | 정보·증빙 준비와 공식 신청 안내 |
| 피해보상 처리 결과를 확인할 때 | 기존 품질담당자 | 권한 범위에서 보상 목록·상세·결과 모니터링 |

위 표는 역할을 설명하는 설계안이다. 자동 기관 배정·기관 간 전산 연계·지원 확정 기능이 구현됐다는 뜻은 아니다.

## 8. 1차 스프린트 품질담당자와의 관계

**품질담당자 페르소나:** 피해보상 건의 처리 현황과 결과를 확인하는 모니터링 전담 사용자. 목표는 필요한 건을 찾아 신청·조사·조치·산정·지급 관련 정보를 이해하는 것이다. 니즈는 목록 검색, 상세의 연결 관계, 서류·금액·일자의 확인이며 실제 구현 범위는 기존 스프린트 자료를 따른다.

농진청·센터·연구소·농관원 담당자를 품질담당자와 같은 계정·권한으로 묶지 않는다. 품질담당자에게 기술지도·생산공정 운영·경영체 심사·보상 승인·지급 업무를 부여하지 않는다. 소속기관은 이번 페르소나 정리만으로 확정하지 않는다.

생산자의 재배공정과 관계기관의 지원은 피해 발생 배경을 설명하는 맥락이다. 관련 자료가 실제 피해 건에 연결되고 열람 근거가 확인되는 경우 품질담당자의 모니터링에 참고하도록 검토한다.

## 9. 발표용 서비스 제공 배경

> 온실 절화국화 생산자는 재배공정을 운영하면서 품종 선택, 재배기술 확인, 현장 문제 해결, 경영체 정보 준비 등 서로 다른 지원을 필요로 합니다. 이에 공공 서비스 제공자를 농진청의 기술보급 담당자, 농업기술센터의 현장 지원 담당자, 화훼연구소의 품종·재배기술 연구자, 농관원의 경영체 등록 담당자로 구분했습니다. 생산자가 공정별로 필요한 지원과 준비자료를 찾을 수 있도록 돕는 것이 공공 제공자를 검토하는 배경입니다. 1차 스프린트의 품질담당자는 기존과 동일하게 피해보상 모니터링만 수행합니다.

## 10. 페르소나 검증 질문

- 생산자: 공정별로 실제 문의하는 기관은 어디이며, 상담·행정 준비에서 어떤 설명과 자료를 반복하는가?
- 농진청 담당자: 기술자료를 어떤 대상·경로로 보급하며, 현장 피드백을 어떤 방식으로 받는가?
- 기술센터 담당자: 상담 전에 필요한 최소 정보는 무엇이고, 어떤 경우에 연구기관의 지원이 필요한가?
- 화훼연구소 담당자: 품종별 상담·현장 적용 검토에 필요한 기록과 참여 조건은 무엇인가?
- 농관원 담당자: 생산자가 반복해서 어려워하는 등록·변경 항목과 준비자료는 무엇인가?
- 품질담당자: 보상 모니터링에 실제로 필요한 자료는 무엇이며, 누가 어떤 근거로 제공하는가?
