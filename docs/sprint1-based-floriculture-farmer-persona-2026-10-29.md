# 화훼농민 중심 페르소나와 니즈

작성일: 2026-10-29

정리 기준: 기존 1차 스프린트는 프로젝트의 출발점으로 유지한다. 이번 문서는 화훼농민의 일상적인 재배관리 니즈에 집중한다. 아래 기능은 기획 검토안이며 1차 구현 완료 기능이나 이번 개발 확정 범위를 뜻하지 않는다.

페르소나의 이름·나이·농장 규모·행동·발화는 인터뷰 전 가설이다. 기존 문서의 온실 절화국화 사례를 대표 상황으로 사용하며, 모든 화훼농가의 특성으로 일반화하지 않는다.

## 1. 서비스 개요

**화훼농민이 온실별 재배현황과 작업·환경·출하 기록을 한곳에서 관리하여, 필요한 작업을 제때 수행하고 다음 재배에 참고하도록 돕는 서비스.**

농민에게 설명하는 한 문장:

> “우리 온실에서 무엇을 키우고 있고, 지금 무엇을 해야 하며, 지난번에 어떻게 관리했는지 확인하는 서비스입니다.”

## 2. 주 페르소나

### 김민수 — 여러 온실의 재배를 직접 관리하는 화훼농민

| 항목 | 내용 |
|---|---|
| 기본 설정 | 50대, 절화국화를 재배하는 농장주 겸 재배 책임자 |
| 농장 상황 | 온실 3개 동에서 재배하며, 구역에 따라 품종·정식 시기·재배 단계가 다름 |
| 담당 업무 | 재배계획, 생육 확인, 환경·설비 관리, 작업 지시, 수확·출하 관리 |
| 현재 관리 방식 | 온실을 돌며 상태를 확인하고 수첩·휴대전화 사진·메신저에 작업 내용을 나누어 남김 |
| 디지털 사용 상황 | 현장에서는 스마트폰으로 짧게 확인·입력하고, 사무실에서는 PC로 여러 온실과 지난 기록을 살펴보고 싶어 함 |
| 핵심 목표 | 온실별 상황을 빠르게 파악하고 필요한 작업을 놓치지 않으며, 이전 재배 경험을 다음 관리에 활용 |
| 서비스 사용 계기 | 아침 작업 전, 현장 작업 직후, 외출 중 상태 확인, 수확·출하 후, 다음 재배 준비 시 |

대표 발화:

> “온실마다 심은 시기와 할 일이 달라요. 어디에 무슨 작업이 필요한지 보고, 지난번에는 어떻게 했는지도 바로 찾아보고 싶어요.”

## 3. 불편에서 도출한 니즈

| 농민이 겪는 상황·불편 가설 | 농민의 니즈 | 기능으로 연결할 때의 검토안 |
|---|---|---|
| 온실마다 품종과 재배 시기가 달라 머릿속으로 구분하기 어려움 | **온실·구역별로 무엇을 키우고 어느 단계인지 한눈에 알고 싶다.** | 농장·온실·구역·품종·정식일·재배 단계별 현황 |
| 여러 구역의 작업을 챙기다 보면 해야 할 일과 완료한 일이 섞임 | **오늘 할 일과 이미 끝낸 일을 구분하고 싶다.** | 구역별 예정 작업·완료 기록 조회 |
| 작업 내용과 사진이 흩어져 지난 관리를 다시 찾기 어려움 | **언제 어디에서 무슨 작업을 했는지 쉽게 남기고 찾아보고 싶다.** | 날짜·온실·작업 종류별 기록 등록·검색·상세 조회 |
| 현장에 가야 환경과 설비 상태를 확인할 수 있음 | **농장 밖에서도 확인이 필요한 온실을 알고 싶다.** | 환경·설비 상태와 측정 시각 조회. 실제 제공 범위는 장비 연동 여부에 따라 결정 |
| 설정을 바꾼 뒤 원하는 상태가 됐는지 다시 확인해야 함 | **내가 바꾼 설정과 실제 결과를 함께 확인하고 싶다.** | 적용 설정·변경 이력·실행 결과 확인. 제어는 장비 연동을 전제로 별도 검토 |
| 이전 재배에서 어떤 조건과 작업을 적용했는지 기억에 의존함 | **지난 재배의 관리 방법과 결과를 비교해 다음 재배에 참고하고 싶다.** | 재배 회차별 작업·환경 설정·수확 기록 비교 |
| 수확량과 출하 내역을 따로 적어 재배 결과와 연결하기 어려움 | **어느 온실에서 얼마나 수확하고 출하했는지 알고 싶다.** | 온실·재배 회차별 수확·출하 날짜와 수량 기록 |
| 작업 중 긴 양식 작성은 번거로워 기록을 미루게 됨 | **작업 직후 짧게 입력하고 나중에 다시 확인하고 싶다.** | 온실·날짜 기본값, 자주 쓰는 작업 선택, 사진 첨부, 저장 상태 표시 |

환경값만으로 생육 상태나 재배 단계가 자동 판정된다고 가정하지 않는다. 단계와 생육 상태는 농민의 관찰·입력과 구분해 다룬다.

## 4. 니즈 우선순위

### 우선 검토 — 내 재배현황과 작업을 파악하고 기록하기

1. 온실·구역별 품종과 재배 단계 확인.
2. 예정 작업과 완료한 작업 확인.
3. 작업기록 등록·검색·상세 확인.
4. 수확·출하 기록과 해당 재배 회차 연결.

이 흐름으로 농민이 기록을 남길 이유와 다시 조회할 이유를 먼저 검증한다. 기존 1차의 목록·검색·상세 흐름은 화면 설계 참고로 활용하되, 농민용 기능의 구현 여부는 별도로 확인한다.

### 현장 조건을 확인하며 구체화

- 환경 모니터링과 이상 상태 확인: 필요한 측정 항목, 확인 빈도, 장비 연결 여부 확인.
- 중앙·원격제어와 환경 설정: 자주 조작하는 설비, 설정 기준, 실제 작동 확인 수단 확인.
- 설정 비교와 운영 통계: 농민이 실제로 비교하는 조건과 다음 재배에 활용하는 항목 확인.

위 우선순위는 페르소나 검증을 위한 제안이다. 기존에 논의한 제어 기능을 삭제하거나 전체 스프린트 백로그를 변경한 것으로 보지 않는다.

## 5. 대표 이용 시나리오

1. **작업 전:** 김민수 씨가 온실별 품종·재배 단계·예정 작업을 확인한다.
2. **작업 후:** 해당 구역을 선택해 수행한 작업과 관찰 내용을 짧게 기록하고 사진을 남긴다.
3. **상태 재확인:** 특정 온실의 지난 작업을 검색해 언제 어떤 관리를 했는지 확인한다. 환경 데이터가 연결된 경우 측정 시각과 함께 현재 상태도 확인한다.
4. **수확·출하 후:** 날짜와 수량을 해당 재배 회차에 연결해 기록한다.
5. **다음 재배 준비:** 지난 재배의 작업과 수확·출하 내역을 살펴보고 이번 계획에 참고한다.

## 6. 인터뷰에서 확인할 질문

- 온실별 재배현황과 할 일을 지금 어떻게 구분하고 있는가?
- 가장 자주 빠뜨리거나 다시 찾는 작업기록은 무엇인가?
- 현장에서 기록할 수 있는 최소 항목과 적절한 입력 시점은 무엇인가?
- 농장 밖에서 꼭 확인해야 하는 상태와 직접 조작해야 하는 설비는 무엇인가?
- 지난 재배와 비교할 때 실제로 보는 기록은 무엇인가?

사용성 검증에서는 특정 온실의 현황 확인 → 작업기록 입력 → 이전 기록 검색을 수행하게 하고, 완료 여부·막히는 지점·입력 부담을 관찰한다.

## 7. 발표용 페르소나 설명

> 저희의 주 사용자는 여러 온실에서 화훼를 재배하며 작업과 환경 관리를 직접 맡는 농민입니다. 온실마다 품종과 재배 시기가 다르고 작업기록이 흩어져 있어, 현재 상황과 필요한 작업을 파악하거나 지난 관리를 다시 확인하는 데 어려움이 있다는 가설을 세웠습니다. 이에 온실별 재배현황, 작업과 수확·출하 기록을 한곳에서 관리하여, 농민이 필요한 작업을 제때 하고 다음 재배에 경험을 활용하도록 돕고자 합니다.
